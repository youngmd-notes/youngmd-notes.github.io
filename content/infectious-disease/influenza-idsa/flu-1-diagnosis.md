> [!abstract] 一句話重點
> - 流行季：
>   - **==住院的 acute respiratory illness（含 pneumonia）、慢性心肺病惡化、免疫不全或高風險者一律驗（A-II/A-III）==**
>   - 門診**驗了會改變處置才驗**
> - **檢體**：發病 **4 天內**採，**NP 最好**，沒有就 **nasal＋throat 合併**；**插管病人要送 ETA 或 BAL**（上呼吸道陰性也要）
> - **檢驗**：門診用 **rapid molecular assay** 優於快篩（RIDT），**住院用 RT-PCR**，免疫不全住院用 **multiplex PCR**
> - **==RIDT 敏感度只有約 5 成，流行季陰性不能排除，不可因此不給藥==**；**不驗血清抗體、不用病毒培養做初步診斷**
> - **給藥不必等檢驗結果**

## 證據分級怎麼讀（Table 1）

<div class="orig-fig" data-src="感染科/influenza-originals/table-01.png" data-label="Table 1"></div>

這份指引沿用 **IDSA–USPHS 分級**（不是 GRADE）：**字母＝建議強度**，**羅馬數字＝證據品質**。

| 強度 | 意思 | 證據品質 | 意思 |
| --- | --- | --- | --- |
| **A** | 好的證據支持做或不做 | **I** | ≥ 1 個 RCT |
| **B** | 中等證據 | **II** | 非隨機試驗、cohort、case-control |
| **C** | 證據差 | **III** | 專家意見、描述性研究 |

> [!tip] 讀法
> 「A-III」＝**強烈建議，但只有專家意見**——很多流感建議都是這種（沒有 RCT，但委員會認為一定要做）。

## 什麼時候要懷疑流感

### 典型症狀（Table 2）

<div class="orig-fig" data-src="感染科/influenza-originals/table-02.png" data-label="Table 2"></div>

**突然發作**的呼吸道＋全身症狀，**可以沒有發燒**：

| 全身 | 頭頸 | 神經肌肉 | 腸胃 | 呼吸 |
| --- | --- | --- | --- | --- |
| Fever、chills、malaise、fatigue | Headache、nasal congestion、rhinorrhea、sore throat、hoarseness | **Myalgia**、arthralgia、weakness | Abdominal pain、vomiting、diarrhea | **Nonproductive cough**、pleuritic chest pain |

- 成人門診**突發 fever＋cough** 預測力最好（流行季 sensitivity > 70%）
- **嬰幼兒**：可能只有高燒、像 sepsis；diarrhea 較常見；**老人與嬰兒**可能不燒或只有低燒
- **老人**：發燒少、全身症狀較輕，但 **altered mental status** 較多；把體溫切點降到 **≥ 37.2–37.3°C** 配合 cough 可提高敏感度
- **免疫不全**：常不符合 ILI 定義（移植中心群聚中只有 7% 符合）
- **住院 ≥ 48 小時後**才發燒、或住院中新出現的 cough → 想 **nosocomial influenza**
- 打過疫苗**不能排除**流感（VE 最好也只有約 40–60%）

### 併發症（Table 3）

<div class="orig-fig" data-src="感染科/influenza-originals/table-03.png" data-label="Table 3"></div>

| 族群 | 重要併發症 |
| --- | --- |
| **所有年齡** | Respiratory failure、**ARDS**、multiorgan failure、sepsis、肝發炎 |
| **成人** | **Pneumonia**、**invasive bacterial coinfection**、myocarditis、pericarditis、myositis、**rhabdomyolysis**、AKI、encephalopathy、**誘發 MI、HF、stroke**、*S. aureus*／*S. pyogenes* **toxic shock syndrome**、慢性病惡化 |
| **老人** | Pneumonia、細菌合併感染、myositis、慢性病惡化 |
| **孕婦與產後** | Dehydration、pneumonia、心肺疾病、**早產、流產** |
| **免疫不全** | 同一般人，但**嚴重 pneumonia、ARDS 更常見** |
| 兒童 | Febrile seizure、croup、otitis media、**bilateral gastrocnemius myositis**、**Reye syndrome（用 aspirin）**、sudden death |

- 最常見的細菌合併感染：***S. pneumoniae***，其次 ***S. aureus*（含 MRSA，兒童流感死亡中越來越多）**、*S. pyogenes*
- 肺外併發症中最常被描述的是 **myocarditis 與 encephalitis**；流感可**誘發急性 MI**

### 高風險族群（Table 4）

<div class="orig-fig" data-src="感染科/influenza-originals/table-04.png" data-label="Table 4"></div>

| 高風險 | 細節 |
| --- | --- |
| **年齡** | **< 5 歲（尤其 < 2 歲）**、**≥ 65 歲** |
| **慢性病** | 肺（含 **asthma**）、**心血管（單純 HTN 不算）**、腎、肝、血液（含 sickle cell）、代謝（含 **DM**） |
| **神經與發展疾病** | Cerebral palsy、epilepsy、stroke、intellectual disability、muscular dystrophy、spinal cord injury |
| **免疫抑制** | 藥物或 HIV；**==最高風險是嚴重免疫不全（例如 HSCT）==** |
| **懷孕或產後 2 週內** | |
| **< 19 歲長期吃 aspirin** | Reye syndrome 風險 |
| **極度肥胖** | **BMI ≥ 40** |
| **住在 nursing home、長照機構** | |
| 美國原住民 | 死亡率較高 |

### 哪些表現要想到流感（Table 5）

<div class="orig-fig" data-src="感染科/influenza-originals/table-05.png" data-label="Table 5"></div>

| 時機 | 要想到流感的情境 |
| --- | --- |
| **流行季** | 任何年齡的**急性呼吸道症狀**（不論有無發燒）；**pneumonia**；**COPD、asthma 惡化**；嬰幼兒**不明原因發燒**或 **new-onset seizure、altered mental status**；**新發生或惡化的心血管事件**（HF、MI、stroke）；**嚴重或惡化中**的呼吸道疾病、找不到其他診斷；**住院中新出現**呼吸道症狀 |
| **全年** | 和流感病例或群聚有流行病學關聯：照顧流感病人的醫護、**機構群聚**、家人或同住者、**最近出國**、旅行團、國際大型集會、夏令營、**郵輪**、軍艦 |

> [!warning] Pitfall
> - 研究中只有 **29%** 檢驗確診的流感病人被臨床診斷為流感；**被診斷為細菌感染的人，被想到流感的機會少 3 倍**
> - 有**禽類接觸**（活禽市場）或**豬隻接觸**的旅客 → 想 **novel influenza A**，通報衛生單位（不在本指引範圍）

## 誰要驗：Recommendation 1–4（Figure 1）

<div class="orig-fig" data-src="感染科/influenza-originals/figure-01.png" data-label="Figure 1"></div>

| 情境 | 流行季（influenza activity） | 低流行期 |
| --- | --- | --- |
| **門診、高風險**（含免疫不全）有 ILI、pneumonia 或非特異性呼吸道症狀 | **要驗**（若會改變處置，A-III） | **可考慮驗**，尤其免疫不全、高風險（B-III） |
| **門診**，急性呼吸道症狀＋**慢性病惡化**（asthma、COPD、HF）或**併發症**（pneumonia） | **要驗**（若會改變處置，A-III） | 同上 |
| **門診、非高風險**、預計回家 | **可考慮驗**：會影響抗病毒、減少抗生素與其他檢查、縮短急診停留，或影響**同住高風險家人**的處置（C-III） | 同上 |
| **住院**的 acute respiratory illness（**含 pneumonia**），不論有無發燒 | **==入院就驗（A-II）==** | **有流行病學關聯**（接觸病例、群聚、近期出國）→ **要驗（A-II）**；其他高風險者可考慮（B-III） |
| **住院**，**慢性心肺病急性惡化**（COPD、asthma、CAD、HF） | **入院就驗（A-III）** | — |
| **住院**，**免疫不全或高風險**＋急性呼吸道症狀 | **入院就驗（A-III）**（表現常不典型） | — |
| **住院中**新出現呼吸道症狀或 respiratory distress，沒有明確其他診斷 | **要驗（A-III）** | — |

Figure 1 重點（流行季、不論是否打過疫苗；依原圖內容重新整理）：

| 起點 | 再問 | 結論 |
| --- | --- | --- |
| **症狀像流感**（fever＋cough、myalgia、headache），**要住院** | — | **==驗流感＋立即經驗性抗病毒，不等結果==** |
| 症狀像流感但**不住院**；或症狀**不典型**（只有發燒、免疫不全者沒發燒）、有**併發症**（pneumonia）、**慢性病惡化**（asthma、COPD、HF） | **驗了會改變處置嗎？** → **會** | **驗流感＋經驗性抗病毒，等結果** |
| 同上 | → **不會** | **臨床診斷**，不驗；**高風險或病程惡化 → 給抗病毒**；非高風險、**發病 ≤ 2 天**可考慮給；回家 |
| 不像流感，也沒有不典型表現或併發症 | — | **不驗**，找其他病因 |

> [!tip] Pearl
> **抗病毒藥的決定不需要等檢驗確診**——依症狀與流行病學就可以開始；檢驗的價值在於**決定要不要用抗生素、要不要做其他檢查、感染管制**與**群聚處理**。

## 採什麼檢體：Recommendation 5–9

| # | 建議 | 分級 |
| --- | --- | --- |
| 5 | **門診**：盡早採上呼吸道檢體，**最好在發病 4 天內** | A-II |
| 5 | **NP 檢體優於**其他上呼吸道檢體 | A-II |
| 5 | 沒有 NP → **nasal＋throat 合併**送驗，優於單一部位（**尤其優於 throat swab**） | A-II |
| 5 | **Mid-turbinate** 優於 throat swab；**flocked swab** 優於非 flocked | A-II |
| 6 | **住院、沒有嚴重下呼吸道疾病**：NP、mid-turbinate 或 nasal＋throat 合併，越快越好 | A-II |
| 7 | **==插管的呼吸衰竭病人：送 ETA 或 BAL==**，**即使上呼吸道已經陰性** | A-II |
| 8 | **不要**送血、CSF、尿、糞便等非呼吸道檢體 | A-III |
| 9 | **不要**送血清（單次或配對）做診斷 | A-III |

- 病毒排出在**發病 1–2 天最多**，之後下降；**發病 > 3–4 天**才採，上呼吸道可能已經陰性
- 嚴重 pneumonia 時，病毒可能在**下呼吸道持續複製**而上呼吸道已清除

## 用什麼驗：Recommendation 10–17（Table 6、7）

<div class="orig-fig" data-src="感染科/influenza-originals/table-06.png" data-label="Table 6"></div>

| 檢驗 | 方法 | 時間 | 敏感度 | 特異度 |
| --- | --- | --- | --- | --- |
| **Rapid molecular assay** | NAAT | **15–30 分鐘** | **高（A 92%、B 95%）** | 高（99%） |
| **RT-PCR**、其他 molecular | NAAT | 1–8 小時 | **最高**，可分亞型 | 很高 |
| **Multiplex PCR** | NAAT，同時驗其他病原 | 1–2 小時 | 高 | 高 |
| **RIDT（抗原快篩）** | Antigen | 10–15 分鐘 | **==低到中（約 54%）==**；成人約 54%、兒童約 67%；有判讀儀較高 | 高（99%） |
| Immunofluorescence | Antigen | 1–4 小時 | 中（約 77–80%） | 高 |
| 病毒培養 | Virus isolation | 1–10 天 | 高 | 高 |

| # | 建議 | 分級 |
| --- | --- | --- |
| 10 | **門診：rapid molecular assay 優於 RIDT** | A-II |
| 11 | **住院：RT-PCR 或其他 molecular assay** 優於其他檢驗 | A-II |
| 12 | **住院免疫不全：用 multiplex RT-PCR**（呼吸道病原 panel） | A-III |
| 13 | 住院非免疫不全：會影響處置（分床、減少檢查、減少抗生素）時可考慮 multiplex | B-III |
| 14 | 住院**不要用 immunofluorescence**，除非沒有 molecular；**陰性要用 RT-PCR 確認** | A-II／A-III |
| 15 | **==住院不要用 RIDT==**，除非沒有 molecular；**陰性要用 RT-PCR 確認** | A-II |
| 16 | **不要用病毒培養做初步診斷**（太慢）；群聚時可用來確認 RIDT 陰性、取得病毒株 | A-III／C-II |
| 17 | **不要用血清學**診斷（要間隔 2–3 週的配對血清） | A-III |

### 檢驗結果怎麼解讀（Table 7）

<div class="orig-fig" data-src="感染科/influenza-originals/table-07.png" data-label="Table 7"></div>

| 檢驗 | 結果 | **低流行期**（夏天） | **高流行期**（冬天） |
| --- | --- | --- | --- |
| **RIDT** | **陰性** | NPV 高 → 多為真陰性（發病 < 4 天採檢時）；和群聚有關 → molecular 確認 | **==NPV 低 → 可能偽陰性==**，不能排除；**臨床需要就照樣給抗病毒**；用 molecular 確認 |
| | **陽性** | **PPV 低 → 可能偽陽性**，用 molecular 確認 | PPV 高 → 多為真陽性 |
| **Molecular** | **陰性** | NPV 高 → 很可能真陰性 | 沒有下呼吸道疾病 → 可能真陰性；**住院病人上呼吸道陰性要想到偽陰性**；**插管者送 ETA、BAL** |
| | **陽性** | PPV 較低 → 偽陽性可能 | PPV 高 → 真陽性 |

> [!warning] Pitfall
> - Molecular 陽性只表示**有病毒 RNA**，不代表有活病毒（只有培養能證明）
> - 多數 FDA 核准的檢驗只認可**上呼吸道檢體**，不是痰或下呼吸道檢體——送 ETA、BAL 前確認實驗室能做
