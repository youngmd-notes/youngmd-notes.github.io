> [!abstract] 一句話重點
> - 每個腹瀉病人都要問**詳細病史與暴露史**（strong），並**評估脫水**（strong, high；嬰幼兒與老人最危險）
> - **發燒或血便 → 要找可治療的菌：*Salmonella*、*Shigella*、*Campylobacter***
>   - **發燒＋到過流行區（或吃過流行區來的人做的食物）→ 想 enteric fever**（可以沒有腹瀉）
> - **==疑似 STEC（血便、不太燒、腹痛明顯）→ 要驗 Shiga toxin 並區分 O157==**，它是 **HUS** 的元兇
> - 還要留意**感染後併發症**：GBS（*Campylobacter*）、reactive arthritis、post-infectious IBS

> 本篇來源：2017 IDSA Clinical Practice Guidelines for the Diagnosis and Management of Infectious Diarrhea（Shane AL, et al. *Clin Infect Dis* 2017;65:e45–80）Recommendation 1–7、Table 1–4、Figure 1

## 定義

| 名詞 | 定義 |
| --- | --- |
| **Diarrhea**（WHO） | **24 小時內 ≥ 3 次**稀便或水便，或比平常次數多；成形便次數多不算，喝母奶嬰兒的糊便也不算 |
| **Acute** | **< 7 天**（watery 或 bloody；**dysentery**＝頻繁、量少、帶血與黏液） |
| **Prolonged** | **7–13 天** |
| **Persistent** | **14–29 天** |
| **Chronic** | **≥ 30 天** |

- 美國每年估計 1.79 億次門診、近 50 萬次住院、> 5,000 人死亡；**發生率 < 5 歲最高，但住院與死亡比例 ≥ 65 歲最高**
- 病原：**norovirus 造成最多病例（58%）**，但 ***Salmonella* 造成更多住院（35%）與死亡（28%）**；輪狀病毒疫苗後，norovirus 成為兒童第一名
- 健康成人的急性腹瀉**多半是病毒或原因不明、會自己好** → 通常**不需要檢驗**

## 要問什麼：Recommendation 1–2（Figure 1）

<div class="orig-fig" data-src="感染科/diarrhea-originals/figure-01.png" data-label="Figure 1"></div>

| # | 建議 | 強度 |
| --- | --- | --- |
| 1 | 所有腹瀉病人都要問**詳細的臨床與暴露史**，包括**身邊有沒有人一樣在拉** | Strong, moderate |
| 2 | 在**托兒所、長照機構、醫療照護、餐飲業、游泳池等**工作或就學者，要依當地規定**通報群聚、執行感染管制** | Strong, high |

Figure 1 要問的暴露（依原圖內容重新整理）：**食物或飲水**、**國外旅遊**、**近期抗生素**、**免疫不全**、**動物接觸**、**性行為**（肛交、口肛接觸）、**住院**、**長照機構**、**托兒所**；再依病程分成 acute（< 14 天）、persistent（14–29 天）、chronic（≥ 30 天）。

Table 1 是各種傳播途徑對應的參考指引（旅遊、免疫不全、食媒水媒、抗生素相關 *C. difficile*、醫療照護、托兒所、長照、人畜共通），臨床上用來查詢細節。

| **飯店、郵輪、餐廳、喜宴群聚** | **Norovirus**、non-typhoidal *Salmonella*、*C. perfringens*、*B. cereus*、*S. aureus*、*Campylobacter*、ETEC、STEC、*Listeria*、*Shigella*、*Cyclospora*、*Cryptosporidium* |

| **水果、未殺菌果汁、生菜、芽菜** | **STEC**、*Salmonella*、*Cyclospora*、*Cryptosporidium*、norovirus、hepatitis A、*Listeria* |
| **未熟的蛋** | ***Salmonella***、*Shigella*（蛋沙拉） |
| **生貝類、生蠔** | ***Vibrio***、**norovirus**、hepatitis A、*Plesiomonas* |
| **喝或游未處理的淡水** | *Campylobacter*、*Cryptosporidium*、***Giardia***、*Shigella*、*Salmonella*、STEC、*Plesiomonas* |
| 有消毒的游泳池 | ***Cryptosporidium***（耐氯） |
| **醫院、長照、監獄** | **Norovirus**、***C. difficile***、*Shigella*、*Cryptosporidium*、*Giardia*、STEC、rotavirus |
| **托兒所** | **Rotavirus**、*Cryptosporidium*、*Giardia*、***Shigella***、STEC |
| **近期抗生素** | ***C. difficile***、多重抗藥 *Salmonella* |
| **到資源匱乏國家旅遊** | ***E. coli*（ETEC、EAEC、EIEC）**、*Shigella*、typhoid 與 non-typhoidal *Salmonella*、*Campylobacter*、*V. cholerae*、*E. histolytica*、*Giardia*、*Cyclospora*、*Cryptosporidium* |
| 寵物腹瀉 | *Campylobacter*、*Yersinia* |
| **幼禽、爬蟲類** | **Non-typhoidal *Salmonella*** |
| **農場、可觸摸動物區** | **STEC**、*Cryptosporidium*、*Campylobacter* |
| **年齡** | Rotavirus（6–18 個月）；**NTS（< 3 個月嬰兒、> 50 歲有動脈硬化）**；*Shigella*（1–7 歲）；*Campylobacter*（年輕成人） |
| **免疫不全** | NTS、*Cryptosporidium*、*Campylobacter*、*Shigella*、*Yersinia* |
| **Hemochromatosis、血紅素病變** | ***Y. enterocolitica***、*Salmonella* |
| **AIDS、免疫抑制治療** | *Cryptosporidium*、*Cyclospora*、*Cystoisospora*、microsporidia、**MAC**、**CMV** |
| **肛交、口肛接觸** | *Shigella*、*Salmonella*、*Campylobacter*、***E. histolytica***、*Giardia*、*Cryptosporidium*，以及 STI |

## 發燒或血便：Recommendation 3–4

| # | 建議 | 強度 |
| --- | --- | --- |
| 3 | **發燒或血便** → 找**抗生素可能有幫助**的腸道菌：***Salmonella*、*Shigella*、*Campylobacter*** | Strong, low |
| 4 | **發燒（有無腹瀉都算）**＋**到過流行區**、**吃過剛從流行區回來的人做的食物**，或**實驗室接觸** → 想 **enteric fever**（*S.* Typhi、Paratyphi） | Strong, moderate |

- *S.* Typhi 病人約 **68%**、Paratyphi 約 50% 有旅遊史；**enteric fever 常常沒有腹瀉**

## 嚴重度與併發症：Recommendation 5–7

| # | 建議 | 強度 |
| --- | --- | --- |
| 5 | **所有急性腹瀉都要評估脫水**——脫水會增加致命風險，**嬰幼兒與老人尤其危險** | **Strong, high** |
| 6 | **臨床或流行病學像 STEC** → 用能驗出 **Shiga toxin（或其基因）**、並**區分 O157:H7 與其他 STEC** 的方法；能分 **Stx1 vs Stx2**（Stx2 較毒）更好；***Shigella dysenteriae* type 1** 等也能產 Shiga toxin，**HUS 加上旅遊史**時要想到 | Strong, moderate |
| 7 | 評估**感染後與腸外併發症** | Strong, moderate |

> [!warning] Pitfall：STEC 的樣子
> - **血便、腹痛明顯（腹部壓痛）、但就診時常常不發燒**
> - 約 **65%** O157 病人 WBC > 10,000
> - **約 10% 發生 HUS 的 STEC 病人沒有血便**
> - **腹瀉期給足 IV fluid 可降低後續 HUS 時 oligoanuric renal failure 的風險**；入院時脫水者 HUS 較需要洗腎

### 臨床表現與可能病原（Table 3）

<div class="orig-fig" data-src="感染科/diarrhea-originals/table-03.png" data-label="Table 3"></div>

| 表現 | 可能病原 |
| --- | --- |
| **噁心嘔吐 ≤ 24 小時**（吃完很快發作） | ***S. aureus* enterotoxin**、***B. cereus*（短潛伏期嘔吐型）** |
| **腹瀉＋腹絞痛 1–2 天** | ***C. perfringens*、*B. cereus*（長潛伏期）** |
| **嘔吐＋非血便腹瀉 2–3 天** | **Norovirus**（約 40% 頭 24 小時低燒） |
| **血便** | **STEC、*Shigella*、*Salmonella*、*Campylobacter*、*E. histolytica***、non-cholera *Vibrio*、*Yersinia*、*Balantidium*、*Plesiomonas* |
| **劇烈腹痛＋明顯血便＋不太燒** | **STEC**、*Salmonella*、*Shigella*、*Campylobacter*、*Y. enterocolitica* |
| **持續腹痛＋發燒，像 appendicitis** | ***Y. enterocolitica*、*Y. pseudotuberculosis***（mesenteric adenitis、terminal ileitis） |
| 發燒 | 鑑別力不高；**高燒偏向細菌或 *E. histolytica***；**STEC 通常不燒** |
| **Persistent 或 chronic** | **原蟲**：*Cryptosporidium*、***Giardia***、*Cyclospora*、*Cystoisospora*、*E. histolytica* |
| 慢性水瀉 ≥ 1 年 | Brainerd diarrhea、post-infectious IBS |

### 感染後併發症（Table 4）

<div class="orig-fig" data-src="感染科/diarrhea-originals/table-04.png" data-label="Table 4"></div>

| 併發症 | 病原 |
| --- | --- |
| **HUS** | **STEC、*S. dysenteriae* type 1** |
| **Guillain-Barré syndrome** | ***Campylobacter*** |
| **Reactive arthritis**（含 Reiter） | *Salmonella*、*Shigella*、*Campylobacter*、*Yersinia*（少見 *Giardia*、*Cyclospora*） |
| Erythema nodosum | *Yersinia*、*Campylobacter*、*Salmonella*、*Shigella* |
| Glomerulonephritis | *Shigella*、*Campylobacter*、*Yersinia* |
| **IgA nephropathy** | *Campylobacter* |
| Hemolytic anemia | *Campylobacter*、*Yersinia* |
| **Post-infectious IBS** | *Campylobacter*、*Salmonella*、*Shigella*、STEC、*Giardia*（細菌性腹瀉後 3–10% 成人） |
| Meningitis | *Listeria*、*Salmonella*（**≤ 3 個月嬰兒**高風險） |
| **Intestinal perforation** | *Salmonella*（含 Typhi）、*Shigella*、*Campylobacter*、*Yersinia*、*E. histolytica* |
| Ekiri syndrome（致命中毒性腦病變）、seizure | ***Shigella*** |
| **Aortitis、osteomyelitis、深部感染** | ***Salmonella*、*Yersinia*** |
