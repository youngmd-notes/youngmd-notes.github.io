> [!abstract] 一句話重點
> IE 病人的 AKI 有很多條路：**腎前性（心輸出低、敗血症）、栓塞梗塞、藥物（gentamicin ATN、ceftriaxone AIN）、血紅素／肌紅素、免疫複合體腎絲球腎炎**。作者一步步用**尿液顏色 → 尿沉渣 → CK → 影像 → C3 → 腎切片**收斂：==變形紅血球＋蛋白尿＋低 C3＋IE 復發== → **IE 相關腎絲球腎炎**。治療重點是**治好感染**，而不是免疫抑制。

> [!info] 個案來源
> NEJM Evidence Morning Report〈A 7-Year-Old Boy with Fever and Dark Urine〉，2023，[DOI 10.1056/EVIDmr2300191](https://doi.org/10.1056/EVIDmr2300191)。以下用自己的話整理，重點放在作者的推理過程。

## 個案一覽

- 7 歲男童，東非出生、最近移居美國；**法洛氏四重症** 1 年前修補（VSD 補片、**人工肺動脈瓣**、右心出口與肺動脈擴大）
- 修補後 7 個月：**Aggregatibacter actinomycetemcomitans** 菌血症＋肺動脈瓣贅生物（推測來自**蛀牙**）→ IV ceftriaxone 6 週，治療後血液培養陰性
- 停藥 4 週後：疲倦；兩週間歇低燒（最高 38.3°C）；**一天前尿變深色**、瀰漫性腹部不適

## 推理過程

### Checkpoint 1：病史——三個問題

| 作者問 | 為什麼問 | 答案 | 推理結果 |
| --- | --- | --- | --- |
| 呼吸困難、運動不耐、胸痛、水腫？ | 修補後＋IE → **心衰竭** → 腎灌流不足 | 沒有心臟症狀，但**小腿輕微腫** | 🟠 |
| 排尿痛、頻尿、急尿、失禁？UTI 病史？ | 大男孩 UTI 少見，除非有結構、神經或便秘問題；腰痛 → 腎盂腎炎 | 都沒有，無腰痛 | ⚪ UTI |
| 尿是什麼顏色？整段都深嗎？ | 鮮紅＋血塊 → **下泌尿道**；**深褐（可樂色）→ 腎臟**；也可能是血紅素、肌紅素、膽紅素、紫質；開始時 → 尿道、結束時 → 膀胱頸、**全程 → 腎、膀胱** | ==可樂色、整段都是、沒有血塊== | 🔴 腎臟來源 |

### Checkpoint 2：理學檢查

- **38.1°C、HR 132、RR 32、BP 145/76（收縮壓 > 第 99 百分位）**、SpO₂ 94%
- 原本 3/6 收縮期雜音，==新出現 1/6 早期舒張期雜音==（左上胸骨緣）
- 腹部輕微壓痛、無肝脾腫大、**無 CVA 壓痛**；兩腿微腫；無瘀點皮疹

> **Problem representation**：人工肺動脈瓣 IE 後的男童，兩週發燒疲倦＋可樂色尿＋**高血壓**＋**新雜音**。

### Checkpoint 3：第一輪檢查

| 檢查 | 為什麼做 | 結果 | 推理結果 |
| --- | --- | --- | --- |
| CBC、CRP、ESR | 感染與發炎 | WBC 11.9（嗜中性球 10.67）、Hb 低、**PLT 104**、**CRP 139、ESR 121** | 感染 |
| 白蛋白 | | **1.2** | 很低 |
| **Cr** | 腎功能 | **0.89**（基準 0.37） | ==AKI== |
| 尿液 dipstick | | **heme 陽性** | 紅血球、血紅素或肌紅素 |
| **TTE** | 新雜音 | ==肺動脈瓣 1.4 × 1.2 cm 贅生物＋絲狀突起==、右心稍大、功能稍差 | 🔴 **IE 復發** |

### Checkpoint 4：AKI 的框架——IE 可以從每一條路傷腎

| 類別 | 疾病（**粗體為與 IE 相關**） |
| --- | --- |
| 腎前性 | 脫水、**心輸出下降**、**敗血症血管擴張**、**腎梗塞（septic emboli）** |
| 腎因性—血管 | TMA、ANCA 血管炎、**腎梗塞** |
| 腎因性—腎絲球 | **IE 相關 GN**、鏈球菌後 GN、IgA 腎病變、IgA 血管炎、狼瘡腎炎、ANCA、anti-GBM、C3 腎絲球病變 |
| 腎因性—ATN | 缺血、**敗血症**、腎毒性藥（**gentamicin**、vancomycin）、血紅素／肌紅素／膽紅素管型 |
| 腎因性—AIN | **ceftriaxone**、rifampin、感染、自體免疫 |
| 腎後性 | 結石、血塊、腫瘤、先天或後天阻塞 |

### Checkpoint 5：把 AKI 分型——每一項檢查刪掉一條路

| 檢查 | 為什麼做 | 結果 | 推理結果 |
| --- | --- | --- | --- |
| **尿沉渣** | 分辨腎絲球、ATN、AIN | 紅血球 > 100、**變形紅血球 > 25**、少量透明管型；**無白血球、無 muddy brown 管型** | ❌ AIN、ATN |
| **UPCR** | | **4.6 mg/mg** | 大量蛋白尿 |
| CK | 肌紅素 | 正常 | ❌ 橫紋肌溶解 |
| 腎臟 Doppler 超音波 | 阻塞、血管 | 腎臟**變大、回音增強**，無水腎 | ❌ 腎後性 |
| 顯影 CT | 腎梗塞、septic emboli | 無 | ❌ 栓塞 |

> [!important] 🔀 轉折點：變形紅血球＋蛋白尿
> ==可樂色尿＋變形紅血球＋大量蛋白尿 = 腎絲球腎炎==。小兒腎絲球腎炎依免疫螢光分四類：**免疫複合體型、ANCA、anti-GBM、C3 腎絲球病變**。

### Checkpoint 6：分型與確診

> [!tip] 免疫複合體 GN 用 C3 再分
> **低 C3**：IE 相關 GN、鏈球菌後 GN、狼瘡腎炎、C3 腎絲球病變；**C3 正常**：IgA 腎病變、IgA 血管炎

| 檢查 | 結果 | 推理結果 |
| --- | --- | --- |
| **C3 39、C4 8** | 低 | 免疫複合體或 C3 病變 |
| ASO、anti-DNase B | 陰性 | ❌ 鏈球菌後 |
| ANA、anti-dsDNA | 陰性 | ❌ 狼瘡 |
| MPO、PR3、anti-GBM | 陰性 | ❌ ANCA、anti-GBM |
| LDH 373、haptoglobin 152、**ADAMTS13 46%**、無 schistocyte | | ⚪ TMA、急性溶血 |
| **血液培養 2/2** | ==A. actinomycetemcomitans（同一隻菌）== | ✅ IE 復發 |
| **腎切片** | 瀰漫性**毛細血管內增生性**免疫複合體 GN；IF：**IgG、C1q、C3** 顆粒狀沉積；EM：**繫膜電子緻密沉積** | ✅ **IE 相關 GN** |

## 治療與結果

- 治療核心是**治好感染**：自體瓣 IE 通常 4 週、**人工瓣 6 週**的靜脈抗生素
- 這次採**手術＋藥物**：切除人工肺動脈瓣、換成同種異體瓣（病理為癒合中的 IE、組織培養陰性）＋ IV ceftriaxone 6 週
- 發炎指數下降、血尿與蛋白尿逐漸消失
- 復發原因推測：第一次沒有完全根治，或牙周移生的 HACEK 菌再次感染

## Pearls & Pitfalls

> [!tip] Pearl
> - **IE 相關 GN**：免疫複合體介導；切片多為**新月體性**或**瀰漫增生性**；IF **C3 陽性約 94%**；常**低 C3**
> - 最常見致病菌是 **S. aureus**、**鏈球菌**；抗生素前時代與**亞急性 IE**（如 **HACEK**）較相關
> - **HACEK**：Haemophilus、Aggregatibacter、Cardiobacterium、Eikenella、Kingella（口腔菌、難培養）
> - ==治療靠根治感染==；不是先給免疫抑制

> [!warning] Pitfall
> - IE 病人的 AKI 別直接怪抗生素：**尿沉渣**是分流關鍵（AIN 白血球管型、ATN muddy brown、GN 變形紅血球）
> - 血尿顏色：深褐色不一定是血，**dipstick 陽性要看顯微鏡有沒有紅血球**
> - 蛀牙是 HACEK IE 的來源，**口腔衛生**是預防復發的一部分
