> [!abstract] 一句話重點
> 水腫先分「**容積過多 vs 等容**」，再用 **JVP、BNP、白蛋白、尿蛋白** 一層層定位：心臟（BNP 16 → ⚪）、肝（無門脈高壓）、腎（==尿蛋白 3+、UPCR 5.2、白蛋白低、LDL 303== → **腎病症候群**）。甲狀腺低下（TSH 輕度高、fT4 正常）**解釋不了這麼嚴重的水腫**。胸水是另一條線：**乳白色、三酸甘油脂 > 110** → 乳糜胸。腎切片：**微小變化腎病**。

> [!info] 個案來源
> NEJM Evidence Morning Report〈A 73-Year-Old Man with Shortness of Breath, Edema, and Weight Gain〉，2024，[DOI 10.1056/EVIDmr2300299](https://doi.org/10.1056/EVIDmr2300299)。以下用自己的話整理，重點放在作者的推理過程。

## 個案一覽

- 73 歲退伍軍人；腹股溝疝氣修補、PSA 高（BPH）
- 一個月前**雙腳腫**、輕微活動就喘；兩週後腫到**大腿與陰囊**
- 家醫科診斷**甲狀腺低下**，給 levothyroxine＋需要時吃 furosemide；**不吃利尿劑就更腫**
- **兩週胖 14 kg**（86 → 99.8 kg）

## 推理過程

### Checkpoint 1：病史——三個問題

| 作者問 | 為什麼問 | 答案 | 推理結果 |
| --- | --- | --- | --- |
| 胸痛？姿勢性喘（端坐呼吸）？ | 急性喘＋水腫 → **急性心衰竭** | 都沒有 | ⚪ 心衰竭 |
| 酗酒？ | **肝硬化** → 腹水、胸水、水腫 | 很少喝 | ⚪ 肝硬化 |
| 腎臟病、NSAID？ | 腎衰竭、腎病症候群；**NSAID 常被忽略** | 沒有腎病；偶爾吃 ibuprofen、不超量 | 🟠 |

### Checkpoint 2：理學檢查

- **BP 168/93**、SpO₂ 93%
- **右側呼吸音減弱**；==沒有頸靜脈怒張==；無雜音
- 腹部軟、無腹壁靜脈曲張
- **兩腿凹陷性水腫到大腿**

**Problem representation**：最近診斷甲狀腺低下的 73 歲男性，**喘、體重增加、兩腿水腫**，合併**高血壓**與**右側呼吸音減弱**。

| 水腫類型 | 系統 | 疾病 | 此時判斷 |
| --- | --- | --- | --- |
| **容積過多** | 心肺 | 心衰竭、瓣膜疾病、PE | ⚪ JVP 不高 |
| | 腎 | **腎病症候群**、腎炎症候群、急慢性腎衰竭 | 🔴 |
| | 腸胃 | 門脈高壓 | ⚪ |
| **等容** | | 低蛋白血症（蛋白流失腸病、IBD）、淋巴水腫、靜脈功能不全、**甲狀腺低下** | 🟠 |

### Checkpoint 3：第一輪檢查——每一項刪掉一個系統

| 檢查 | 為什麼做 | 結果 | 推理結果 |
| --- | --- | --- | --- |
| ECG、**BNP** | 心衰竭、ACS | 正常、==BNP 16== | ❌ 心衰竭 |
| **TSH、fT4** | 甲狀腺低下（劑量不足或沒吃） | TSH 6.63（兩週前 20.7）、**fT4 正常** | ⚪ 黏液水腫解釋不了 |
| Cr | 腎衰竭 | 正常 | ⚪ |
| **尿液** | 腎病 vs 腎炎 | ==蛋白 3+、潛血 2+== | 蛋白尿 ＞ 血尿 → **腎病症候群** |
| 總蛋白、白蛋白 | | 低 | |
| CXR → **CTA** | PE、肺水腫、積液 | **右側大量**、左側少量肋膜積液；**無 PE** | ❌ PE |
| 下肢 Doppler | 靜脈功能不全 | 正常 | ❌ 靜脈、淋巴水腫 |
| 腸胃症狀 | 蛋白流失腸病、IBD | 沒有 | ⚪ |

### Checkpoint 4：兩條線同時追

| 檢查 | 為什麼做 | 結果 |
| --- | --- | --- |
| **胸腔穿刺** | 滲出 vs 漏出（心衰竭、肝硬化、腎衰竭 → 漏出；腫瘤、肺炎旁 → 滲出） | ==乳白色==；蛋白 0.8、LDH 54、**三酸甘油脂 238**、膽固醇 28；細胞學陰性 |
| **UPCR** | 量化蛋白尿 | **5.2 mg/mg** |
| **LDL** | 腎病症候群會高血脂 | **303** |
| 心臟超音波 | 瓣膜、收縮與舒張功能 | EF 60–65%、舒張功能稍差 |
| 腹部 CT | | 少量腹水、瀰漫皮下水腫 |

> [!important] 🔀 轉折點：兩個診斷同時成立
> 1. **胸水**：Light's criteria 三項都不符 → **漏出液**；但 ==三酸甘油脂 > 110 mg/dL → 乳糜胸==（外觀乳白也支持）。常見原因：外傷、胸腔手術、先天異常、**腫瘤（淋巴瘤）**、感染；少見：主動脈瘤、甲狀腺腫、心衰竭、結節性硬化、**乳糜腹水經橫膈移到胸腔**
> 2. **腎病症候群**：**UPCR > 3**＋低白蛋白＋高血脂＋新發高血壓 ✅

### Checkpoint 5：腎病症候群的原因

| 原因 | 相關 | 檢查 | 結果 |
| --- | --- | --- | --- |
| 微小變化腎病（MCD） | 腫瘤、NSAID、C 肝（干擾素）、免疫檢查點抑制劑 | | |
| FSGS | **HIV** | HIV | （作者列為應驗） |
| 膜性腎病變 | **PLA2R 抗體**（原發）；梅毒、B 肝、SLE、**腫瘤** | PLA2R、B/C 肝、梅毒 | 陰性 |
| 狼瘡 | | ANA、dsDNA、**補體** | 陰性、補體正常 |
| 糖尿病、類澱粉 | | | 無 |

- **腎切片**：==瀰漫性足細胞病變、腎絲球幾乎正常== → ✅ **微小變化腎病**
- **PET-CT** 找隱藏腫瘤（MCD 與乳糜胸都可能來自淋巴瘤）→ 沒有

## 治療與結果

- **類固醇**（MCD）、**bumetanide**（容積過多）、**amlodipine**（高血壓）
- 出院後再入院：**Cr 3.1**、低血氧
- 乳糜胸：**octreotide** 無效；胸管放了又拔掉後迅速再積 → 原本計畫淋巴攝影 → 先做 **doxycycline 化學性肋膜沾黏** → 低血氧改善、Cr 恢復正常；UPCR 5.2 → 1.5
- 乳糜胸原因最後仍不明；罕見情況下腎病症候群可合併**乳糜腹水經橫膈移到胸腔**

## Pearls & Pitfalls

> [!tip] Pearl
> - 水腫第一刀：**容積過多（心、腎、肝）vs 等容（低蛋白、淋巴、靜脈、甲狀腺）**
> - **腎病症候群**：UPCR > 3（或 24h > 3.5 g）、低白蛋白、水腫、高血脂
> - MCD 約占成人腎病症候群 10%；續發原因：**腫瘤（淋巴瘤）、NSAID、免疫檢查點抑制劑**、HCV、HIV、結核
> - ==胸水 TG > 110 mg/dL → 乳糜胸==；可以符合漏出液標準

> [!warning] Pitfall
> - ==輕度 TSH 上升、fT4 正常不能解釋重度水腫==，別讓「甲狀腺低下」的標籤終止思考
> - 新發水腫一定要驗**尿液蛋白**
> - 乳糜胸要積極找**淋巴瘤**等腫瘤
