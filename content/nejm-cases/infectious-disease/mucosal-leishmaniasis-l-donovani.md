> [!abstract] 一句話重點
> 慢性、會侵蝕的鼻部病灶，鑑別分「**感染（寄生蟲、黴菌、分枝桿菌、慢性細菌）／自體免疫（GPA）／腫瘤（NK/T 細胞淋巴瘤）**」。完整的**移民路徑**（蘇丹 → 肯亞，不只是「從東非來」）是關鍵。第一次切片什麼都沒找到時，作者推理：==利什曼病灶裡蟲很少，常要分子檢測== → 潰瘍邊緣再切、送 PCR → **L. donovani**。

> [!info] 個案來源
> NEJM Evidence Morning Report〈A 52-Year-Old Man with a Chronic Nasal Wound〉，2024，[DOI 10.1056/EVIDmr2400089](https://doi.org/10.1056/EVIDmr2400089)。以下用自己的話整理，重點放在作者的推理過程。

## 個案一覽

- 52 歲男性，**20 年前**開始鼻子間歇性癢；**5 年前**無外傷出現小傷口，慢慢變大，最後**侵蝕穿鼻中隔**
- 持續鼻痛、間歇白色分泌物；**頭痛、視力模糊、右耳聽力下降**
- 所有症狀都在東非發生，抵達美國第 2 天就醫
- 無病史、未曾切片；不抽菸、**不用鼻吸古柯鹼**

## 推理過程

### Checkpoint 1：病史——三個問題

| 作者問 | 為什麼問 | 答案 | 推理結果 |
| --- | --- | --- | --- |
| 在哪裡出生？途經哪些國家？ | ==移民史要包含出生地與所有過境國==，不只最後居住地 | **西蘇丹**出生、在**肯亞難民營 10 年**，直飛美國 | 暴露地區確定 |
| 發燒、體重減輕、皮疹、咳血、血尿？ | 體重減輕 → 鼻腔鱗癌、淋巴瘤、**NK/T 細胞淋巴瘤**；結核；咳血血尿 → **GPA** | **盜汗、間歇發燒、2 年瘦 20 kg**；沒有皮疹、咳血、血尿 | 全身性疾病；⚪ GPA |
| 牲畜、化學物、類似症狀的人？ | 甲醛 → 鼻腔腫瘤；牲畜與病媒 → 利什曼、M. ulcerans、痲瘋 | 種蔬菜和果樹、沒有農藥、無牲畜 | ⚪ 化學 |

### Checkpoint 2：理學檢查

- 體重 46 kg、**BMI 15.4**、惡病質
- 前鼻孔 **5 cm 潰瘍，鼻中隔完全不見，延伸到上唇皮膚**；黃膿＋少量出血
- 口腔沒有潰瘍或念珠菌
- **左頸 3 cm 硬、壓痛淋巴結**
- 神經學正常

**Problem representation**：東非移民，**發燒、盜汗、體重減輕＋慢性漸進侵蝕性鼻部病灶＋頸部淋巴結**。

| 類別 | 疾病 | 此時判斷 |
| --- | --- | --- |
| 細菌 | 梅毒、**鼻硬結症（Klebsiella rhinoscleromatis）**、放線菌、壞疽性口炎（noma） | 🟠 |
| 分枝桿菌 | 結核、**痲瘋**、M. ulcerans | 🟠 |
| 黴菌 | Histoplasma、Blastomyces、Cryptococcus、Aspergillus；Mucor（太穩定 → ⚪） | 🟠 |
| **寄生蟲** | **利什曼**（黏膜型 > 90% 在玻利維亞、巴西、**衣索比亞**、秘魯） | 🟠 |
| 自體免疫 | **GPA**、復發性多軟骨炎、sarcoidosis、SLE | 🟠 |
| 腫瘤 | 基底細胞癌、**鱗癌**、Kaposi、鼻腔淋巴瘤、**NK/T 細胞淋巴瘤** | 🔴 體重減輕＋淋巴結 |

> 病程數年、病人穩定 → **不急著經驗性治療黴菌或寄生蟲**；但有膿 → 可治療次發性軟組織感染。

### Checkpoint 3：第一輪檢查

| 檢查 | 為什麼做 | 結果 | 推理結果 |
| --- | --- | --- | --- |
| CBC | 血癌、嗜中性球低、嗜酸性球 | 輕度正球性貧血、嗜酸性球 4.7% | ⚪ 血液腫瘤、伺機感染 |
| 腎功能、尿液 | GPA | 正常、無血尿蛋白尿 | ⚪ |
| ANA 1:160（邊緣）、ENA 陰性、**ANCA 陰性** | SLE、小血管炎 | | ⚪ GPA、SLE |
| HIV | 免疫狀態 | 陰性 | ⚪ 伺機感染 |
| 梅毒、Blastomyces、Histoplasma | | 陰性 | ⚪ |
| QuantiFERON、痰 PCR×3、AFB | 結核 | 陰性 | 🟠 肺外結核仍可能 |
| CXR | 結核 | 無空洞 | |
| 臉部 CT | 膿瘍 | 無膿瘍；剩餘鼻組織結節狀增厚、**兩側頸部淋巴結壞死樣** | |
| 腦 MRI | 頭痛、視力、聽力 → 顱內侵犯？ | 無眼眶或顱內病灶 | |
| **鼻底切片** | 腫瘤、肉芽腫、病原 | **肉芽組織＋急慢性發炎**；無癌、無壞死、無成形肉芽腫（只有少數多核巨細胞）；AFB、GMS 陰性；**流式細胞儀正常** | ⚪ 癌、淋巴瘤 |
| 鼻組織培養 | | 少量 S. aureus、C. glabrata | 移生或次發感染 |

> [!important] 🔀 轉折點：什麼都陰性 → 想到「蟲很少」的病
> 第一輪檢查讓很多病下降，但**沒有一個答案**。作者的推理：
> - 剩下的感染裡，==利什曼病是寡寄生蟲（pauciparasitic），組織上很難看到蟲體，常需要分子檢測==
> - 下一步：在**潰瘍邊緣**重新切片並送 **Leishmania PCR**、再做 GMS；同時切**壞死頸部淋巴結**（感染、sarcoidosis、轉移性鱗癌）

### Checkpoint 4：確診

| 檢查 | 結果 |
| --- | --- |
| 頸部淋巴結 core biopsy | **非壞死性肉芽腫**；AFB、GMS 陰性 |
| 鼻黏膜邊緣切片 | 急慢性發炎、無壞死或惡性；AFB 陰性；GMS 少量非侵襲性假菌絲；各種培養陰性 |
| 組織學看蟲體 | **沒有看到 amastigote** |
| **Leishmania PCR** | ==L. donovani complex 陽性== ✅（L. donovani／chagasi／infantum）→ 依流行病學判為 **L. donovani** |

## 治療與結果

- 確診 L. donovani 後要找**內臟侵犯**：胸腹骨盆 CT 沒有內臟病灶
- 治療：**IV liposomal amphotericin B＋口服 miltefosine**（參考 WHO 對 HIV 合併內臟利什曼的建議組合，因為菌種與黏膜侵犯範圍廣）

## Pearls & Pitfalls

> [!tip] Pearl
> - 利什曼經**雌性白蛉**叮咬傳播，表現分**內臟、皮膚、皮膚黏膜、黏膜**型，依菌種與地區而定
> - L. donovani 典型造成**內臟利什曼（kala-azar）**，東非（蘇丹、肯亞、衣索比亞）流行；確診後一定要找內臟侵犯
> - ==切片看不到蟲很常見，潰瘍邊緣取樣＋PCR才是診斷關鍵==
> - 慢性侵蝕性鼻部病灶鑑別：**利什曼、鼻硬結症、痲瘋、結核、黴菌、GPA、古柯鹼、NK/T 細胞淋巴瘤、鱗癌**

> [!warning] Pitfall
> - 只問「從哪裡來」不夠，**出生地、過境國、難民營**都要問
> - 第一次切片陰性不要結案：病原量少的疾病（利什曼、結核）需要**重複取樣與分子檢測**
> - 鼻腔培養長出 S. aureus、Candida 多半是移生，不是答案
