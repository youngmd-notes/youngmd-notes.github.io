> [!abstract] 一句話重點
> 這個個案的主軸是**電解質推理**：==hypokalemia（1.5）＋metabolic alkalosis（HCO₃⁻ 47）＋hypertension＋edema== → 「**容積擴張型**」鹼中毒 → 驗腎素與醛固酮：**醛固酮低、腎素正常** → 不是 primary aldosteronism → 皮質醇過多活化礦物皮質素受體 → **ACTH 306** → 腦下垂體 MRI 正常、**右肺門大腫塊** → 肺神經內分泌癌異位分泌 ACTH。

> [!info] 個案來源
> NEJM Evidence Morning Report〈A 72-Year-Old Woman with Fatigue and Shortness of Breath〉，2023，[DOI 10.1056/EVIDmr2300084](https://doi.org/10.1056/EVIDmr2300084)。以下用自己的話整理，重點放在作者的推理過程。

## 個案一覽

- 72 歲女性，第 2 型糖尿病、COPD、hypertension（**hydrochlorothiazide**，5 年前加倍）
- **抽菸 40 pack-years**（10 年前戒）；從沒做過 colonoscopy 或肺癌篩檢
- 3 週越來越**疲倦、活動喘**、**兩腿腫**、**不自主瘦 5 kg**

## 推理過程

### Checkpoint 1：病史——三個問題

| 作者問 | 為什麼問 | 答案 | 推理結果 |
| --- | --- | --- | --- |
| 胸痛、端坐呼吸、心悸、頭暈？ | 先排除需要緊急處理的 heart failure、ACS、心律不整、PE | 都沒有 | ⚪ 急性心肺 |
| 癌症篩檢？ | 年紀＋抽菸＋weight loss → 惡性；腫瘤常以非特異症狀表現 | 子宮頸、乳房有篩；**沒做過 colonoscopy 與肺癌篩檢** | 🟠 惡性 |
| 最近換藥？ | 藥物影響容積、血球、電解質 | HCTZ 5 年前加倍後沒變 | ⚪ 利尿劑（劑量穩定） |

### Checkpoint 2：理學檢查與第一輪檢查

- **BP 147/88**、BMI 32
- **JVP 8 cm、腹頸靜脈回流陽性**、兩肺底 crackles、**兩腿 pitting edema**
- ==proximal muscle weakness（股四頭肌最明顯）==

| 檢查 | 結果 | 推理結果 |
| --- | --- | --- |
| **K** | ==1.5== | 嚴重 hypokalemia |
| **HCO₃⁻** | ==47==、靜脈 pH **7.68**、pCO₂ 40 | 嚴重 metabolic alkalosis |
| 血糖 | 219 | |
| WBC | 20.06 | |
| 肝功能 | 肝細胞＋cholestasis 混合型損傷 | 肝臟受侵犯？ |
| **CXR** | ==右肺門變大==、少量右 pleural effusion | 腫瘤？ |
| ECG | 竇性、無 ST-T 變化 | |

### Checkpoint 3：metabolic alkalosis＋hypokalemia 的框架

| 容積狀態 | 有無 hypertension | 疾病 |
| --- | --- | --- |
| **容積不足** | | 嘔吐、失氯性腹瀉、瀉劑 |
| **容積擴張** | **有 hypertension** | **primary aldosteronism**、**分泌腎素的腫瘤**、==Cushing／異位 ACTH==、Liddle、長期吃甘草 |
| | 無 hypertension | 近期利尿劑、Bartter、Gitelman |

這位：**hypertension＋edema＋JVP 高 → 容積擴張＋hypertension**那一欄
- 沒有嘔吐腹瀉 → ⚪ 容積不足型
- HCTZ 劑量 5 年沒變 → ⚪ 利尿劑
- Liddle 很少這麼晚才發病 → ⚪
- 甘草要問

> [!tip] 把 CXR 和電解質連起來
> 抽菸 40 pack-years＋**右肺門變大** → 可能有**隱藏腫瘤**分泌異位荷爾蒙：**ACTH、CRH、腎素**都可以造成 hypertension＋鹼中毒＋hypokalemia。
> **異位 ACTH 的 hypokalemia 比其他 Cushing 更常見**：皮質醇太多，腎臟 **11β-HSD2** 來不及把它轉成 cortisone，多出來的皮質醇就去活化礦物皮質素受體。

### Checkpoint 4：用尿液與荷爾蒙分型

| 檢查 | 為什麼做 | 結果 | 推理結果 |
| --- | --- | --- | --- |
| **尿 Cl⁻** | **> 20 → 容積擴張、氯鹽無效**；< 20 → 容積不足 | **70** | 容積擴張型 |
| **尿 K⁺/Cr** | **> 13 mEq/g → 腎臟漏鉀** | **124** | 腎臟漏鉀 |
| **血漿醛固酮、24 小時尿醛固酮** | primary aldosteronism | ==醛固酮 < 4（低）、尿醛固酮 < 0.2（低）== | ❌ primary aldosteronism |
| **血漿腎素** | 腎素腫瘤 | 3.5（正常） | ❌ 腎素腫瘤 |
| 甘草、steroid（口服、注射、外用、吸入）、瀉劑 | 外源性 | 都沒有 | ❌ |
| **24 小時尿游離皮質醇** | Cushing 篩檢 | **5,655 µg**（10–100） | 🔴 |
| **午夜唾液皮質醇** | 第二項篩檢確認 | **31,700 ng/dL** | ✅ 高皮質醇症 |
| 早上皮質醇 | 不是篩檢工具，但極高時有指引價值 | 135.7 | |

> [!important] 🔀 轉折點：醛固酮低，皮質醇極高
> 礦物皮質素過多的表現（hypertension、鹼中毒、hypokalemia）**卻沒有醛固酮** → 有別的東西在活化礦物皮質素受體 → ==皮質醇過量== → 確認 Cushing 症候群。

### Checkpoint 5：ACTH 依賴？來源在哪？

| 檢查 | 為什麼做 | 結果 | 推理結果 |
| --- | --- | --- | --- |
| **ACTH** | 依賴 vs 非依賴（腎上腺） | ==306 pg/mL（10–60）== | ACTH 依賴 |
| 腦下垂體 MRI | Cushing's disease | **沒有病灶** | ⚪ 腦下垂體 |
| **高劑量（8 mg）dexamethasone 抑制** | 腦下垂體腺瘤通常可部分抑制；**異位不行** | 抑制後皮質醇仍 141 | 支持**異位** |
| **胸部 CT** | 肺門 | **右肺門大腫塊包住右肺動脈遠端**、少量積液 | 原發灶 |
| **PET** | 分期 | 右肺門、**肝、脾、左鎖骨**大量攝取 | 廣泛轉移 |
| 肺門與肝臟 biopsy | | **低分化神經內分泌癌**（ACTH IHC 陰性） | ✅ |

> ACTH 染色陰性可能是**取樣沒取到**分泌 ACTH 的區域，或每單位腫瘤分泌量低、但整體腫瘤負荷大到足以造成症狀。

## 治療與結果

- **Metyrapone**（抑制 11β-hydroxylase）＋**spironolactone**（阻斷皮質醇在礦物皮質素受體的作用）；選 metyrapone 是因為其他藥（ketoconazole 類）可能加重肝損傷
- 4 天後早上皮質醇 141 → 11.9；預防 adrenal insufficiency 加 **hydrocortisone**（**block-and-replace**）
- 腫瘤治療：**dexamethasone＋durvalumab＋etoposide＋carboplatin** → ACTH 兩天內快速下降
- 出院時 K 4.4、HCO₃⁻ 26
- 若腫瘤無法短期控制，**雙側腎上腺切除**是較確定的選擇

## Pearls & Pitfalls

> [!tip] Pearl
> - Metabolic alkalosis 先看**尿 Cl⁻**：< 20 容積不足（氯鹽有效）；**> 20 容積擴張或腎臟原因**
> - Hypokalemia 看腎臟有沒有漏：**尿 K/Cr > 13 mEq/g** 代表腎臟流失
> - Hypertension＋hypokalemia＋鹼中毒，**醛固酮低**時想：**Cushing（尤其異位 ACTH）**、甘草（抑制 11β-HSD2）、Liddle、CAH
> - Cushing 篩檢：**24 小時尿游離皮質醇、午夜唾液皮質醇、1 mg 隔夜 dexamethasone**，需兩項陽性
> - 異位 ACTH 來源：現今**神經內分泌／類癌腫瘤 30–40%** 最多，其次 **SCLC 15%**、胸腺腫瘤 10%

> [!warning] Pitfall
> - 吃 thiazide 的人 hypokalemia 不要全怪利尿劑：==K 1.5、HCO₃⁻ 47 太嚴重==
> - 單一早上皮質醇不是篩檢工具（受壓力、生理時鐘影響）
> - 用 metyrapone 等抑制劑時要提防**adrenal insufficiency**
