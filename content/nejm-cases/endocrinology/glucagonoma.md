> [!abstract] 一句話重點
> 上腹痛最常見的是 GERD、潰瘍、功能性消化不良，**內視鏡正常就給 PPI 試驗**是合理的；但 ==經驗治療無效== 就必須擴大鑑別。被忽略的線索早就在第一次抽血：**血糖 202**；後來出現**在不同部位反覆出現的皮疹** → CT 找到胰臟腫塊 → Ga-68 PET、切除、免疫染色＋血中升糖素 → **glucagonoma**，皮疹是 **necrolytic migratory erythema**。

> [!info] 個案來源
> NEJM Evidence Morning Report〈A 53-Year-Old Man with Persistent Epigastric Pain〉，2024，[DOI 10.1056/EVIDmr2400027](https://doi.org/10.1056/EVIDmr2400027)。以下用自己的話整理，重點放在作者的推理過程。

## 個案一覽

- 53 歲男性，高血壓、高血脂、**性腺低下（肌注 testosterone）**；曾做痔瘡手術、14 年前肛門膿瘍引流
- 8 週間歇**上腹痛、胸骨後燒灼感**，數分鐘到數小時，和吃東西、活動無關；acetaminophen 幾乎無效、越來越痛
- 無吞嚥困難、嘔吐、腹脹、早飽、排便改變、**體重減輕**
- 戒菸 3 年（15 pack-years），每週有氧運動 4 次

## 推理過程

### Checkpoint 1：病史——三個問題

| 作者問 | 為什麼問 | 答案 | 推理結果 |
| --- | --- | --- | --- |
| 血便？ | 潰瘍、胃炎出血；**肛門膿瘍病史 → IBD？** | 糞便正常 | ⚪ 出血、IBD |
| 胸痛、心悸？ | 高血壓、高血脂、抽菸 → **冠心症、主動脈瘤、心包膜炎**可表現為上腹痛 | 沒有 | 🟠 仍要檢查 |
| 用藥前有新藥？ | **NSAIDs**、鉀片 → 胃炎、潰瘍 | 沒有 | ⚪ 藥物性 |

### Checkpoint 2：理學檢查

- BMI 24；生命徵象大致正常
- **腹部完全正常**（軟、不脹、無壓痛）；無頸靜脈怒張、無水腫

| 類別 | 疾病 | 此時判斷 |
| --- | --- | --- |
| 腸胃 | **GERD**、裂孔疝氣、胃炎、**消化性潰瘍**、**功能性消化不良**、胃輕癱、藥物 | 🔴 |
| 血管 | 缺血性腸病、**median arcuate ligament** 壓迫腹腔幹 | 🟠 |
| 胰臟 | 慢性胰臟炎 | 🟠 |
| 浸潤 | sarcoidosis 等 | ⚪ |
| 腫瘤 | 淋巴瘤、胃、肝、**胰臟**癌（警示症狀：體重減輕、吞嚥痛、頑固嘔吐） | ⚪ 沒有警示症狀 |
| 心臟 | 冠心症、主動脈瘤、心包膜炎（橫膈神經共同支配 → 上腹痛） | 🟠 |

### Checkpoint 3：第一線檢查

| 檢查 | 為什麼做 | 結果 | 推理結果 |
| --- | --- | --- | --- |
| CBC | 出血性潰瘍、腫瘤 | 無貧血 | |
| **尿素呼氣試驗** | H. pylori | 陰性 | ⚪ 潰瘍 |
| Lipase | 胰臟炎 | 24（正常） | ⚪ |
| **上消化道內視鏡** | GERD、潰瘍、胃炎 | 食道、胃、十二指腸都正常 | ❌ 糜爛性疾病 |
| ECG、心臟超音波 | 缺血、心包膜炎 | 正常 | ❌ 心臟 |
| ==血糖== | | **202 mg/dL** | 先放著：可能造成胃輕癱，但沒有腹脹早飽 |

→ 沒有浸潤性疾病的其他器官表現、沒有腫瘤警示症狀 → 經驗治療**功能性消化不良或非糜爛性逆流**：**PPI 約 2 個月**

### Checkpoint 4：轉折點

- PPI 兩個月，**症狀持續**
- 新症狀：==在皮膚不同部位間歇出現的皮疹==；檢查兩腿有**色素沉著斑**
- 胸腹骨盆 CT：**胰臟體部遠端後側 1.6 cm 實心腫塊**

> [!important] 🔀 轉折點：經驗治療失敗＋高血糖＋遊走性皮疹
> - ==經驗治療失敗本身就是一個檢查結果==：表示診斷可能錯了，要擴大鑑別
> - 把三條看似無關的線索放在一起：**上腹痛＋高血糖＋遊走性皮疹** → 想到**升糖素瘤症候群**
> - 胰臟實心腫塊：
>   - **外分泌腫瘤**（腺癌、腺泡細胞癌）多在**胰頭**
>   - **神經內分泌腫瘤**（insulinoma、gastrinoma、glucagonoma）可在任何地方，但**體部與尾部**較多 → 這顆在體部

### Checkpoint 5：分期與確診

| 檢查 | 為什麼做 | 結果 |
| --- | --- | --- |
| **Ga-68 標記 somatostatin 類似物 PET** | 神經內分泌腫瘤高表現 somatostatin 受體；找轉移 | **單一**胰臟病灶，無其他器官 |
| **遠端半胰切除** | 局部病灶可根治 | 術中肝臟無病灶；淋巴結無腫瘤 |
| 病理 | | 偽腺泡、迴狀、彼此吻合的帶狀結構；細胞一致、無壞死或分裂；有神經周圍侵犯 → **分化良好的胰臟神經內分泌腫瘤** |
| 免疫染色 | 神經內分泌來源＋分泌哪種荷爾蒙 | **chromogranin、synaptophysin、glucagon 強陽性**；insulin、somatostatin、gastrin 陰性；**Ki-67 < 1%** |
| 血中荷爾蒙 | 是否為功能性 | ==glucagon 319 ng/L（正常 < 200）==；insulin、serotonin 正常 |

→ ✅ **Glucagonoma**；皮疹為 **necrolytic migratory erythema**

## 治療與結果

- 手術切除（局部病灶的最佳根治方式）
- 術後**空腹血糖很快恢復正常**，上腹痛與皮疹消失
- 用**空腹血糖**監測是否殘留或復發；持續影像追蹤（常見轉移到肝）

## Pearls & Pitfalls

> [!tip] Pearl
> - **Glucagonoma 症候群**（胰島 α 細胞）：==necrolytic migratory erythema、糖尿病、體重減輕==、上腹痛、腹瀉、口角炎、舌炎、貧血、**靜脈血栓**、神經精神症狀
> - **Necrolytic migratory erythema**：紅色、起水泡、脫屑的斑塊，**在不同部位反覆出現**，癒合後留下色素沉著
> - 胰臟神經內分泌腫瘤診斷：**chromogranin、synaptophysin＋特定荷爾蒙染色＋血中荷爾蒙**；**Ki-67** 判斷侵襲性
> - **Ga-68 DOTATATE PET** 對 somatostatin 受體陽性腫瘤的分期很好用

> [!warning] Pitfall
> - 不要只看主訴相關的檢驗：==不明原因的新高血糖==也是線索
> - PPI 試驗無效時，不要只是換藥或加量，要**重新思考診斷**
> - Glucagonoma 長得慢，就醫時常已有**肝轉移**
