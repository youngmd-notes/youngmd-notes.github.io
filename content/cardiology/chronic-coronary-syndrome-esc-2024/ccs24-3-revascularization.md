> [!abstract] 一句話重點
> 再通有兩個目的：**改善症狀**（GDMT 仍有心絞痛 → 再通功能顯著的狹窄，I A）與**改善預後**。**LVEF > 35%**：**顯著 LM 狹窄**、**三條血管**、**含近端 LAD 的一或兩條** → **再通＋GDMT**（I）。**LVEF ≤ 35%＋多條血管、可開刀 → CABG 優於藥物（I B）**。選 PCI 或 CABG：**LM 低手術風險 → CABG 為首選（I A）**，**LM 且 SYNTAX ≤ 22 → PCI 可替代（I A）**、**23–32 → IIa**；**多條血管＋糖尿病 → CABG（I A）**；**三條血管、無 DM、低到中複雜度 → PCI 可替代（I A）**。複雜病例找 **Heart Team**；PCI 用 **IVUS／OCT**（複雜病灶 I A）與 **FFR/iFR** 選病灶。

## 什麼時候要再通（Recommendation Table 22）

> [!tip] ISCHEMIA 之後的觀念
> ISCHEMIA 試驗（中重度缺血、LVEF ≥ 35%）5 年主要終點沒差，但**藥物組自發性 MI 較多**；**延長追蹤 7 年（ISCHEMIA-EXTEND）侵入策略的 CV 死亡少 2.2%**，**多條血管病變最明顯**，但非心臟死亡多 1.2%，總死亡沒差。加上統合分析：**再通減少自發性 MI 與心臟死亡，追蹤越久越明顯**。

### 改善預後

| 建議 | 等級 |
| --- | --- |
| **==LVEF > 35%＋功能顯著的 LM 狹窄 → 再通（改善存活）==** | **I A** |
| **==LVEF > 35%＋功能顯著的三條血管病變 → 再通（長期存活、CV 死亡、自發性 MI）==** | **I A** |
| **LVEF > 35%＋含近端 LAD 的一或兩條血管 → 再通（CV 死亡、自發性 MI）** | **I B** |
| **LVEF ≤ 35%**：再通或只用藥，**由 Heart Team** 評估解剖、CAD 與 LV 功能不良的關聯、共病、餘命、病人觀點後決定 | I C |
| **==LVEF ≤ 35%＋多條血管、可開刀 → CABG 優於只用藥（長期存活）==** | **I B** |
| LVEF ≤ 35%、高手術風險或不能開 → PCI 替代 CABG | IIb B |

### 改善症狀

| 建議 | 等級 |
| --- | --- |
| **GDMT 下仍有心絞痛 → 再通功能顯著的阻塞性 CAD** | **I A** |

### 決策過程

| 建議 | 等級 |
| --- | --- |
| 再通前**完整告知好處、風險、後果與替代方案**，共同決策 | I C |
| **複雜病例**（尤其 CABG 與 PCI 等級相同時）→ **Heart Team** 討論 | I C |
| Heart Team 的建議用病人聽得懂的話**平衡地**說明；決策以病人為中心 | I C |
| **STS score** 估 CABG 院內併發症與 30 天死亡 | I B |
| **多條血管 → SYNTAX score 評估解剖複雜度** | I B |
| **複雜病灶 PCI（LM、真分叉、長病灶）→ IVUS 或 OCT 引導** | **I A** |
| **多條血管 → FFR、iFR 或 QFR 選擇要處理的病灶** | **I A** |
| PCI 結束時做壓力測量，找出持續心絞痛與事件高風險者 | IIa B |

## PCI 還是 CABG（Recommendation Table 23）

| 解剖 | 建議 | 等級 |
| --- | --- | --- |
| **LM（低手術風險）** | **==CABG 優於只用藥（存活）==** | **I A** |
| | **==CABG 是整體首選==**（自發性 MI、重複再通較少） | **I A** |
| | **低複雜度（SYNTAX ≤ 22）**、PCI 能達到同等完全再通 → **PCI 可替代**（較不侵入、存活不劣） | **I A** |
| | **中複雜度（SYNTAX 23–32）** → PCI 可考慮 | **IIa A**（升級） |
| | 高手術風險 → PCI 優於只用藥 | IIb B |
| **LM＋多條血管** | 低手術風險、解剖適合 → CABG 優於只用藥 | I A |
| | 手術風險極高 → PCI 優於只用藥 | IIa B |
| **==多條血管＋糖尿病==** | GDMT 反應不足 → **CABG 優於只用藥和 PCI** | **I A** |
| **三條血管、無 DM、LVEF 正常** | GDMT 反應不足 → **CABG 優於只用藥** | I A |
| | **低到中複雜度**、PCI 能達到同等完全再通 → **PCI** | I A |
| **一或兩條含近端 LAD** | GDMT 反應不足 → **CABG 或 PCI 優於只用藥** | I A |
| | 複雜、不適合 PCI → **CABG 優於 PCI** | I B |
| **一或兩條不含近端 LAD** | 有症狀、GDMT 反應不足 → **PCI** | I B |
| | 不適合 PCI → CABG | IIb C |

- **SYNTAX 分級：0–22 低、23–32 中、≥ 33 高**；分數越高越偏向 CABG
- 舊版（2018）寫的「**LM 且 SYNTAX ≥ 33 不做 PCI（III B）**」「**DM＋三條血管且 SYNTAX > 22 不做 PCI（III A）**」，2024 改寫成上表的正向建議

### LM 病變 PCI vs CABG 的試驗（Table 9 依內容重新整理）

| 試驗 | 族群 | 主要終點 | 結果 |
| --- | --- | --- | --- |
| **PRECOMBAT** | 600 位新診斷 LM（穩定、不穩定、無症狀缺血、NSTEMI） | 死亡、MI、中風、目標血管再通 | 1 年 8.7% vs 6.7%（非劣）；2 年、5 年、11.3 年都沒有顯著差異 |
| **SYNTAX（LM 次群體）** | 1,800 位新三條血管（1,095）或 LM（795） | 死亡、中風、MI、重複再通 | 1、3、5 年 PCI 與 CABG 相近；**10 年全死因 27% vs 28%** |
| **NOBLE** | 1,201 位 LM（穩定、不穩定、NSTEMI） | 非手術相關 MI、重複再通、中風、全死因 | **3.1 年 28% vs 18%、4.9 年 28% vs 19%：CABG 較好**（主要是 MI 與重複再通） |
| **EXCEL** | 1,905 位低到中複雜度 LM（SYNTAX ≤ 32） | 死亡、中風、MI | 3 年 15.4% vs 14.7%（非劣）；5 年 22.0% vs 19.2%（無顯著差異） |

- 結論：**低到中複雜度 LM → PCI 存活不劣於 CABG**，但 **CABG 的 MI 與重複再通較少** → CABG 仍是整體首選，PCI 是合理替代

## CCS 合併慢性 HF（Recommendation Table 24）

### HF 病人怎麼找 CAD

| 建議 | 等級 |
| --- | --- |
| **==LVEF ≤ 35% 懷疑阻塞性 CAD → ICA==**，目標是 **CABG 改善預後** | **I B** |
| LVEF > 35%、可能性 > 5–50% → CCTA 或功能影像 | I C |
| LVEF > 35%、可能性 > 85% → ICA（需要時 FFR、iFR、QFR） | I C |
| HFpEF＋心絞痛、冠狀動脈正常或非阻塞 → PET、CMR 灌流或侵入性功能檢查找**微血管功能不良** | IIa B |
| HFrEF 做高風險複雜 PCI → 有經驗的中心可用 microaxial flow pump | IIb C |

### CCS 病人怎麼治 HF

| 建議 | 等級 |
| --- | --- |
| 加入多專科 HF 照護計畫 | I A |
| **HFrEF：ACE-I、MRA、SGLT2-I、穩定時 beta-blocker** | **I A** |
| **HFmrEF、HFpEF：SGLT2-I**（dapagliflozin 或 empagliflozin） | I A |
| ACE-I、ARNI 都不耐受 → ARB | I B |
| **Sacubitril/valsartan 取代 ACE-I 或 ARB** | I B |
| 有鬱血 → 利尿劑 | I B |
| **ICD**：缺血性、**NYHA II–III、LVEF ≤ 35%、GDMT ≥ 3 個月**（**MI 40 天內除外**）、預期存活 > 1 年 | I A |
| ICD：從造成血行動力不穩的心室心律不整恢復（**MI 後 < 48 h 發生的除外**） | I A |
| **CRT**：竇律、**LVEF ≤ 35%**、**LBBB＋QRS ≥ 150 ms** | I A |
| 高度 AV block 需要心室起搏的 HFrEF → **CRT 而非 RV pacing**（含 AF） | I A |

> [!info] 🆕 新版指引（2026 ESC Heart Failure Guidelines）
> - **HFmrEF 取消**：**HFrEF＝LVEF < 50%**、HFpEF＝LVEF ≥ 50% → 上表「HFmrEF」的病人改依 HFrEF 治療
> - **MRA 與 SGLT2-I 用於所有有症狀的 HF（不論 LVEF，I A）**；HFpEF 的 MRA 可用 finerenone
> - HFrEF 再加 **beta-blocker＋ACE-I 或 ARNI**（I A）
