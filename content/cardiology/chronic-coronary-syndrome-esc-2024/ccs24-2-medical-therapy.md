> [!abstract] 一句話重點
> 兩條腿走路：<strong>改善症狀（抗心絞痛）</strong>與**改善預後（疾病修飾）**。**抗心絞痛**：**舌下 NTG 隨身（I B）**＋**beta-blocker 和／或 CCB 起始（I B）**，beta-blocker **目標靜止 HR 55–60**；不夠 → **BB＋DHP-CCB（IIa）** 或加 **long-acting nitrate、ranolazine（IIa）**、nicorandil、trimetazidine（IIb）；❌ **ivabradine 不加在 LVEF > 40% 沒有 HF 的人（III）**、❌ **ivabradine＋verapamil／diltiazem（III）**、❌ **nitrate＋PDE5 inhibitor 或 HCM（III）**。**預後**：**aspirin 75–100 mg 終生（或 clopidogrel 75 mg，I A）**；**PCI 後 DAPT（aspirin＋clopidogrel）6 個月**，高出血風險 **1–3 個月**；**高強度 statin，LDL-C < 55 mg/dL 且降 ≥ 50%** → ezetimibe → PCSK9i；**T2DM → SGLT2-I、GLP-1 RA（I A）**；**colchicine 0.5 mg（IIa A）**；有 HTN、DM、HF → **ACE-I（I A）**。

## 生活型態與運動（Recommendation Table 15、Table 7）

| 建議 | 等級 |
| --- | --- |
| 依病人需求討論 CVD 風險與治療好處 | I C |
| **多專科行為介入**幫助健康生活，搭配藥物 | **I A** |
| <strong>以運動為主的多專科計畫（心臟復健）</strong>改善風險、**降低 CV 死亡** | **I A** |
| **每週中強度有氧 150–300 分鐘或高強度 75–150 分鐘**，減少久坐 | I B |
| 居家心臟復健、行動健康介入增加順從 | IIa B |

### 生活型態諮詢的目標（Table 7 依內容重新整理）

| 主題 | 目標 |
| --- | --- |
| **疫苗** | **流感、肺炎鏈球菌**、COVID-19 等 |
| 睡眠 | 治療睡眠呼吸障礙 |
| **性生活** | 穩定且中低強度活動無症狀者風險低；**PDE5 inhibitor 一般安全，但不可與 nitrate 併用**（嚴重低血壓） |
| 心理 | 避免壓力；**憂鬱與焦慮要治療** |
| 環境 | 避免二手菸、噪音、空氣污染 |
| **菸與物質** | 藥物＋行為戒菸；**避免電子菸** |
| **體重** | **BMI 18.5–25**；必要時藥物或手術減重 |
| **血脂** | **LDL-C < 55 mg/dL 且下降 ≥ 50%** |
| **糖尿病** | **HbA1c < 7%** |
| **血壓** | **SBP 120–129 mmHg**（可耐受時） |
| **飲食與酒** | **酒精 < 100 g／週**；地中海飲食；飽和脂肪 < 10% 熱量 |
| 運動 | **每次 30–60 分鐘中強度、每週 > 5 天**；減少久坐 |

## 抗心絞痛藥（Recommendation Table 16、Figure 9）

> [!tip] 觀念轉變
> **沒有證據顯示哪一種抗心絞痛藥比較有效**，也**沒有一種能改善長期預後**（例外：**MI 後 1 年內的 beta-blocker**）。2024 不再硬性分「第一線、第二線」，改成**依病人的 HR、血壓、共病、耐受度與缺血機轉（阻塞、痙攣、微血管）量身選藥**，很多人需要合併。

| 建議 | 等級 |
| --- | --- |
| 依病人特性、共病、併用藥、耐受度、**心絞痛機轉**選藥，也考慮可近性與費用 | I C |
| **==短效 nitrate（舌下 NTG）立即緩解==** | **I B** |
| **==多數 CCS：先用 beta-blocker 和／或 CCB 控制心跳與症狀==** | **I B** |
| 單用 BB 或 CCB 控制不好 → **BB＋DHP-CCB** | IIa B |
| **Long-acting nitrate 或 ranolazine**：BB／CCB 不夠時加上，或特定病人作為起始 | IIa B |
| Long-acting nitrate 要有**無 nitrate 或低 nitrate 的時段**避免耐藥 | IIa B |
| **Ivabradine**：**LVEF < 40%** 且症狀控制不好時加上，或特定病人起始 | IIa B |
| Nicorandil 或 trimetazidine：BB／CCB 不夠時加上 | IIb B |
| 特定病人：BB 或 CCB 合併第二線藥物當起始治療 | IIb B |
| ❌ **Ivabradine 加在 LVEF > 40%、沒有 HF 的 CCS** | **III B** |
| ❌ **Ivabradine＋non-DHP CCB 或其他強效 CYP3A4 抑制劑** | **III B** |
| ❌ **Nitrate 用在 HCM，或與 PDE5 inhibitor 併用** | **III B** |

- **Beta-blocker 用於心絞痛 → 靜止 HR 目標 55–60 bpm**
- **Beta-blocker 改善預後**：MI 後 **LVEF 低**的證據充分；**LVEF > 40% 的無併發症 ACS 後，沒有大型 RCT 支持長期使用**；沒有 MI、LVEF 正常的 CAD 是否有預後好處未知

### 抗心絞痛藥怎麼搭（Figure 9 依內容重新整理）

| 藥物 | 適合誰（藍） | 特定情況可用（灰） | **禁忌（紅）** |
| --- | --- | --- | --- |
| **Beta-blocker** | 阻塞性 CAD、微血管功能不良、**高血壓**、**AF**、**HFrEF** | COPD、PAD、第一型 DM | **Sick sinus syndrome** |
| **DHP-CCB** | 阻塞性 CAD、**血管痙攣性心絞痛**、高血壓 | HFrEF | — |
| **Diltiazem／verapamil** | 阻塞性 CAD、**血管痙攣**、**AF** | — | **Sick sinus、HFrEF** |
| **Nitrate／nicorandil** | 阻塞性 CAD、**血管痙攣** | HFrEF | **HCM** |
| **Ivabradine** | — | **HFrEF** | **Sick sinus** |
| **Ranolazine** | 阻塞性 CAD、微血管功能不良 | — | — |
| **Trimetazidine** | 阻塞性 CAD、微血管功能不良 | — | — |

| 組合 | 評價 |
| --- | --- |
| **BB＋DHP-CCB**、**BB＋nitrate**、**DHP-CCB＋ivabradine**、**DHP-CCB＋diltiazem／verapamil**、**diltiazem／verapamil＋nitrate**、**nitrate＋ivabradine** | **有用的組合**（綠線） |
| **==Ivabradine＋diltiazem／verapamil==** | **不建議**（紅線） |
| BB＋ivabradine（HFrEF）、BB＋diltiazem／verapamil（AF）、DHP-CCB＋nitrate（痙攣） | 作用相似，**特定情況**才合併 |
| Ranolazine、trimetazidine 與其他藥 | 可能的組合 |

- ⚠️ **BB＋verapamil／diltiazem 會加重心跳過慢與 AV block**，只有 AF 控速等特定情況才合併

## 抗血栓治療（Recommendation Table 17、Figure 10–11、Table 8）

### 抗血栓藥作用在哪（Figure 10 依內容重新整理）

| 作用點 | 藥物（口服／**注射**） |
| --- | --- |
| **COX-1 → TxA2** | **Aspirin**（乙醯化 COX-1，阻止 TxA2 生成） |
| **P2Y12 受體（ADP）** | Clopidogrel、prasugrel、ticagrelor；**cangrelor**（注射） |
| **PAR-1（thrombin 受體）** | Vorapaxar |
| **GP IIb/IIIa（血小板聚集）** | **Eptifibatide、tirofiban**（注射） |
| **FXa** | Rivaroxaban、apixaban、edoxaban；**fondaparinux**、**enoxaparin**、**UFH**（注射） |
| **Thrombin** | Dabigatran；**bivalirudin、argatroban**、UFH（注射） |
| **多個凝血因子** | VKA |

<div class="orig-fig" data-src="心臟科/ccs-esc-2024-originals/figure-10.png" data-label="Figure 10"></div>

### 長期抗血栓（沒有 OAC 適應症）

| 建議 | 等級 |
| --- | --- |
| **==MI 或 PCI 後（DAPT 結束後）：aspirin 75–100 mg 終生==** | **I A** |
| **==Clopidogrel 75 mg 是 aspirin 單一治療安全有效的替代==** | **I A**（升級） |
| **CABG 後 aspirin 終生** | I A |
| **沒有 MI、沒做再通，但有顯著阻塞性 CAD → aspirin 終生** | **I B**（升級） |
| PAD 或缺血性中風／TIA → clopidogrel 優於 aspirin | IIb B |
| **高缺血風險、非高出血風險 → aspirin 加第二種抗血栓藥延長治療**（Table 8） | IIa A |
| PCI 後原本用 ticagrelor DAPT、高缺血非高出血 → **ticagrelor 90 mg bid 單一** | IIb C |

### PCI 後（沒有 OAC 適應症）（Figure 11 依內容重新整理）

| 出血與缺血風險 | 前段 | 之後 | 等級 |
| --- | --- | --- | --- |
| **非高出血風險（預設）** | **==Aspirin＋clopidogrel 6 個月==** | aspirin 或 clopidogrel 單一 | **I A** |
| 非高出血、**非高缺血** | DAPT **1–3 個月**即停 | 單一抗血小板 | IIb B |
| 非高出血、**高缺血** | DAPT 6 個月（I）；**高血栓風險支架**可用 **aspirin＋ticagrelor 或 prasugrel 1 個月到 3–6 個月**（IIb） | **延長：aspirin＋clopidogrel、aspirin＋rivaroxaban 2.5 bid、aspirin＋ticagrelor 60 bid、aspirin＋prasugrel**（IIa）；或 **ticagrelor 單一**（IIb） | — |
| **==高出血風險（預設）==** | **DAPT 1–3 個月** | aspirin 或 clopidogrel 單一 | **I A** |

- **高血栓風險支架**：複雜 LM、雙支架分叉、結果不理想、曾有支架血栓、已知 <strong>CYP2C19 loss-of-function（&#42;2、&#42;3）</strong>
- Prasugrel **≥ 75 歲或 < 60 kg → 5 mg**
- 出血風險用 **PRECISE-DAPT 或 ARC-HBR** 評估（I B）

### 延長加強抗血栓的選擇（Table 8 依內容重新整理）

| 藥物（加在 aspirin 上） | 劑量 | 試驗與族群 | NNT／NNH |
| --- | --- | --- | --- |
| **Rivaroxaban** | **2.5 mg bid** | COMPASS：CAD 或症狀性 PAD、高缺血風險 | 77／84 |
| Clopidogrel | 75 mg qd | DAPT trial：MI 後已耐受 DAPT 1 年 | 63／105 |
| Prasugrel | 10 mg qd（< 60 kg 或 ≥ 75 歲 5 mg） | DAPT trial：MI 的 PCI 後耐受 DAPT 1 年 | 63／105 |
| **Ticagrelor** | **60 mg bid**（試驗 60／90） | PEGASUS：MI 後耐受 DAPT 1 年 | 84／81 |

### 需要口服抗凝（OAC）的 CCS

| 建議 | 等級 |
| --- | --- |
| **長期 OAC 適應症 → 單用 OAC（DOAC 較佳）終生**，不必加抗血小板 | **I B** |
| 可用 OAC 時 **DOAC 優於 VKA** | I A |
| PCI 時：**OAC＋clopidogrel＋低劑量 aspirin 起始** | I C |
| **==無併發症 PCI：aspirin ≤ 1 週即停 → OAC＋clopidogrel 6 個月（高缺血 12 個月）→ 只剩 OAC==** | **I A** |
| 高缺血或解剖、手術因素 → aspirin 延長到 1 個月 | IIa B |
| 出血顧慮較大：rivaroxaban 15 mg、dabigatran 110 mg bid（合併抗血小板期間） | IIa B |
| ❌ **Triple therapy 不用 ticagrelor 或 prasugrel** | **III C** |

### CABG 與 PPI

| 建議 | 等級 |
| --- | --- |
| CABG 後**沒有出血顧慮就盡快開始 aspirin** | I B |
| 移植血管阻塞風險高、出血風險低 → CABG 後 DAPT | IIb B |
| **合併抗血栓（抗血小板和／或 OAC）且 GI 出血風險高 → PPI** | **I A** |
| 單一抗血栓時，依 GI 出血風險考慮 PPI | IIa A |

## 降血脂（Recommendation Table 18）

| 建議 | 等級 |
| --- | --- |
| **==LDL-C < 1.4 mmol/L（< 55 mg/dL）且比基準下降 ≥ 50%==** | **I A** |
| **所有 CCS：高強度 statin 用到最高耐受劑量** | **I A** |
| 未達標 → **加 ezetimibe** | I B |
| **Statin 不耐受、ezetimibe 未達標 → 加 bempedoic acid** | I B |
| statin＋ezetimibe 未達標 → **加 PCSK9 inhibitor** | **I A** |
| statin＋ezetimibe 未達標 → bempedoic acid | IIa C |
| 最高耐受 statin 下**再發動脈硬化事件 → LDL-C < 40 mg/dL** | IIb B |

> [!info] 🆕 新版指引（2025 ESC/EAS Dyslipidaemia Focused Update）
> **不能用 statin 的病人，建議使用有心血管結果證據的 non-statin（ezetimibe、PCSK9 mAb、bempedoic acid）單用或合併**來達到 LDL-C 目標（I A）；詳見 [[cardiology/dyslipidemia-esc/lipid-esc-4-drugs|血脂 ④ 降 LDL-C 藥物]]。

## 其他疾病修飾藥物（Recommendation Table 19–21）

| 藥物 | 建議 | 等級 |
| --- | --- | --- |
| **SGLT2-I** | **T2DM＋CCS：有 CV 證據的 SGLT2-I**，不論 HbA1c 與其他降糖藥 | **I A** |
| **GLP-1 RA** | **T2DM＋CCS：有 CV 證據的 GLP-1 RA** | **I A** |
| **Semaglutide** | **沒有 DM、BMI ≥ 27** → 降 CV 死亡、MI、中風 | IIa B |
| **Colchicine** | **動脈硬化性 CAD：低劑量 0.5 mg qd** → 降 MI、中風、再通 | **IIa A** |
| **ACE-I（或 ARB）** | **合併高血壓、糖尿病或 HF** | **I A** |
| | **CV 事件風險極高**的 CCS | IIa A |

- ACE-I 在沒有 HF、非高風險的 CCS **不常規建議**，除非為了血壓目標
