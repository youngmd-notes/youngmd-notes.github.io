> [!abstract] 一句話重點
> 2024 版的核心改變：**RF-CL 估 pre-test likelihood**、**5–50% 首選 CCTA**、**抗心絞痛藥不再分一二線**、**clopidogrel 升為 aspirin 的長期替代（I A）**、**沒 MI 沒再通但有阻塞性 CAD 也要終生 aspirin（I B）**、**LM 中等 SYNTAX 可 PCI（IIa A）**。最常考的「不要做」：**ivabradine 給 LVEF > 40% 沒 HF 的人、ivabradine 併 non-DHP CCB、nitrate 給 HCM 或併 PDE5 inhibitor、三合一抗栓用 ticagrelor／prasugrel、停經後荷爾蒙療法**。

## Table 10：「不要做」清單（全部 Class III）

| 不要做 | 等級 |
| --- | --- |
| 把 SVT（尤其 re-entrant AV tachycardia）時的 ST deviation 當成阻塞性 CAD 的可靠證據 | III-B |
| **Resting ECG 已有 ST depression ≥ 0.1 mV、LBBB 或在吃 digitalis → 做運動心電圖來診斷** | III-C |
| PTL 5–50% 且有 CCTA 或 functional imaging 可用 → 用運動心電圖來排除 CAD | III-C |
| **CCTA 做在影像品質不可能好的人**：eGFR < 30、decompensated HF、廣泛鈣化、心跳快且不規則、嚴重肥胖、無法閉氣 | III-C |
| Cath 時常規對所有血管做 wire-based pressure 評估 | III-A |
| ==Ivabradine 加在 LVEF > 40%、沒有臨床 HF 的 CCS 病人== | III-B |
| ==Ivabradine 合併 non-DHP CCB 或其他強效 CYP3A4 inhibitor== | III-B |
| ==Nitrate 用在 hypertrophic cardiomyopathy，或與 PDE5 inhibitor 併用== | III-B |
| ==三合一抗栓（aspirin＋OAC）裡用 ticagrelor 或 prasugrel== | III-C |
| ==CCS 女性用全身性停經後荷爾蒙療法==（沒有心血管好處，增加血栓） | III-A |

## Table 10：「必做」清單（Class I，依主題）

> 原圖見上方「不要做」清單下的 Table 10 原圖（共 7 頁）。

### 病史、ECG 與抽血

| 必做 | 等級 |
| --- | --- |
| 疑似缺血症狀：詳細問危險因子、病史與症狀特徵（發作、持續、性質、位置、誘發、緩解、時段） | I-C |
| **臨床或 ECG 像 ACS 而不是 CCS → 立刻轉急診**，或重複測 hs-troponin 排除急性心肌損傷 | I-B |
| 所有胸痛的人做 resting 12-lead ECG（除非明顯非心臟原因），最好在發作中或剛結束時 | I-C |
| 所有人抽血：**lipid profile（含 LDL-C）** | I-A |
| CBC（含 Hb）、creatinine＋eGFR、**HbA1c 和／或 fasting glucose** | I-B |
| 至少驗一次 thyroid function | I-B |

### Pre-test likelihood 與基本檢查

| 必做 | 等級 |
| --- | --- |
| ==用 RF-CL 模型估 PTL== | I-B |
| 用其他臨床資料（周邊動脈、resting ECG、resting echo、之前影像看到的血管鈣化）調整 RF-CL 估計值 | I-C |
| Resting TTE：量 LVEF、容積、舒張功能；找 regional wall motion abnormality；找非冠狀動脈心臟病（肥厚、心肌病、瓣膜、心包積液）；評估 RV 與 sPAP | I-B |
| 運動心電圖：選擇性用來評估運動耐受、症狀、心律不整、血壓反應與事件風險（不是用來診斷） | I-C |
| 胸痛又懷疑心律不整 → ambulatory ECG | I-C |

### 非侵入影像

| 必做 | 等級 |
| --- | --- |
| ==PTL 5–50% → CCTA 診斷阻塞性 CAD 並估 MACE 風險== | I-A |
| PTL 5–50%，另一種非侵入檢查做不出結論 → CCTA | I-B |
| ==PTL 15–85% → stress echo== 診斷缺血、估 MACE 風險 | I-B |
| Stress echo 有 ≥ 2 個相鄰節段看不清楚 → 用 microbubble 顯影劑 | I-B |
| Stress echo 用 microbubble 評估心肌灌流，提升準確度與風險分層 | I-B |
| PTL 15–85% → **stress SPECT 或（更好）PET** 灌流：定量缺血／疤痕、估 MACE、PET 可量血流 | I-B |
| 做 PET／SPECT 時，順便從衰減校正用的非顯影 CT 量 CACS | I-B |
| PTL 15–85% → CMR 灌流：定量缺血／疤痕、估 MACE | I-B |

### 選第一個檢查

| 必做 | 等級 |
| --- | --- |
| 依 PTL、會影響檢查表現的病人特性、當地專長與設備選第一個非侵入檢查 | I-C |
| 有症狀且 PTL > 5% → 第一個檢查用 **CCTA 或非侵入 functional imaging** | I-B |
| ==PTL 5–50% 要排除阻塞性 CAD → CCTA 是首選== | I-B |
| PTL 5–50%，functional imaging 做不出結論 → CCTA | I-B |
| CCTA 看到功能意義不明的 CAD 或做不出結論 → functional imaging | I-B |
| 非侵入檢查結論不明 → **ICA（可做侵入性功能評估）** 確認或排除阻塞性 CAD 或 ANOCA／INOCA | I-B |

### 侵入性檢查（ICA）與功能評估

| 必做 | 等級 |
| --- | --- |
| ICA 首選 **radial access** | I-A |
| ICA 時要有 coronary pressure 評估可用，並用來評估中等程度、非 LM 狹窄的功能意義後再決定再通 | I-A |
| PTL **> 85%**、藥物治療無效的嚴重症狀、**低運動量就心絞痛**、和／或事件風險高 → ICA 診斷 | I-C |
| 新發、很像阻塞性 CAD 的症狀且在**低運動量**發生 → 心臟科評估後**直接 ICA**（準備再通） | I-C |
| 中等狹窄用功能評估決定要不要再通：**FFR ≤ 0.80 或 iFR ≤ 0.89** 有意義 | I-A |
| QFR ≤ 0.80 有意義 | I-B |

### 高風險的定義

| 必做 | 等級 |
| --- | --- |
| 先用基本臨床資料分層（年齡、ECG、心絞痛閾值、DM、CKD、LVEF） | I-B |
| 以下任一代表**事件風險高** | I-B |
| ・運動心電圖：**Duke Treadmill Score < −10** | |
| ・SPECT／PET：**缺血面積 ≥ 10% LV** | |
| ・Stress echo：16 節段中 **≥ 3 段**出現 hypokinesia／akinesia | |
| ・Stress CMR：**≥ 2 段**灌流缺損，或 dobutamine 誘發 **≥ 3 段**功能異常 | |
| ・CCTA：**LM ≥ 50%**；**三條 ≥ 70%**；**兩條 ≥ 70% 且含近端 LAD**；或**單條近端 LAD ≥ 70% 且 FFR-CT ≤ 0.8** | |
| ==事件風險高（不論有沒有症狀）→ ICA（必要時加 FFR／iFR）==，以再通改善症狀與預後 | I-A |

### 生活型態

| 必做 | 等級 |
| --- | --- |
| 依個人需求討論心血管風險與治療好處 | I-C |
| 多專科行為介入協助健康生活，搭配藥物 | I-A |
| 多專科運動計畫，改善危險因子、降低心血管死亡 | I-A |
| **有氧運動：每週中強度 150–300 分鐘或高強度 75–150 分鐘**，減少久坐 | I-B |

### 抗心絞痛藥

| 必做 | 等級 |
| --- | --- |
| 依病人特性、共病、併用藥物、耐受度、心絞痛機轉、藥物可近性與價格量身選藥 | I-C |
| **Short-acting nitrate** 立即緩解心絞痛 | I-B |
| ==大多數人起始用 beta-blocker 和／或 CCB== 控制心跳與症狀 | I-B |

### 抗血栓

| 必做 | 等級 |
| --- | --- |
| 曾 MI 或之前 PCI：DAPT 之後 **aspirin 75–100 mg qd 終生** | I-A |
| 曾 MI 或之前 PCI：**clopidogrel 75 mg qd 可取代 aspirin 單一治療** | I-A |
| **CABG 後 aspirin 75–100 mg qd 終生** | I-A |
| 沒 MI、沒再通，但有明顯阻塞性 CAD → aspirin 75–100 mg qd 終生 | I-B |
| ==沒有 OAC 適應症，PCI 放支架後預設 DAPT（aspirin＋clopidogrel）最多 6 個月== | I-A |
| 出血風險高但缺血風險不高 → PCI 後 **1–3 個月**停 DAPT，改單一抗血小板 | I-A |
| 長期需要 OAC：**單用 OAC 終生**（DOAC 優於 VKA，劑量照 AF） | I-B |
| 需要 OAC 的人做 PCI：起始先加低劑量 aspirin（沒在吃就給 loading）＋OAC＋clopidogrel | I-C |
| 可用 OAC 時，**DOAC 優於 VKA**（除非禁忌） | I-A |
| ==需要 OAC 的人做完單純 PCI：aspirin ≤ 1 週就停 → OAC＋clopidogrel（缺血風險不高 6 個月、高 12 個月）→ 之後單用 OAC== | I-A |
| CABG 後只要沒有出血疑慮，盡早開始 aspirin | I-B |
| 合併抗栓（抗血小板和／或 OAC）期間，GI 出血風險高 → **PPI** | I-A |

### 降血脂、降糖藥、ACE-I

| 必做 | 等級 |
| --- | --- |
| ==LDL-C 目標 < 55 mg/dL（1.4 mmol/L）且比基準值降 ≥ 50%== | I-A |
| 所有 CCS 用 **high-intensity statin** 到最大耐受劑量 | I-A |
| 最大耐受 statin 仍未達標 → 加 **ezetimibe** | I-B |
| Statin 不耐受、ezetimibe 仍未達標 → 加 **bempedoic acid** | I-B |
| Statin＋ezetimibe 仍未達標 → 加 **PCSK9 inhibitor** | I-A |
| T2DM＋CCS：有 CV 好處的 **SGLT2 inhibitor**，與 HbA1c、其他降糖藥無關 | I-A |
| T2DM＋CCS：有 CV 好處的 **GLP-1 RA**，與 HbA1c、其他降糖藥無關 | I-A |
| 有高血壓、DM 或 HF 等共病 → **ACE-I（或 ARB）** | I-A |

### 血管再通：決策流程

| 必做 | 等級 |
| --- | --- |
| 再通前完整告知好處、風險、後果與替代方案，共同決策 | I-C |
| 複雜個案（尤其 CABG 與 PCI 建議等級相同）→ **Heart Team** 討論 | I-C |
| 用病人聽得懂的語言平衡說明 Heart Team 的建議 | I-C |
| 再通與方式的決定以病人為中心（偏好、健康識能、文化、社會支持） | I-C |
| Heart Team 訂定院內再通流程 | I-C |
| 複雜 CAD 考慮再通 → 評估手術風險與術後結果 | I-C |
| **STS score** 估 CABG 住院併發症與 30 天死亡率 | I-B |
| 多條血管阻塞 → 算 **SYNTAX score** 評估解剖複雜度 | I-B |
| 複雜病灶（LM、true bifurcation、長病灶）PCI → **IVUS 或 OCT 導引** | I-A |
| 多條血管病變 → **FFR／iFR 或 QFR** 決定要處理哪些病灶 | I-A |
| 依病人特性、解剖、手術因素、LVEF、偏好與預期結果選再通方式 | I-C |

### 血管再通：哪些人要做

| 必做 | 等級 |
| --- | --- |
| LVEF > 35%＋**功能顯著的 LM 狹窄** → 再通（加 GDMT）改善存活 | I-A |
| LVEF > 35%＋**功能顯著的三條血管病變** → 再通改善長期存活、降心血管死亡與自發性 MI | I-A |
| LVEF > 35%＋**功能顯著、含近端 LAD 的單或雙條** → 再通降心血管死亡與自發性 MI | I-B |
| LVEF ≤ 35% → Heart Team 評估解剖、CAD 與 LV 功能的關聯、共病、餘命、利弊與病人觀點後，選再通或單純藥物 | I-C |
| ==可開刀的多條血管 CAD＋LVEF ≤ 35% → CABG 優於單純藥物==（改善長期存活） | I-B |
| GDMT 下仍持續心絞痛 → 對功能顯著的阻塞性 CAD 再通改善症狀 | I-A |

### 血管再通：選 CABG 還是 PCI

| 解剖 | 必做 | 等級 |
| --- | --- | --- |
| **LM**（手術風險低） | CABG 優於單純藥物（改善存活） | I-A |
| **LM**（手術風險低） | ==CABG 整體優於 PCI==（自發性 MI、重做再通較少） | I-A |
| **LM**，SYNTAX ≤ 22 | PCI 能做到和 CABG 一樣完整 → PCI 可替代 CABG | I-A |
| **LM＋多條** | 手術風險低、解剖合適 → CABG 優於單純藥物 | I-A |
| **多條＋DM** | GDMT 反應不足 → ==CABG 優於單純藥物，也優於 PCI== | I-A |
| **三條、無 DM**、LVEF 正常 | GDMT 反應不足 → CABG 優於單純藥物 | I-A |
| **三條、無 DM**、低到中等複雜度 | PCI 能做到同樣完整 → PCI 可做 | I-A |
| **單／雙條含近端 LAD** | GDMT 反應不足 → CABG 或 PCI 都優於單純藥物 | I-A |
| **單／雙條含近端 LAD**、複雜不適合 PCI | CABG 優於 PCI | I-B |
| **單／雙條不含近端 LAD** | 有症狀、GDMT 反應不足 → PCI | I-B |

### CCS 合併心衰竭

| 必做 | 等級 |
| --- | --- |
| HF、LVEF ≤ 35%、懷疑阻塞性 CAD → **ICA**（為了 CABG 改善預後） | I-B |
| HF、LVEF > 35%、PTL 5–50% → CCTA 或 functional imaging | I-C |
| HF、LVEF > 35%、PTL > 85% → ICA（必要時 FFR／iFR／QFR） | I-C |
| 加入多專科 HF 照護計畫 | I-A |
| HFrEF：**ACE-I、MRA、SGLT2-I（dapagliflozin 或 empagliflozin）、穩定時 beta-blocker** | I-A |
| HFmrEF 或 HFpEF：**SGLT2-I** | I-A |
| HFrEF 不耐受 ACE-I 或 ARNI → ARB | I-B |
| HFrEF：**sacubitril/valsartan 取代 ACE-I 或 ARB** | I-B |
| 有充血 → 利尿劑 | I-B |
| ICD：缺血性 HF、NYHA II–III、GDMT ≥ 3 個月後 LVEF 仍 ≤ 35%、預期存活 > 1 年（MI 後 40 天內除外） | I-A |
| ICD：從造成血行不穩的心室心律不整恢復、預期存活 > 1 年（可逆原因或 MI 後 48 小時內發生除外） | I-A |
| CRT：竇性心律、LVEF ≤ 35%、**QRS ≥ 150 ms 且 LBBB** | I-A |
| HFrEF 因高度 AV block 需要心室起搏 → **CRT 而不是 RV pacing**（含 AF） | I-A |

### ANOCA／INOCA 與血管痙攣

| 必做 | 等級 |
| --- | --- |
| 治療下仍有症狀、懷疑 ANOCA／INOCA、生活品質差 → **侵入性冠狀動脈功能檢查**找 endotype | I-B |
| 懷疑血管痙攣 → 心絞痛發作時做 12-lead ECG | I-C |
| 懷疑血管痙攣、反覆休息時心絞痛併 ST 變化（nitrate 或 CCB 可緩解）→ 侵入性功能性血管攝影確診並評估動脈硬化程度 | I-C |
| ==單純血管痙攣性心絞痛 → CCB== 控制症狀、預防缺血與致命併發症 | I-A |

### 特殊族群、篩檢、順從性

| 必做 | 等級 |
| --- | --- |
| ≥ 75 歲：特別注意藥物副作用、不耐受、交互作用、過量與手術併發症 | I-C |
| 老人和年輕人一樣，依症狀、缺血範圍、衰弱、餘命、共病與偏好決定檢查與再通 | I-C |
| 女性和男性一樣給 GDMT 預防治療 | I-C |
| 出血風險用 **PRECISE-DAPT、ARC-HBR** 或其他驗證工具評估 | I-B |
| **HIV：注意抗病毒藥與 statin 的交互作用** | I-B |
| 努力讓所有 CCS（尤其社經地位低者）得到照護，並讓代表性不足的族群納入試驗 | I-C |
| 健康人機會性篩檢危險因子，用 **SCORE2／SCORE2-OP** 估風險 | I-C |
| 行動健康介入（簡訊、App、穿戴裝置）提升順從性 | I-A |
| 行為介入 | I-B |
| **簡化用藥（fixed-dose combination）** | I-B |
| 多專業與家屬參與 | I-C |

### 追蹤、再通失敗、難治心絞痛

| 必做 | 等級 |
| --- | --- |
| 不論症狀，**定期（例如每年）回診**評估危險因子控制與病情變化 | I-C |
| LV 收縮功能變差且找不到可逆原因 → 重新評估 CAD | I-C |
| 新出現或惡化的症狀 → 風險分層，**首選 stress imaging** | I-C |
| 藥物治療無效或事件風險高 → ICA（必要時 FFR／iFR） | I-C |
| **DES 內再狹窄 → 用 DES**，優於藥物塗層氣球 | I-A |
| 重做 CABG → 之前沒用過的話，**LIMA** 是首選 | I-B |
| 難治心絞痛、生活品質差、懷疑 ANOCA／INOCA → 侵入性功能檢查找 endotype | I-B |

### 藥物、檢查、篩檢

| 主題 | 舊版 | 2024 版 | 變化 |
| --- | --- | --- | --- |
| **抗心絞痛藥** | Nicorandil、ranolazine、ivabradine、trimetazidine 當**第二線**（IIa-B）；特定病人 BB／CCB 加第二線藥當第一線（IIb-B） | **Long-acting nitrate 或 ranolazine**：BB／CCB 控制不佳時加上，或特定病人起始就用（**IIa-B**）；**nicorandil、trimetazidine** 同樣情境（IIb-B） | ==不再分第一線、第二線== |
| Aspirin（曾 MI 或再通） | Aspirin 75–100 mg（I-A） | 曾 MI 或之前 PCI：**先 DAPT，之後 aspirin 終生**（I-A） | 措辭更明確 |
| **Clopidogrel 長期** | Aspirin 不耐受才用（I-B）；PAD 或中風／TIA 可優先（IIb-B） | 曾 MI 或之前 PCI：**可取代 aspirin 單一治療**（**I-A**） | ==不需 aspirin 不耐受，證據升為 A== |
| **沒 MI、沒再通的 CAD** | 影像確定有 CAD → aspirin 可考慮（IIb-C） | **明顯阻塞性 CAD → aspirin 終生**（**I-B**） | ==IIb → I== |
| PCI 後 DAPT（無 OAC） | 放支架後 aspirin（I-A）＋clopidogrel 6 個月（I-A）；出血風險較高 3 個月（IIa-A）；極高 1 個月（IIb-C） | **DAPT 最多 6 個月為預設**（I-A）；**出血風險高、缺血風險不高 → 1–3 個月**停（**I-A**）；都不高也可 1–3 個月停（IIb-B） | 短 DAPT 升為 I |
| **長期 OAC** | AF 用 OAC 時 NOAC 優於 VKA（I-A）；CHA₂DS₂-VASc 門檻（I-A／IIa-B）；MI 後高缺血風險可在 OAC 上加 aspirin 或 clopidogrel（IIb-B） | 長期需 OAC 的 CCS：**單用 OAC 終生**，DOAC 優先（I-B） | ==不再建議 OAC 上長期加抗血小板== |
| **OAC＋PCI** | 早停 aspirin（≤ 1 週）可考慮（IIa-B）；三合一 ≥ 1 個月、最長 6 個月（IIa-C） | **Aspirin ≤ 1 週停 → OAC＋clopidogrel 6 或 12 個月 → 單用 OAC**（**I-A**）；血栓風險高可延到 1 個月（IIa-B） | ==IIa → I，三合一縮短== |
| Statin | 所有 CCS 用 statin（I-A） | **High-intensity statin 到最大耐受劑量**以達 LDL-C 目標（I-A） | 強調高強度 |
| **ANOCA 侵入檢查** | 持續症狀、血管正常或 FFR 正常 → guidewire 量 CFR／微循環阻力（IIa-B）；acetylcholine 試驗（IIb-B） | 治療下仍有症狀、生活品質差 → **侵入性冠狀動脈功能檢查找 endotype**（**I-B**） | ==IIa／IIb → I== |
| 血管痙攣 | Ambulatory ST monitoring（IIa-C） | 症狀頻繁 → ambulatory ST monitoring（IIa-B） | 證據升級 |
| 篩檢 | > 40 歲用 SCORE 估總風險（I-C） | 機會性篩檢，用 **SCORE2／SCORE2-OP**（I-C） | 換新工具 |
| 病程進展 | 新出現或惡化症狀 → stress imaging 或運動心電圖分層（I-B） | 新出現或惡化症狀 → **首選 stress imaging**（I-C） | 拿掉運動心電圖 |

### 血管再通（對照 2018 ESC/EACTS）

| 情境 | 2018 版 | 2024 版 | 變化 |
| --- | --- | --- | --- |
| **LVEF ≤ 35%** | 單／雙條且能完整再通 → PCI 可替代 CABG（IIa-C）；三條 → Heart Team 評估後 PCI（IIa-C） | 功能顯著多條血管、手術風險高或不能開 → **PCI 可考慮**替代 CABG（**IIb-B**） | ==降級==：LVEF 差首選 CABG |
| LM，SYNTAX 0–22 | PCI（I-A） | PCI 能和 CABG 一樣完整 → 可替代 CABG（I-A） | 加上條件 |
| LM，SYNTAX 23–32 | PCI（IIa-A） | PCI 能和 CABG 一樣完整 → 應考慮（IIa-A） | 加上條件 |
| **LM＋多條** | SYNTAX ≥ 33 → PCI **不建議**（III-B） | 手術風險高 → PCI 可考慮，優於單純藥物（IIb-B） | 改從「不能開刀的人」角度寫 |
| **多條＋DM** | 三條、SYNTAX 0–22 → PCI（IIb-A）；SYNTAX > 22 → PCI 不建議（III-A） | **手術風險極高 → PCI 應考慮，優於單純藥物**（IIa-B） | 同上 |
| 單／雙條含近端 LAD | CABG 或 PCI（I-A） | GDMT 反應不足 → CABG 或 PCI 優於藥物（I-A）；**複雜不適合 PCI → CABG 優於 PCI**（I-B） | 新增 CABG 優先情境 |
| 單／雙條不含近端 LAD | PCI（I-C）；CABG 可考慮（IIb-C） | 有症狀、GDMT 反應不足 → PCI（**I-B**）；不適合 PCI → CABG 可考慮（IIb-C） | 證據升級 |

### 診斷

| 新建議 | 等級 |
| --- | --- |
| 情緒壓力誘發的胸痛、運動時喘或頭暈、手臂／下巴／頸部／上背痛、疲倦 → 視為**可能的 angina equivalent** | IIa-B |
| 可考慮驗 hs-CRP 和／或 fibrinogen | IIa-B |
| ==RF-CL 模型估 PTL（新）== | I-B |
| ==PTL ≤ 5% → 可延後進一步檢查== | IIa-B |
| PTL > 5–15% → 用 **CACS** 重新分類，找出更多 ≤ 5% 的人 | IIa-B |
| PTL > 5–15% → 運動心電圖、非冠狀動脈的動脈硬化可用來調整 PTL | IIb-C |
| 懷疑血管痙攣 → ambulatory ECG | IIa-B |
| Stress echo 加做 Doppler LAD flow reserve，改善風險分層並評估微血管 | IIb-B |
| Cath 時 CFR／HSR／CFC 當補充檢查 | IIa-B |
| Resting Pd/Pa、dPR、RFR 或 angiography-derived FFR 當替代參數 | IIb-C |
| CCTA 看到近端或中段中等狹窄 → 可考慮 CT-FFR | IIb-B |

### 治療

| 新建議 | 等級 |
| --- | --- |
| 居家心臟復健、行動健康介入提升長期順從、減少住院 | IIa-B |
| **Ivabradine**：LVEF < 40% 且症狀控制不佳時加上，或特定病人起始 | IIa-B |
| Statin 不耐受、ezetimibe 仍未達標 → **bempedoic acid（新）** | I-B |
| 最大 statin＋ezetimibe 仍未達標 → bempedoic acid | IIa-C |
| ==沒有 DM、BMI ≥ 27 → semaglutide== 降心血管死亡、MI、中風 | IIa-B |
| ==動脈硬化 CAD → 低劑量 colchicine 0.5 mg qd== 降 MI、中風、再通 | IIa-A |
| PCI 結束時用 FFR／iFR／QFR 找出持續心絞痛與事件高風險者 | IIa-B |
| PCI 結束時用 FFR／iFR／QFR 找可再加做 PCI 的病灶 | IIb-B |

| 新建議 | 等級 |
| --- | --- |
| HFpEF＋心絞痛、冠狀動脈正常或無阻塞 → PET／CMR 灌流或侵入性功能檢查找微血管功能不良 | IIa-B |
| HFrEF 做高風險複雜 PCI → 有經驗的中心可考慮 microaxial flow pump | IIb-C |

| 血管痙攣 → nitrate 預防復發 | IIa-B |
