> [!abstract] 一句話重點
> 2024 版最大的改變：**CHA₂DS₂-VA 取代 CHA₂DS₂-VASc**、**paroxysmal AF 導管燒灼升為第一線（I）**、共病處理多項升為 Class I（減重 10%、酒精每週 ≤ 3 份、量身運動）；**最常考的「不要做」是：抗血小板取代或加在抗凝上、用 AF 類型或出血分數決定抗凝、不符條件卻減量 DOAC**。

### 診斷與照護原則

| 建議 | 等級 |
| --- | --- |
| 會影響治療決策時，AF 病人做 TTE | I-C |
| 對病人、家屬、照顧者與醫療人員衛教，促進共同決策 | I-C |
| 不論性別、族裔、社經地位，都能得到 AF-CARE 照護 | I-C |
| 以病人為中心的多專科照護 | IIa-B |

### [C] 共病與危險因子

| 建議 | 等級 |
| --- | --- |
| AF 合併心衰竭與充血：給利尿劑 | I-C |
| AF 合併 LVEF 下降的心衰竭：給適當心衰竭藥物 | I-B |
| **AF 合併心衰竭，不論 LVEF 都給 SGLT2 inhibitor** | **I-A** |
| AF 合併糖尿病：有效控制血糖 | I-C |
| BMI ≥ 40（或 ≥ 35 合併肥胖相關併發症）且計畫 rhythm control：可考慮減重手術 | IIb-C |
| 治療 OSA | IIb-B |
| **篩檢 OSA 時只用症狀問卷** | **III-B** |

### [A] 抗凝

| 建議 | 等級 |
| --- | --- |
| 臨床 AF 且栓塞風險高：給 OAC | I-A |
| **CHA₂DS₂-VA ≥ 2 分代表栓塞風險高** | **I-C** |
| CHA₂DS₂-VA = 1 分應視為風險高 | IIa-C |
| **肥厚性心肌病變或心臟類澱粉沉積症：不論分數都給 OAC** | **I-B** |
| 定期個別化重新評估栓塞風險 | I-B |
| 無症狀、裝置偵測到的亞臨床 AF 且栓塞風險高：可考慮 DOAC（出血風險高者除外） | IIb-B |
| **不符合各藥條件卻減量 DOAC** | **III-B** |
| ≥ 75 歲、多重用藥、VKA 穩定者：可考慮繼續 VKA 不換 DOAC | IIb-B |
| **為預防中風在 OAC 上加抗血小板** | **III-B** |
| 抗凝中仍發生中風：完整檢查（非心因性原因、血管危險因子、劑量、服藥順從性） | IIa-B |
| **抗凝中仍中風：加抗血小板、或無明確理由換另一種 DOAC 或改 VKA** | **III-B** |
| 接受內視鏡或混合式燒灼時，外科關閉左心耳作為 OAC 的輔助 | IIa-C |
| 長期抗凝有禁忌：可考慮單獨以內視鏡外科關閉左心耳 | IIb-C |
| DOAC 病人致命或重要部位出血：考慮特異性解毒劑 | IIa-B |

### [R] Rate 與 rhythm control

| 建議 | 等級 |
| --- | --- |
| Rate control 可用於急性期、rhythm control 的輔助或單獨策略 | I-B |
| **LVEF > 40%：beta-blocker、diltiazem、verapamil 或 digoxin 為首選** | I-B |
| Permanent AF、症狀嚴重、至少一次心衰竭住院：AV node 燒灼 + CRT | IIa-B |
| **Cardioversion 優先用 DOAC 而非 VKA** | I-A |
| 有症狀的 persistent AF：cardioversion 作為 rhythm control 的一部分 | IIa-B |
| 血行動力穩定：可觀察 48 小時內是否自行恢復，取代立即整流 | IIa-B |
| 有栓塞風險的選擇性病人：**診斷後 12 個月內**開始 rhythm control | IIa-B |
| **AF > 24 小時，沒有適當抗凝或 TEE 就早期整流；或明明可以等自行恢復** | **III-C** |
| Persistent AF：用電擊整流當「診斷工具」，釐清竇性節律是否改善症狀或 LVEF | IIa-C |
| **嚴重傳導障礙且沒有節律器保護時用抗心律不整藥** | **III-C** |
| AF 終止時出現心搏過慢或竇性停頓：考慮導管燒灼以免裝節律器 | IIa-C |
| 第一次燒灼後症狀曾改善（或第一次 PVI 失敗）而復發：考慮再次燒灼 | IIa-B |
| **導管燒灼期間不中斷 OAC** | **I-A** |
| 外科、內視鏡或混合式燒灼後，栓塞風險高者繼續 OAC，不論心律或是否關閉左心耳 | I-C |
| 藥物無效的症狀性 persistent AF：考慮內視鏡或混合式燒灼 | IIa-A |
| 外科燒灼時，術中影像檢查左心房血栓 | I-C |
| 非二尖瓣心臟手術且適合 rhythm control：考慮同時做外科燒灼 | IIa-B |

### 特殊族群、篩檢與預防

| 建議 | 等級 |
| --- | --- |
| 評估照護品質、找出改善機會 | IIa-B |
| **穩定慢性冠心症或血管疾病、已用 OAC：抗血小板超過 12 個月** | **III-B** |
| Trigger-induced AF 且栓塞風險高：考慮長期 OAC | IIa-C |
| 心臟手術：需要藥物預防術後 AF 時用 amiodarone | I-A |
| 心臟手術時同時做後心包膜切開，預防術後 AF | IIa-B |
| **ESUS 但沒有記錄到 AF：開始 OAC** | **III-A** |
| **Atrial flutter 且栓塞風險高：給 OAC** | I-B |
| 醫師判讀 ECG 才能確診 AF | I-B |
| ≥ 75 歲，或 ≥ 65 歲加上 CHA₂DS₂-VA 危險因子：考慮長時間非侵入性 ECG 族群篩檢 | IIa-B |
| 一般族群維持理想血壓預防 AF，**首選 ACEi 或 ARB** | I-B |
| HFrEF 給適當藥物預防 AF | I-B |
| 維持正常體重（**BMI 20–25**） | I-B |
| 規律運動：**每週中強度 150–300 分鐘或高強度 75–150 分鐘** | I-B |
| 避免狂飲與過量飲酒 | I-B |
| 糖尿病需要用藥時，考慮 **metformin 或 SGLT2 inhibitor** 預防 AF | IIa-B |
| 肥胖者減重預防 AF | IIa-B |

## Table 4：與 2020 版相比修訂的建議

<div class="orig-fig" data-src="心臟科/af-originals/table-04-1.png,心臟科/af-originals/table-04-2.png" data-label="Table 4"></div>

| 主題 | 2020 版 | 2024 版 | 變化 |
| --- | --- | --- | --- |
| **AF 診斷** | 12 導程或 **≥ 30 秒**單導程 ECG（I-B） | ECG（12 導程、多導程或單導程）確認即可（**I-A**） | 不再寫死 30 秒；證據升為 A |
| 症狀評估 | 治療前後用 mEHRA 評估（I-C） | **重大治療改變前後**評估症狀影響，作為共同決策依據（I-B） | 證據升級 |
| 高血壓 | 良好控制血壓（I-B） | 降壓治療，減少 AF 復發與進展（I-B） | 措辭更新 |
| **減重** | 應考慮（IIa-B） | **建議，目標減重 ≥ 10%**（**I-B**） | **IIa → I** |
| **運動** | 應考慮，但避免過度耐力運動（IIa-C） | **paroxysmal／persistent AF 建議量身訂做的運動計畫**（**I-B**） | **IIa → I** |
| **酒精** | 應考慮避免過量（IIa-B） | **每週 ≤ 3 份（≤ 30 g 酒精）**（**I-B**） | **IIa → I**，有明確數字 |
| **心臟手術時關閉左心耳** | 可考慮（IIb-C） | **作為 OAC 輔助，建議**（**I-B**） | **IIb → I** |
| **出血風險** | 用 **HAS-BLED**，≥ 3 分更頻繁追蹤（IIa-B） | **所有適合抗凝者都評估並處理可改變的出血因子**（I-B） | **==不再推薦特定出血分數==** |
| **Paroxysmal AF 第一線燒灼** | 應考慮（IIa-B） | **建議作為第一線選項**（**I-A**） | **IIa → I** |
| 胸腔鏡／混合式燒灼（paroxysmal） | 藥物與導管燒灼失敗：應考慮（IIa-B） | 可考慮（IIb-B） | **IIa → IIb**（降級） |
| 胸腔鏡／混合式燒灼（persistent） | 有復發危險因子、至少一種藥物失敗：可考慮（IIb-C） | 藥物無效的症狀性 persistent AF：應考慮（**IIa-A**） | **IIb → IIa** |
| 心臟手術同時燒灼 | 一般心臟手術：應考慮（IIa-A） | **二尖瓣手術且適合 rhythm control：建議**（**I-A**） | 針對二尖瓣手術升為 I |
| 術後 AF 長期抗凝 | 心臟手術後：可考慮（IIb-B） | **心臟與非心臟手術後**，栓塞風險高：應考慮（**IIa-B**） | **IIb → IIa**，範圍擴大 |

> [!tip] Pearl：升級最多的是生活型態
> 2020 年還是「應考慮」的**減重、運動、限酒**，2024 年全部升為 **Class I**，而且都有具體目標。HAS-BLED 則從指引中退場，重點變成「處理可改變的出血因子」。

| 非心臟手術常規用 beta-blocker 預防術後 AF | III-B |
| ESUS 沒有記錄到 AF 就開始 OAC | III-A |

## Table 17：「必做」清單（Class I，依主題）

> 原圖見上方「不要做」清單的原圖區塊（Table 17 共 4 頁）。

### 診斷、評估與照護

| 必做 | 等級 |
| --- | --- |
| 以 ECG（12 導程、多導程或單導程）確診臨床 AF | I-A |
| 重大治療改變前後評估症狀影響 | I-B |
| 會影響治療決策時做 TTE | I-C |
| 對病人、家屬、照顧者、醫療人員衛教，促進共同決策 | I-C |
| 不論性別、族裔、社經地位都能得到 AF-CARE 照護 | I-C |

### [C] 共病與危險因子

| 必做 | 等級 |
| --- | --- |
| 找出並處理危險因子與共病，是 AF 照護的一部分 | I-B |
| 合併高血壓：降壓 | I-B |
| 合併心衰竭與充血：利尿劑 | I-C |
| 合併 LVEF 下降的心衰竭：適當心衰竭藥物 | I-B |
| **合併心衰竭：不論 LVEF 都給 SGLT2 inhibitor** | I-A |
| 合併糖尿病：有效控制血糖 | I-C |
| 過重或肥胖：**減重 ≥ 10%** | I-B |
| Paroxysmal 或 persistent AF：量身訂做的運動計畫 | I-B |
| **酒精每週 ≤ 3 份（≤ 30 g）** | I-B |

### [A] 抗凝、出血與左心耳

| 必做 | 等級 |
| --- | --- |
| 臨床 AF 且栓塞風險高：給 OAC | I-A |
| **CHA₂DS₂-VA ≥ 2 分視為栓塞風險高** | I-C |
| **==肥厚性心肌病變或心臟類澱粉沉積症：不論分數都給 OAC==** | I-B |
| 定期個別化重新評估栓塞風險 | I-B |
| **優先 DOAC 而非 VKA**（機械瓣、中重度二尖瓣狹窄除外） | I-A |
| VKA 的 INR 目標 2.0–3.0 | I-B |
| VKA 的 TTR < 70%：改 DOAC | I-B |
| 心臟手術時關閉左心耳，作為 OAC 的輔助 | I-B |
| 所有適合抗凝者：評估並處理可改變的出血因子 | I-B |
| 活動性出血：中斷抗凝並診斷或治療，直到找到並處理出血原因 | I-C |

### [R] Rate control

| 必做 | 等級 |
| --- | --- |
| Rate control 可用於急性期、rhythm control 的輔助或單獨策略 | I-B |
| LVEF > 40%：beta-blocker、diltiazem、verapamil 或 digoxin | I-B |
| **LVEF ≤ 40%：beta-blocker 和／或 digoxin** | I-B |

### [R] Cardioversion

| 必做 | 等級 |
| --- | --- |
| 急性或惡化的血行動力不穩：電擊整流 | I-C |
| Cardioversion 優先用 DOAC 而非 VKA | I-A |
| **擇期整流前規律抗凝至少 3 週**（DOAC 確認服藥、VKA 要 INR ≥ 2.0）；atrial flutter 也一樣 | I-B |
| 沒有抗凝滿 3 週：**TEE 排除血栓**後才能早期整流 | I-B |
| **==整流後所有病人至少抗凝 4 週==**；有栓塞危險因子者長期抗凝，**不論是否恢復竇性節律** | I-B |
| 新發 AF 藥物整流：**IV flecainide 或 propafenone**（嚴重 LVH、HFrEF、冠心病除外） | I-A |
| 新發 AF 藥物整流：**IV vernakalant**（近期 ACS、HFrEF、嚴重主動脈瓣狹窄除外） | I-A |
| **嚴重 LVH、HFrEF 或冠心病：IV amiodarone**（接受整流較慢） | I-A |

### [R] 長期抗心律不整藥

| 必做 | 等級 |
| --- | --- |
| **HFrEF：amiodarone**（監測心臟外毒性） | I-A |
| **Dronedarone**：包括 HFmrEF、HFpEF、缺血性心臟病或瓣膜疾病 | I-A |
| **Flecainide 或 propafenone**：排除左心室收縮功能差、嚴重 LVH 或冠心病 | I-A |

### [R] 導管燒灼與其抗凝

| 必做 | 等級 |
| --- | --- |
| 考慮燒灼時共同決策（風險、效益、復發因子） | I-C |
| Paroxysmal 或 persistent AF，藥物無效或無法耐受：導管燒灼 | I-A |
| **==Paroxysmal AF：導管燒灼作為第一線選項==** | I-A |
| **HFrEF 且高度懷疑心搏過速引起的心肌病變：導管燒灼** | I-B |
| 栓塞風險高者，**燒灼前至少 3 週**開始 OAC | I-C |
| **燒灼期間不中斷 OAC** | I-A |
| **==燒灼後所有病人至少抗凝 2 個月==**，不論心律或分數 | I-C |
| 之後是否繼續抗凝，**依 CHA₂DS₂-VA，不看燒灼是否成功** | I-C |
| 外科、內視鏡或混合式燒灼後：栓塞風險高者繼續 OAC，不論心律或是否關閉左心耳 | I-C |
| 二尖瓣手術且適合 rhythm control：同時做外科燒灼 | I-A |
| 外科燒灼時：術中影像檢查左心房血栓 | I-C |

### 冠心症、手術、ESUS

| 必做 | 等級 |
| --- | --- |
| 需要合併抗血小板時：優先 DOAC 而非 VKA | I-A |
| **ACS 接受單純 PCI**（血栓風險低或出血風險高）：**aspirin ≤ 1 週即停**，OAC（首選 DOAC）+ P2Y12 inhibitor（首選 clopidogrel）**最多 12 個月** | I-A |
| **單純 PCI**（缺血風險低）：aspirin ≤ 1 週即停，OAC + P2Y12 inhibitor **最多 6 個月** | I-A |
| 心臟手術需要藥物預防術後 AF：amiodarone | I-A |
| **ESUS：長時間監測找 AF** | I-B |

### 懷孕、atrial flutter、篩檢與預防

| 必做 | 等級 |
| --- | --- |
| 懷孕合併血行動力不穩或**預激性 AF**：立即電擊整流 | I-C |
| 懷孕且栓塞風險高：**LMWH 或 VKA**（**第一孕期和 36 週後不用 VKA**） | I-C |
| 懷孕的心率控制：**beta-1 選擇性 blocker（不用 atenolol）** | I-C |
| Atrial flutter 且栓塞風險高：OAC | I-B |
| 醫師判讀 ECG 才能確診 | I-B |
| **≥ 65 歲每次就醫評估心律** | I-C |
| 一般族群維持理想血壓預防 AF，**首選 ACEi 或 ARB** | I-B |
| HFrEF 給適當藥物預防 AF | I-B |
| 維持 BMI 20–25 | I-B |
| 規律運動：每週中強度 150–300 分鐘或高強度 75–150 分鐘 | I-B |
| 避免狂飲與過量飲酒 | I-B |

> [!tip] Pearl：三個「抗凝時間」要分清楚
> - **整流前**：規律抗凝 **≥ 3 週**，不然先做 TEE
> - **整流後**：所有人 **≥ 4 週**
> - **燒灼後**：所有人 **≥ 2 個月**
>
> 之後要不要長期抗凝，**一律看 CHA₂DS₂-VA，不看心律是否恢復**。
