> [!abstract] 一句話重點
> Cardiac syncope 的死亡率遠高於 reflex、orthostatic 或原因不明的 syncope，**懷疑就要住院**。最常見的是 arrhythmia：**tachy（VT、WPW 等極快 SVT）**與 **brady（sick sinus syndrome、AV block）**。**有 CAD、HF 或其他心臟病的 syncope，要認真想 VT**；**wide complex tachycardia 除非有確切證據，一律當 VT**；**long QT 可以模仿 vasovagal**，所以典型 vasovagal 也要做 ECG 看 QTc。

## Cardiac syncope 總論

### Textbook presentation

心臟本身的疾病造成 syncope。**Arrhythmia（tachy 或 brady）最常見**；較少見的有 ACS、obstructive syndrome（AS、HCM、PE）、罕見的 aortic dissection、atrial myxoma。典型病人是**已知心臟病（HF、CAD）的老年人，突然、毫無預警地昏倒**，可能有 palpitations。

### Disease highlights

- **==Cardiac syncope 的死亡率明顯高於 reflex、orthostatic 或 unknown cause==**
- Dilated cardiomyopathy 的死亡中，30% 是 sudden cardiac death（推測為 arrhythmia）
- **懷疑 cardiac syncope → 住院評估**
- 心律不整很多，但會造成 syncope 的不多：**大部分 SVT 因為 AV node 限制心室速率，不會造成 syncope**
- 會造成 syncope 的主要 arrhythmia：

| Tachycardias | Bradycardias |
| --- | --- |
| **VT** | **Sinus node dysfunction**：sinus bradycardia < 35 bpm；**sinus pause > 3 s 或有症狀時 > 2 s** |
| 經 accessory pathway 的 SVT（**WPW**），或心室速率極快的 SVT | **AV block（second- 或 third-degree）** |
| | **AF with slow ventricular response** |

### History 與 ECG 的證據

**大幅提高 cardiac syncope 機率的發現**：已知心臟病、ECG 異常、合併 chest pain、**syncope during exertion（LR+ 6.5–14）**、**supine syncope（LR+ 2.5–∞）或坐著時**。

> [!warning] Pitfall
> **==Syncope during exertion 少見但很危險，要當 cardiac syncope 處理==**。

其他較不 specific 的線索：palpitations、突然發生、syncope 合併 dyspnea。**沒有已知或疑似心臟病**、初步 history、PE、ECG 正常 → cardiac syncope 不太可能（LR− 0.09–0.12）。

**ECG**：非 vasovagal 病人 ECG 異常時，cardiac arrhythmia 的 OR 23.5。特定 ECG 發現的意義：

| ECG | 指向 |
| --- | --- |
| Prior MI、**long QT** | VT |
| 明顯 sinus bradycardia、second／third-degree AV block | SSS 或 AV block |
| **BBB** | **AV block 與 VT 都上升** |
| RV strain（S1Q3T3）、RBBB | PE |
| Ischemic changes | MI |
| **Delta wave、short PR** | Accessory pathway（WPW） |

**BBB＋syncope** 特別值得記：

- 40 個月死亡率 28%，其中 32% 是 sudden death（VT 或 electromechanical dissociation）
- 17% 會發生 AV block
- EPS 可證實 His-Purkinje 傳導延長：很 specific 但不 sensitive（67%）；ILR 也有用
- **Pacemaker 幾乎能預防所有這類病人的 syncope，但不能預防 sudden death**

## Ventricular tachycardia（VT）

### Textbook presentation

可以完全沒症狀，也可以從 palpitations、lightheadedness、near syncope、syncope 到 sudden cardiac death。

> [!tip] Pearl
> **==VT 最常發生在有心臟病的人==**：syncope 病人只要有 **CAD、HF 或其他心臟病史**，就要認真考慮 VT。

### 病因與相關疾病

| 類別 | 內容 |
| --- | --- |
| **Ischemic heart disease** | **80% 的 VT 與 CAD 有關**；急性 ischemia／MI 或舊 scar 都會；**10% 的 STEMI 併發 VT 或 VF** |
| HF；其他心臟病 | HCM、valvular heart disease、infiltrative disorders |
| Miscellaneous | **Hypokalemia、hypomagnesemia**；hypoxia；**QT-prolonging drugs**（antiarrhythmics、antipsychotics、TCA、macrolides、部分 fluoroquinolones 等） |
| **Congenital** | Congenital heart disease；**long QT syndrome**；**Brugada syndrome** |

#### Long QT syndrome

- **Long QT：QTc > 450 ms（男）、> 460 ms（女）**；家族 ECG 呈現 refractory period 延長
- 猝死風險來自 **torsades de pointes**（一種 VT）
- 誘發因素：**emotional stress、exercise、突然的巨大聲響（loud noise）、睡眠中**
- 有些型合併 **congenital neural deafness**
- **很多 vasovagal 的症狀在 long QT 也常見**：emotional stress／pain／noise 誘發（70%）、sweating（67%）、nausea（29%）、situational（micturition、defecation、coughing，17%）、abdominal discomfort（16%）

> [!danger] Long QT 會模仿 vasovagal
> **==即使症狀很像 vasovagal，也要做 ECG 量 QTc==**。

#### Brugada syndrome

- **Sodium channel 基因突變**，容易發生 polymorphic VT 與 sudden death
- Baseline ECG 線索：**RBBB pattern＋right precordial leads 的 ST elevation**

### Prognosis

VT 可能致命；死亡率的預測因子：**prior cardiac arrest、LV dysfunction、post-MI、EPS 可誘發 VT**。

### ECG criteria

- **≥ 3 個連續 wide complex（QRS ≥ 0.12 s）beats、速率 > 100 bpm** = wide complex tachycardia（**但不一定是 VT**）
  - **80–90% 的 wide complex tachycardia 是 VT**
  - SVT 也可能 QRS 變寬：合併 BBB、accessory pathway、hyperkalemia、藥物（TCA overdose、class Ia antiarrhythmics）
  - **CAD 或 HF 病史 → 更可能是 VT**
- **支持 VT 而非 SVT with aberrancy 的 ECG 發現**：

| 發現 | 說明 |
| --- | --- |
| **Capture beats** | Wide complex 中出現正常窄 QRS（supraventricular 衝動完全接管心室） |
| **Fusion beats** | QRS 形態介於窄與寬之間（supraventricular 衝動部分接管心室） |
| **AV dissociation** | P 與 QRS 無關 |
| **Precordial concordance** | 胸前導程 QRS 全正或全負 |
| **QRS > 160 ms** | LR+ 22.9 |

- 以上都沒有，**也不能確定是 SVT**
- 比對舊 ECG：
  - 平時 sinus rhythm 就有**相同形態的 BBB** → 支持 SVT with aberrancy
  - 有 WPW → 可能是 antidromic SVT 經 accessory pathway 下傳
- **==Hemodynamic stability 不能排除 VT==**
- **Sustained VT**：持續 > 30 秒

> [!danger] 規則
> **==所有 wide complex tachycardia 都先當 VT 處理==**，除非有確切證據證明是 SVT。

### EPS 的角色

VT 危險因子（ischemic heart disease、HF、HCM）存在但還沒記錄到 VT 時，可做 EPS：**能誘發 sustained monomorphic VT 就可以診斷**；特別適合懷疑 VT 但**還沒有 ICD 適應症**的人。

### 治療

**正在發作的 VT**：

1. **不穩定**（hypotension、angina、HF、altered mental status）→ **照 ACLS**
2. 評估：baseline ECG（夠穩定時）、**troponin**、**electrolytes（尤其 K⁺、Mg²⁺）與 SaO₂**、檢視**會延長 QT 的藥物**、必要時測藥物濃度（如 digoxin）

**後續找病因與 sudden death 風險**：

- Stress test（部分做 coronary angiography）找 ischemia：exercise-induced syncope、chest pain、CAD 機率中等以上者
- **Echocardiogram**：LV function、valvular heart disease、HF
- 部分病人做 EPS

**預防復發與 sudden death**：

1. **治療潛在疾病**：ischemic heart disease（必要時 revascularization）；HF（**ACEI、beta-blocker、spironolactone 都證實降低死亡率**）；矯正 electrolytes（含 magnesium）
2. **特定治療**：antiarrhythmics（尤其 beta-blockers，可能加 amiodarone）、catheter ablation、**ICD**，或合併
   - ICD 會監測節律，自動偵測 VT 並電擊整流
   - 適用 sudden death 高風險者：**部分 HFrEF、sudden death 存活者、sustained VT、推測 syncope 由 VT 造成的人**
   - ACCF/AHA 有 ICD 的 appropriate use criteria

## Sick sinus syndrome（SSS）

### Textbook presentation

依 bradyarrhythmia 的嚴重度與持續時間而定：嚴重且持續久 → sudden syncope；較輕 → weakness、exertional dyspnea、HF、angina、TIA 或 near syncope。發作可能很短，**病人不用處理就自己恢復**。

### Disease highlights

- Sinus node 偶發或持續**無法滿足身體需求**，**通常會逐漸惡化**
- 電生理表現：

| 表現 | 定義 |
| --- | --- |
| Sinus bradycardia | **< 40 bpm** |
| Sinus pauses | **> 2 秒** |
| Sinus arrest | 合併 escape junctional rhythm |
| Sinoatrial exit block | Sinus 衝動無法傳出 sinus node |
| **Chronotropic incompetence** | 活動時心率無法適當上升 → 相對 bradycardia 與症狀 |
| **Tachy-brady syndrome** | 40–60% 合併 SVT（尤其 **AF**），可能主訴 palpitations；**bradycardia 常出現在 tachycardia 終止後**；死亡或 nonfatal stroke 風險為單純 SSS 的 2–3 倍 |

- **Pacemaker 最常見的適應症**（占 30–50%）
- **年齡是最重要的危險因子**（每 5 歲 RR 1.73），平均發病 68 歲
- 通常是 sinus node **fibrosis 與 degeneration**；常合併 CAD
- **會惡化 SSS 的藥**：**beta-blockers、verapamil、diltiazem、digoxin**、acetylcholinesterase inhibitors、cimetidine、clonidine、lithium、methyldopa、其他 antiarrhythmics
- 少見原因：hypothyroidism、sarcoidosis、amyloidosis、hemochromatosis、pericarditis、Lyme disease、Chagas disease、rheumatic fever
- **> 50% 同時有 AV conduction disturbance**

### Evidence-based diagnosis

- **症狀與 ECG 發現同時出現**（sinus bradycardia、明顯 pause、sinus exit block）即可診斷
- Holter 常因發作間歇而抓不到 → external continuous loop event monitor 可監測更久 → **ILR** 可監測更長時間
- EPS：監測抓不到但症狀嚴重時偶爾使用；sensitivity 不完美，**正常不能排除 SSS**
- Exercise stress test：找 ischemia 或 chronotropic incompetence

### 治療

1. **不穩定 → 照 ACLS**
2. 穩定 → **停掉會抑制 sinus function 的藥**；若 beta-blocker 等無法停，可能需要 pacemaker
3. **Pacemaker 適應症**：
   - **記錄到有症狀的 sinus node dysfunction**（bradycardia 或 pauses），包括由無法停用的藥物造成者
   - **有症狀的 chronotropic incompetence**
   - **合理（reasonable）**：懷疑 SSS 但無法確認的 unexplained syncope —— 清醒時 **HR < 40 bpm**，或 **EPS 顯示明顯 sinus node dysfunction**

## AV heart block

### Textbook presentation

依 block 的嚴重度與持續時間：可以無症狀，或 syncope、near syncope、sudden cardiac death、palpitations、angina、TIA。

### Disease highlights

AV node、His bundle 或 bundle branches 的傳導異常，可以是**間歇或永久**的。

**分類**（依原書 Table 31-5 重新整理）：

| 分類 | AV conduction | ECG | 臨床 | 治療 |
| --- | --- | --- | --- | --- |
| **First-degree** | 1:1，**所有** P 都傳下去 | **PR > 0.2 s**；QRS 通常正常 | 無 | 不需要 |
| **Second-degree Mobitz I** | 間歇 | PR 逐漸延長直到 P 後沒有 QRS；掉拍後的 PR 比掉拍前短；QRS < 0.12 s | 合併 **inferior MI**；**很少進展**到 3° | 觀察或 **atropine** |
| **Second-degree Mobitz II** | 間歇 | P 間歇不傳導；**QRS 可能變寬、可見 BBB**（infranodal 較嚴重損傷） | 合併 **anterior MI**；**常進展**到 3° | **==Pacemaker==** |
| **Third-degree** | **沒有** P 傳下去 | P 不傳導、**完全 AV dissociation**；心室速率取決於 escape pacemaker | 合併 CAD、藥物、degeneration、電解質異常；bradycardia、hypotension | **==Pacemaker==** |

- Second／third-degree AV block 時心室速率變慢，依賴心室內較低位的 pacemaker → dyspnea、angina、hypotension、syncope 或死亡
- **AF 合併 slow ventricular response**，且**沒有吃減慢 AV 傳導的藥**（digoxin、beta-blockers、verapamil、diltiazem）→ 也要懷疑 AV nodal disease

### 病因

1. 傳導系統 **fibrosis**
2. **Ischemic heart disease**
3. **藥物**：beta-blockers、verapamil、diltiazem、digoxin、adenosine、amiodarone
4. **Sarcoidosis**：**< 60 歲 unexplained 二或三度 AV block 的常見原因（34%）**，即使沒有 sarcoidosis 病史也要想到；其中 27% 之後發生 VT 或 HF
5. **Hyperkalemia**
6. Valvular heart disease（鈣化延伸到傳導系統）
7. Increased vagal tone
8. 其他：hypothyroidism、Lyme disease、amyloidosis
9. Cardiac procedures（如 TAVI）

> [!warning] Pitfall：藥物造成的 AV block
> 被歸因於 verapamil、diltiazem 或 beta-blockers 的 AV block，**大多數本身也有傳導系統疾病**，**很可能（> 80%）停藥後仍會再發生 AV block**。不要以為停藥就解決了。

### Evidence-based diagnosis

監測抓到以下任一即可診斷：

1. **Third-degree AV block**
2. **Advanced second-degree AV block**（**連續 2 個 P 被擋**）合併任一：症狀；推測由 AV block 引起的 ventricular arrhythmia；**asystole ≥ 3 s 或 AV node 以下 escape rate < 40 bpm**；AF 合併 **pause ≥ 5 s**
3. **有症狀**的 second-degree AV block（不論哪一型）
4. Unexplained syncope 合併 chronic bifascicular block

**ILR 長期監測**可提高診斷率。

### 治療

1. **停用損害 AV 傳導的藥**
2. 治療 ischemia
3. 矯正電解質
4. 緊急時 **atropine** 可能有幫助
5. **Pacemaker**（2012 ACCF/AHA 指引；常見適應症；新版補充見下方 🆕）：
   - **Third-degree AV block**
   - Advanced second-degree AV block 合併：症狀、推測由 AV block 引起的 ventricular arrhythmia、asystole ≥ 3 s 或 escape rate < 40 bpm、AF 合併 pause ≥ 5 s
   - **有症狀**的 second-degree AV block（不論哪一型）
   - **Unexplained syncope＋chronic bifascicular block**（尤其 EPS 顯示 **HV interval ≥ 70 ms**）

> [!info] 🆕 新版指引（2018 ACC/AHA/HRS Bradycardia Guideline；2021 ESC Pacing & CRT Guidelines）
> - **Syncope＋bifascicular block**：非侵入性評估後仍不明 → **做 EPS**；**==HV interval ≥ 70 ms==**、incremental atrial pacing 誘發 2°／3° intra- 或 infra-Hisian block，或藥物激發異常 → **pacemaker**
> - **Alternating bundle branch block**：不論有無症狀都要 **pacing**
> - **無症狀**的 bifascicular block（± 1° AV block）進展到 complete heart block 的機率低，**不建議預防性 pacing**
> - **Acquired 3° 或 high-grade AV block、Mobitz II（非可逆原因）→ permanent pacemaker**，不論症狀；先排除可逆原因（藥物、hyperkalemia、inferior MI、Lyme 等）
> - TAVI 後的 AV block 持續 24–48 小時以上 → permanent pacemaker
> - **Conduction system pacing**（His bundle、left bundle branch area pacing）是新興選擇，仍待隨機試驗

## Wolff-Parkinson-White（WPW）syndrome

### Textbook presentation

可以無症狀，也可以 palpitations、dyspnea、near syncope、syncope 或 sudden death；有些人是因別的原因做 ECG 才發現典型變化。

### Disease highlights

**Accessory bundle 直接連接 atria 與 ventricular muscle，繞過 AV node** 的先天異常。多數人沒症狀，但可能發生致命的 tachyarrhythmia：

| 型態 | 機轉 | QRS |
| --- | --- | --- |
| **Orthodromic tachycardia** | 經正常 His-Purkinje 下傳，再從 accessory pathway **逆傳**回 atria | **窄** |
| **Antidromic tachycardia** | 反方向：**經 accessory pathway 下傳**，心室從 pathway 插入點開始一個細胞一個細胞地去極化 | **寬** |
| **AF 或 atrial flutter** | Accessory pathway 直接把衝動傳到心室（**繞過 AV node 的過濾**）→ 心室極快去極化 | 不規則、寬窄不一 → **VF、sudden death** |

**WPW 病人的 syncope 中，25% 合併快速、致命的 accessory pathway 傳導**。

### ECG（平常 sinus rhythm 時）

| 發現 | 機轉 |
| --- | --- |
| **Short PR（< 0.12 s）** | 正常 PR 包含 AV node 內建的延遲（讓 atria 先排空）；accessory pathway 沒有這個延遲 → 75% 的人 PR 縮短 |
| **Delta wave** | Pathway 直接插入心室肌（而非傳導系統），衝動經 gap junction 緩慢擴散 → **QRS 起始緩慢上升** |
| 窄的 QRS 終末部分 | 之後 AV node 傳下來的衝動經 His-Purkinje 快速去極化剩餘心室 |

### 治療

**Risk stratification**：

1. **Stress test**：部分 accessory pathway 在快心率時傳不過去，代表致命 arrhythmia 風險較低 → **心率變快時 delta wave 與短 PR 突然消失**
2. **EPS**：確認 bypass tract、測量其傳導特性（能否支撐致命的快心率）、**radiofrequency ablation** 可消除 bypass tract
   - 通常建議做 EPS 的人：**有症狀**（tachycardia、syncope、sudden death 病史）；**有 structural heart disease 而 AF 風險較高**；部分**無症狀但 stress test 在快心率下 preexcitation 沒消失**的人

**處置**：

- 急性：electrical cardioversion、藥物等多種選擇，**藥物選擇取決於 tachycardia 的機轉**；建議會診
- 長期：藥物或 **radiofrequency catheter ablation of the bypass tract**；**快速 tachycardia 風險高者做 ablation**；建議會診

> [!danger] 內專常考的延伸（不在原書，依考題整理）
> **WPW 合併 AF（pre-excited AF）==禁用 AV nodal blockers==**（adenosine、verapamil、diltiazem、digoxin、beta-blocker）：擋住 AV node 會讓更多衝動走 accessory pathway → VF。不穩定 → synchronized cardioversion；穩定 → procainamide 或 ibutilide，或鎮靜後電擊。見 [[cardiology/syncope/syncope-exam|⑧ 內專考點]]。
