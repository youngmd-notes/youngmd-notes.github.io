### 2018 新增建議（只列主要的）

| 新建議 | 等級 |
| --- | --- |
| **ED 處置**：low-risk 從 ED 出院；high-risk 在 ED 或 SU 早期密集評估或住院；neither 在 ED 或 SU 觀察、不住院 | **I** |
| 錄下自發性發作（video recording） | **IIa** |
| ILR：懷疑 epilepsy 但未證實 | 圖中標 IIa；建議表為 **IIb-B** |
| ILR：unexplained falls | **IIb** |
| ILR：**primary cardiomyopathy 或遺傳性心律不整、SCD 低風險**者，**取代 ICD** | **IIa** |

> [!warning] Pitfall
> Figure 1 中「ILR 用於懷疑但未證實的 epilepsy」標成黃色（IIa），但正文建議表寫的是 **==IIb-B==**（「epilepsy 疑似但治療無效」），本筆記依建議表。

> [!tip] Pearl
> 讀懂這張圖的邏輯：**tilt test 降級**是因為它只代表 hypotensive susceptibility；**EPS 陽性升級、empirical pacing 降級**是「先證明機轉再治療」；**ILR 擴大適應症**是「長期監測取代猜測」。

## Key messages：19 條規則

### 診斷：初步評估

1. 初步評估回答 **4 個問題**：是不是 TLOC？是 syncopal 還是 non-syncopal？懷疑 syncope 時有沒有明確病因？有沒有心血管事件或死亡的高風險？
2. ED 評估回答 **3 個問題**：有沒有可辨識的嚴重潛在病因？若原因不明，嚴重預後風險多高？要不要住院？
3. **所有病人**都做完整病史、PE（含**站立血壓**）與標準 ECG
4. **High-risk 且懷疑 arrhythmic syncope** → 立即 ECG 監測（床邊或 telemetry）
5. 已知心臟病、懷疑 structural heart disease 或心血管原因 → **echo**
6. **> 40 歲**、原因不明、符合 reflex 機轉 → **CSM**
7. 懷疑 reflex 或 orthostatic 原因 → **tilt test**
8. **有臨床適應症才抽血**：懷疑出血 → Hct、CBC；懷疑缺氧 → 血氧、ABG；懷疑缺血 → troponin；懷疑 PE → D-dimer

### 診斷：後續檢查

9. **Prolonged ECG monitoring**（external 或 implantable）給反覆、嚴重、不明 syncope 且**同時符合三項**的人：有提示 arrhythmic syncope 的臨床或 ECG 特徵、短期內很可能再發、找到原因後能得到特定治療
10. **EPS**：unexplained syncope＋**bifascicular BBB**（可能即將 high-degree AV block）或懷疑 tachycardia
11. **運動中或剛運動後**昏倒 → exercise stress test
12. 懷疑 neurogenic OH → 考慮基本 autonomic tests（**Valsalva、deep breathing**）與 **ABPM**
13. 懷疑 non-syncopal TLOC → 考慮**錄影**（在家或醫院）

### 治療

14. 所有 reflex syncope 與 OH 病人：**解釋診斷、安心、說明再發風險、教導避開 trigger**——這是治療基石，能大幅減少再發
15. **嚴重 reflex syncope** 依臨床特徵選一種以上加強治療：
    - **年輕、低血壓體質** → midodrine 或 fludrocortisone
    - **年輕、有 prodrome** → counter-pressure manoeuvres（必要時含 tilt training）
    - **沒有或很短 prodrome** 的特定病人 → **ILR-guided** 策略
    - **老年高血壓** → 停用或減少降壓藥，目標 **SBP 140 mmHg**
    - **老年、dominant cardioinhibitory** → **pacemaker**
16. **OH** 依嚴重度選一種以上：衛教、適當水分與鹽分、停用降壓藥、PCM、abdominal binder 或彈性襪、床頭抬高睡覺、midodrine 或 fludrocortisone
17. **Cardiac syncope** 一定要針對 culprit arrhythmia 及／或潛在疾病治療
18. **Unexplained syncope 且 SCD 高風險**（LV systolic dysfunction、HCM、ARVC、遺傳性心律不整）→ **權衡 ICD 利弊**；這裡的 unexplained 指**不符合任何 Class I 診斷標準**，視為疑似 arrhythmic syncope
19. 上述規則不適用或失敗時，**重新評估診斷並考慮替代治療**；指引只是建議，治療要依個別病人調整

## What to do：Class I 建議總整理

| 主題 | 必做 |
| --- | --- |
| **初步評估診斷** | VVS、situational、OH、arrhythmic（ECG 標準）、ischemic、structural cardiopulmonary 的診斷標準（見 ①） |
| **ED** | Low-risk 出院；high-risk 早期密集評估或住院；neither 觀察不住院（見 ②） |
| **CSM** | > 40 歲、符合 reflex 機轉；重現症狀 → CSS |
| **Active standing** | 平躺與站立 3 分鐘量 BP、HR；重現症狀的 OH → 確診 |
| **ABPM** | Autonomic failure 找 nocturnal hypertension |
| **ECG monitoring** | High-risk 住院監測；**ILR 兩個 I-A**；症狀－心律相關 → 確診 |
| **EPS** | 舊 MI／scar；**HV ≥ 70 ms → pacemaker**；誘發 monomorphic VT 依 VA 指引；無心臟病＋心悸誘發快速 SVT／VT 給治療 |
| **Echo** | 懷疑 structural heart disease；HCM＋syncope＋gradient < 50 → exercise echo；典型 AS、腫瘤、tamponade、dissection → 診斷 |
| **Exercise test** | 運動中或剛運動後昏倒；運動誘發 2°／3° AV block → 確診；運動後重現 syncope＋嚴重低血壓 → reflex |
| **Reflex 與 OH 治療** | 衛教、安心；OH 補充水分與鹽分 |
| **Arrhythmia 治療** | SSS 或 AV block 與 syncope 相關 → pacing；intermittent 2°／3° AVB（含 slow AF）→ pacing；BBB＋EPS 陽性或 ILR 記錄 AVB → pacing；SVT／VT → ablation；VT＋EF ≤ 35% → ICD；MI＋EPS 誘發 VT → ICD |
| **SCD 高風險 unexplained syncope** | LV dysfunction 依 ICD 指引（I-A）；HCM 依 HCM Risk-SCD 決定 ICD |
| **老人** | 多面向評估；認知與身體功能測試 |
| **神經學** | Autonomic failure、懷疑 epilepsy → 神經學評估；parkinsonism、ataxia、認知障礙 → MRI；急性多系統 autonomic failure → 抗體篩檢 |

## What not to do：Class III 建議

| 不要做 | 等級 |
| --- | --- |
| **Beta-blocker 治療 reflex syncope** | **III-A** |
| **沒有記錄到 cardioinhibitory reflex 就放 pacemaker**（reflex syncope） | **III-B** |
| **Bradycardia 有可逆原因時放 pacemaker** | **III-C** |
| **EEG、頸動脈超音波、腦部 CT 或 MRI 當 syncope 的常規檢查** | **III-B** |

> [!danger] 必背的 Class III
> **==Reflex syncope 不用 beta-blocker（III-A）==**；**==沒有 cardioinhibition 證據不放 pacemaker==**；**==Syncope 不做 EEG、carotid duplex、brain CT／MRI==**。
