> [!abstract] 一句話重點
> 醒來後 **prolonged confusion（postictal period）** 是 nonsyncopal TLOC 的 **pivotal clue**。Seizure 最 specific 的線索是 **tongue laceration、head turning、unusual posturing**（specificity 97%、LR+ 12–15）；**沒有 postictal confusion 就不太像 generalized seizure（LR− 0.09）**。**Limb jerking 不 specific**：15–90% 的 syncope 也會抽動（**convulsive syncope**）。**Carotid artery obstruction 不會造成 syncope**，syncope 病人不需要評估 anterior circulation。

## 三個主要 mimics 一覽

| 鑑別 | 支持的線索 | 重要檢查 |
| --- | --- | --- |
| **Seizure** | **Prolonged lethargy、confusion、amnesia（postictal）**；tonic-clonic activity；incontinence；**tongue laceration**；prior stroke、CNS tumor 或神經疾病；abnormal neurologic exam | **EEG**；contrast CT 或 **MRI** |
| **Hypoglycemia** | **用 insulin、sulfonylureas 或 thiazolidinediones 的 DM 病人**；之前有 confusion 或交感症狀（tremulousness、nervousness、diaphoresis） | **事件當下的 glucose** |
| **Cerebrovascular event（posterior circulation）** | Hypertension、AF、DM、tobacco；**伴隨 brainstem 症狀**（diplopia、vertigo、ataxia、weakness） | CT、MRI、MRA |
| Intoxication | Alcohol 或 drug use | Alcohol level、toxicology screen |

> [!tip] Pearl
> 問病人：「**你記得的下一件事是什麼？**」**不記得救護車、事後 amnesia > 5 分鐘** → 要評估 seizure。

## Seizure

### Textbook presentation

Generalized seizure 典型是 **tonic-clonic activity、失去意識與 postural tone、incontinence，以及很長的 postictal lethargy**。這裡的重點是分辨 seizure 與 syncope。

### Disease highlights

- 美國 3% 的人一生中會有一次 seizure
- Seizure 占 TLOC（可能模仿 syncope）的 1–7%
- **> 60 歲 seizure 的病因**：idiopathic 35%、**ischemic 49%**、CNS tumor 11%（約 1/3 primary、2/3 metastatic）、CNS trauma 3%、CNS infection 2%
- 其他原因：
  - Metabolic：hypoglycemia 與嚴重 hyperglycemia、hypoxia、**hyponatremia、hypocalcemia**、uremia
  - 藥物：很多，常見的有 cyclosporine、fentanyl、meperidine、lidocaine、phenothiazines、quinolones、theophylline、TCA、**bupropion**
  - Illicit drugs：MDMA、cocaine
  - **Withdrawal**：alcohol、baclofen、benzodiazepines、opioids

### Evidence-based diagnosis

**Seizure 的 history 線索**（依原書 Table 31-7 重新整理）：

| Clinical feature | Sensitivity | Specificity | LR+ | LR− |
| --- | --- | --- | --- | --- |
| **==Cut tongue==** | 45% | 97% | **15** | 0.57 |
| **Head turning** | 43% | 97% | **14** | 0.59 |
| **Unusual posturing** | 35% | 97% | **12** | 0.67 |
| Bedwetting | 24% | 96% | 6.4 | 0.79 |
| Limb jerking noted by others | 69% | 88% | 5.8 | 0.35 |
| Prodromal trembling | 29% | 94% | 4.8 | 0.76 |
| Prodromal preoccupation | 8% | 98% | 4.0 | 0.94 |
| Prodromal hallucinations | 8% | 98% | 4.0 | 0.94 |
| **Postictal confusion** | **94%** | 69% | 3.0 | **==0.09==** |

**讓 seizure 變不可能的症狀**（出現就降低 seizure 機率）：

| 症狀 | LR |
| --- | --- |
| Diaphoresis preceding spell | 0.17 |
| Chest pain preceding spell | 0.15 |
| Palpitations | 0.12 |
| Dyspnea prior to spell | 0.08 |
| CAD | 0.08 |
| **Syncope with prolonged standing** | **0.05** |

> [!tip] Pearl
> - **Tongue laceration、head turning、unusual posturing** → 最 specific，**rule in seizure**
> - **沒有 postictal confusion** → 大多數 generalized seizure 都有，**沒有就 rule out**（LR− 0.09）

### Convulsive syncope

1. **Limb jerking 對 seizure 不 specific**
2. **15–90% 與 seizure 無關的 syncope 也會出現 limb jerking**，稱為 **convulsive syncope**；這是 **myoclonic jerks**，要和 tonic-clonic activity 區分：

| | Myoclonic jerks（convulsive syncope） | Tonic-clonic activity（seizure） |
| --- | --- | --- |
| 節律與對稱 | **Arrhythmic、asymmetric** | Rhythmic、symmetric |
| 持續時間 | **短**（平均 6.6 秒） | 長（約 1 分鐘） |
| 與倒下的時間關係 | **==絕不會在倒下前出現==** | 可以在倒下前出現 |
| Postictal period | **沒有明顯 postictal period（< 1 分鐘）** | 通常有明顯 postictal period |

3. **看起來是 refractory「seizure disorder」、EEG 只有 nonspecific 異常的病人，要做 cardiac evaluation**，排除 convulsive syncope

### 區分 seizure 與 syncope 的 point score

**≥ 1 分提示 seizure**（sensitivity 94%、specificity 94%、LR+ 16、LR− 0.06）（依原書 Table 31-8 重新整理）：

| 加分 | 分數 | 減分 | 分數 |
| --- | --- | --- | --- |
| **醒來時 tongue 有傷口** | **+2** | Any presyncope | −2 |
| 異常行為（limb jerking、prodromal trembling、preoccupation、hallucinations） | +1 | **LOC with prolonged standing** | −2 |
| LOC with emotional stress | +1 | **Diaphoresis before a spell** | −2 |
| Postictal confusion | +1 | | |
| Head turning to one side | +1 | | |
| Prodromal déjà vu | +1 | | |

### 評估

| 檢查 | 重點 |
| --- | --- |
| **EEG** | 懷疑 seizure 時做；**發作間期 sensitivity 低（35–50%）**，sleep deprivation 可提高；specificity 98% |
| **Neuroimaging** | **37% 成人 new-onset seizure 有 structural lesion**（tumor、stroke），即使沒有 focal neurologic findings 也有 15%；**所有成人 new-onset seizure 都要做**；急性時常先做 noncontrast CT 排除 intracranial bleed，**之後做 MRI**（對 tumor 與 stroke 較敏感） |
| Tilt-table | 診斷不確定時幫忙分辨：**重現症狀＋hypotension → syncope** |
| ILR | 用在懷疑但未證實 seizure、藥物治療無效的人：**26% 記錄到 arrhythmia** |
| 抽血 | **Sodium、calcium、glucose、BUN、creatinine、oxygen saturation** |
| **LP** | 懷疑 CNS infection 時（immunocompromised、fever、meningismus、headache 或 persistent confusion）；**先用 neuroimaging 排除 increased ICP** 以免 herniation；**先查 platelet、PT、PTT**（thrombocytopenia 與 coagulopathy 增加穿刺處出血、spinal cord compression 的風險） |
| Toxicology screen | 懷疑 illicit drug 時 |

治療：anticonvulsant therapy 複雜且變化快，參考 neurology 教材。

## Hypoglycemia

- **用 insulin、sulfonylureas 或 thiazolidinediones 的 DM 病人**幾乎才會發生
- Hypoglycemia-induced TLOC 之前通常有 **confusion** 或交感刺激症狀（tremulousness、nervousness、diaphoresis）
- **沒處理就自己恢復**、事件當下 **glucose 正常** → 基本上排除

## Cerebrovascular disease 與 syncope

> [!warning] Pitfall：不要做 carotid Doppler 找 syncope 的原因
> 臨床上常把 carotid obstruction 放進 syncope 的鑑別，但 **syncope 需要 transient ==global== cerebral hypoperfusion**，**單側 carotid 阻塞不會造成 syncope**。所以 **==syncope 病人不需要評估 anterior circulation==**。

- **Posterior circulation 阻塞**可能造成 TLOC（reticular activating system ischemia）：**subclavian steal syndrome、vertebrobasilar insufficiency、basilar artery occlusion**
  - **幾乎都伴隨 neurologic signs 或症狀**
  - Syncope 合併 brainstem 症狀（**diplopia、vertigo、ataxia、weakness**）時要考慮
- **Subarachnoid hemorrhage** 可以 syncope 表現，但**幾乎都同時有 severe headache 或 confusion** → **緊急 noncontrast head CT**
