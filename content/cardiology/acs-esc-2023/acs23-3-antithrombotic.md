> [!abstract] 一句話重點
> **Aspirin 150–300 mg LD → 75–100 mg qd（I A）＋P2Y12 inhibitor 12 個月（I A）**：**prasugrel**（P2Y12-naïve、要做 PCI；60 → 10 mg，**≥ 75 歲或 < 60 kg 用 5 mg**、**中風史禁用**）或 **ticagrelor**（不論侵入或保守；180 → 90 mg bid）；**clopidogrel**（300–600 → 75 mg）只在前兩者不能用時。**==NSTE-ACS 預計 24 小時內攝影 → 不常規預先給 P2Y12（III A）==**；**GP IIb/IIIa 不預先給（III A）**。**抗凝：診斷時就給（I A）**；PCI 時 **UFH 70–100 U/kg**；**NSTE-ACS 不會 24 小時內攝影 → fondaparinux 2.5 mg qd（I B）**，但 **STEMI 做 PPCI 不用 fondaparinux（III B）**。**Fibrinolysis**：aspirin＋**clopidogrel**，抗凝首選 **enoxaparin**。**ACS＋AF**：**triple 最多 1 週 → NOAC＋clopidogrel 到 12 個月 → 只剩 NOAC（I A／I B）**；**triple 不用 ticagrelor 或 prasugrel（III C）**。**頭 30 天不降階（III B）**。

## 劑量（Table 6）

| 藥物 | 劑量 | 注意 |
| --- | --- | --- |
| **Aspirin** | **LD 150–300 mg PO**（或 75–250 mg IV）→ **75–100 mg qd** | CKD 不調整 |
| **Clopidogrel** | **LD 300–600 mg → 75 mg qd** | Fibrinolysis 時：**300 mg（> 75 歲 75 mg）** |
| **Prasugrel** | **LD 60 mg → 10 mg qd** | **< 60 kg → 5 mg**；**≥ 75 歲**小心，必要時 5 mg；**==中風史禁用==** |
| **Ticagrelor** | **LD 180 mg → 90 mg bid** | CKD 不調整 |
| Cangrelor | 30 µg/kg IV bolus → 4 µg/kg/min ≥ 2 h 或手術全程 | 轉口服：停後給 clopidogrel 600 或 prasugrel 60；ticagrelor 180 在 PCI 時給 |
| Eptifibatide | 180 µg/kg 兩次 bolus（間隔 10 分）→ 2 µg/kg/min 最多 18 h | CrCl 30–50 減量；ESRD、ICH 史、30 天內中風、PLT < 100k 禁用 |
| Tirofiban | 25 µg/kg（3 分鐘）→ 0.15 µg/kg/min 最多 18 h | CrCl ≤ 60 維持減半 |
| **UFH** | **70–100 U/kg IV bolus** → 滴注維持 **aPTT 60–80 s**；PCI 時依 ACT | — |
| **Enoxaparin** | **1 mg/kg SC bid**（至少 2 天到穩定）；**CrCl < 30 → 1 mg/kg qd** | PCI：上一劑 > 8 h → 加 0.3 mg/kg IV |
| Bivalirudin | PPCI：0.75 mg/kg IV → 1.75 mg/kg/h 到術後 4 h；CrCl < 30 → 1 mg/kg/h | — |
| **Fondaparinux** | **2.5 mg SC qd** | PCI 時要加一劑 **UFH**；**CrCl < 20 避免** |

### 抗血栓藥作用在哪裡（Figure 9 依內容重新整理）

斑塊**破裂或侵蝕** → 一路是 **tissue factor（TF：FVIIa）→ FXa → thrombin → fibrin**（凝血），一路是**血小板活化 → 聚集**，兩者合成成熟的 fibrin 血栓。

| 標的 | 藥物（口服／針劑） |
| --- | --- |
| **TxA₂（COX-1）** | **Aspirin**（口服） |
| **P2Y12 receptor（ADP）** | **Clopidogrel、ticagrelor、prasugrel**（口服）；**cangrelor**（IV） |
| **GP IIb/IIIa**（血小板聚集最後一步） | **Eptifibatide、tirofiban**（IV） |
| **FXa** | **Rivaroxaban、apixaban、edoxaban**（口服）；**fondaparinux**（SC） |
| **FXa＋thrombin** | **UFH**（兩者都抑制）、**enoxaparin**（以 FXa 為主） |
| **Thrombin（直接）** | **Dabigatran**（口服）；**bivalirudin**（IV） |

## 抗血小板

| 建議 | 等級 |
| --- | --- |
| **Aspirin**：所有病人 LD 150–300 mg（IV 75–250 mg），MD 75–100 mg 長期 | **I A** |
| **所有 ACS：aspirin＋P2Y12 inhibitor 12 個月**（除非高出血風險） | **I A** |
| **高 GI 出血風險 → DAPT 加 PPI** | **I A** |
| **Prasugrel**：P2Y12-naïve、要做 PCI | I B |
| **Ticagrelor**：不論侵入或保守策略 | I B |
| **Clopidogrel**：prasugrel 或 ticagrelor 拿不到、不耐受或禁忌 | I C |
| 為 CABG 停 DAPT → **術後恢復至少 12 個月** | I C |
| **==不預先給 GP IIb/IIIa==** | **III A** |
| **==NSTE-ACS、解剖未知、預計 < 24 h 攝影 → 不常規預先給 P2Y12==** | **III A** |
| **頭 30 天不降階抗血小板** | **III B** |

### 預設抗血栓組合（Figure 10 依內容重新整理，沒有 OAC 適應症）

| 項目 | STEMI（PPCI） | NSTE-ACS |
| --- | --- | --- |
| **抗凝** | **UFH（I）**；enoxaparin、bivalirudin（IIa）；**fondaparinux（III）** | 攝影 < 24 h：**UFH（I）**、enoxaparin（IIa）｜攝影 > 24 h：**fondaparinux（I）** |
| **預先給 aspirin** | **所有 ACS（I）** | 同左 |
| **預先給 P2Y12** | **可考慮（IIb）** | **解剖未知、預計 < 24 h 攝影 → 不建議（III）**；不會 < 24 h 攝影、沒有高出血風險 → 可考慮 |
| **P2Y12 選擇** | **Prasugrel 或 ticagrelor（I）**；不能用才 clopidogrel｜**要做 PCI → prasugrel 優於 ticagrelor（IIa）** | 同左 |
| **前 12 個月** | **Aspirin＋P2Y12（DAPT，I）** | 同左 |
| **12 個月後** | **Aspirin 單一（I）** | 同左 |

- **Fondaparinux** 用在 NSTE-ACS **保守治療**或無法 24 h 內轉院 PCI 時（PCI 時加一劑 UFH）
- **Clopidogrel**：prasugrel、ticagrelor 不能用時，也**可考慮用於老人（約 > 70–80 歲）**

### 降低出血的替代策略（Figure 11 依內容重新整理）

| 策略 | 做法 |
| --- | --- |
| **縮短 DAPT**（高出血風險） | **DAPT 1 個月** → **P2Y12 inhibitor 或 aspirin 單一治療**到 12 個月 |
| **縮短 DAPT**（高或非高出血風險） | **DAPT 3 個月或 6 個月** → **單一抗血小板**到 12 個月 |
| **降階（de-escalation）** | 從 aspirin＋**prasugrel 或 ticagrelor** → 換成 **aspirin＋clopidogrel**（**30 天內不降階**） |

> - **Ticagrelor 或 prasugrel 為首選 P2Y12**；clopidogrel 留給不能耐受或拿不到的人
> - 標準 DAPT 仍是 **12 個月**
> - **新的 Class 1**：有出血風險時，**DAPT 1 個月後改 ticagrelor 單一治療**

### 降低 PCI 出血風險（Table 7）

- **抗凝劑依體重與腎功能給藥**，尤其**女性與老人**
- **Radial access** 為預設
- **DAPT 的病人加 PPI**（GI 出血高風險：GI 潰瘍或出血史、抗凝、長期 NSAID 或類固醇，或以下兩項以上：**≥ 65 歲、消化不良、GERD、H. pylori、長期喝酒**）
- 服 OAC 的病人：PCI 時**不中斷 VKA 或 NOAC**；**VKA 病人 INR > 2.5 不加 UFH**；**NOAC 病人不管最後一劑何時，都加低劑量 UFH**（enoxaparin 0.5 mg/kg 或 UFH 60 IU/kg）
- **Aspirin 照給**，但**避免預先給 P2Y12 inhibitor**
- **GP IIb/IIIa 只用在 bail-out 或 PCI 周邊血栓併發症**

## 抗凝

| 建議 | 等級 |
| --- | --- |
| **所有 ACS 診斷時就給 parenteral 抗凝** | **I A** |
| **PCI 時 UFH bolus 70–100 IU/kg** | I C |
| **STEMI 做 PPCI → 不用 fondaparinux** | **III B** |
| **==NSTE-ACS、不會 24 小時內攝影 → fondaparinux==** | **I B** |

## Fibrinolysis 合併用藥

| 建議 | 等級 |
| --- | --- |
| **Aspirin＋clopidogrel** | **I A** |
| 抗凝到再通或住院期間（**最多 8 天**） | I A |
| **==Enoxaparin（IV 再 SC）為首選抗凝==** | **I A** |
| 沒有 enoxaparin → UFH（依體重 bolus＋滴注） | I B |

## 需要口服抗凝的病人（Figure 12）

| 建議 | 等級 |
| --- | --- |
| **==AF（CHA₂DS₂-VASc 男 ≥ 1、女 ≥ 2）：triple 最多 1 週 → NOAC（中風預防劑量）＋單一抗血小板（首選 clopidogrel）到 12 個月==** | **I A** |
| PCI 時加 UFH bolus：**服 NOAC**，或 **VKA 而 INR < 2.5** | I C |
| **Triple therapy 不用 ticagrelor 或 prasugrel** | **III C** |
| **12 個月後停抗血小板**（只剩 OAC） | I B |

**Figure 12 依內容重新整理**（ACS＋需要 OAC）：

| 時間 | 預設策略 | 缺血風險高時 |
| --- | --- | --- |
| **0 → 最多 1 週** | **TAT：(N)OAC＋DAPT（I）** | **TAT 延長到最多 1 個月（IIa）** |
| **1 週 → 6 個月** | **DAT：(N)OAC＋SAPT（I）** | DAT：(N)OAC＋SAPT（I） |
| **6 → 12 個月** | **DAT（I）**，或 **只用 (N)OAC（IIb）** | DAT（I） |
| **12 個月後** | **只用 (N)OAC（I）** | 只用 (N)OAC（I） |

- **NOAC 優於 VKA**；SAPT **首選 P2Y12 inhibitor（通常 clopidogrel）**而非 aspirin
- TAT 與 DAT 時 NOAC 用中風預防劑量：**apixaban 5 mg bid、dabigatran 110 或 150 mg bid、edoxaban 60 mg qd、rivaroxaban 15 或 20 mg qd**（符合減量條件才減）
- **PRECISE-DAPT ≥ 25** 視為高出血風險
