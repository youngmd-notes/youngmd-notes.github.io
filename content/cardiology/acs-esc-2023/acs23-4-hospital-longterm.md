> [!abstract] 一句話重點
> **住院**：高風險（所有 STEMI、very high-risk NSTE-ACS）**ECG 監測 ≥ 24 h**、CCU ≥ 24 h。**AF**：沒有 HF 或低血壓 → **IV beta-blocker**；有急性 HF、沒有低血壓 → **IV amiodarone**；不穩定 → **電擊**。**多形性 VT／VF → IV beta-blocker 和／或 amiodarone＋完全再通**；**沒症狀的心室心律不整不用抗心律不整藥（III）**。**高度 AV block → atropine、腎上腺素 → 暫時起搏；MI 後 ≥ 5 天仍未恢復才放永久起搏器**。**長期**：**心臟復健（I A）**、**==高劑量 statin 盡早（I A），LDL-C < 55 mg/dL 且下降 ≥ 50%（I A）==** → 4–6 週未達標加 **ezetimibe** → 再加 **PCSK9i**；**LVEF ≤ 40% → beta-blocker、ACE-I、MRA（有 HF 或糖尿病）（I A）**；**流感疫苗（I A）**；出院前 LVEF ≤ 40% → **6–12 週後再評估 ICD**。

## 住院處置（Section 8）

| 建議 | 等級 |
| --- | --- |
| 照顧高風險病人的醫院要有 ICCU／CCU | I C |
| **高風險（所有 STEMI、very high-risk NSTE-ACS）ECG 監測 ≥ 24 h** | I C |
| 再灌流成功、沒有併發症的高風險病人 → **CCU ≥ 24 h**，之後監測病床再 24–48 h | I C |

## 併發症（Section 12）

| 併發症 | 建議 | 等級 |
| --- | --- | --- |
| **AF** | 需要控速、**沒有急性 HF 或低血壓 → IV beta-blocker** | I C |
| | 需要控速、**有急性 HF、沒有低血壓 → IV amiodarone** | I C |
| | **血行動力不穩或藥物無法及時控速 → 立即電擊** | I C |
| | 不穩定的新發 AF：**IV amiodarone 幫助電擊、減少早期復發** | I C |
| **心室心律不整** | **多形性 VT 和／或 VF → IV beta-blocker 和／或 amiodarone** | I B |
| | 反覆 VT/VF → **迅速完全再通**治療缺血 | I C |
| | **沒症狀、不影響血行動力的心室心律不整 → 不用抗心律不整藥** | **III C** |
| | **ICD**：有症狀 HF（NYHA II–III）、**LVEF ≤ 35%**、OMT > 3 個月、**MI 後 ≥ 6 週**、預期存活 > 1 年 | I A |
| **Bradyarrhythmia** | 竇性心搏過緩不耐受或高度 AV block 沒有穩定逸搏 → **IV 正向變時藥物（adrenaline、vasopressin、atropine）**；**atropine 無效 → 暫時起搏**；沒做過再灌流 → **緊急攝影** | I C |
| | **高度 AV block 等待 ≥ 5 天仍未恢復 → 永久起搏器** | I C |
| | **再通後或自行恢復 → 不放起搏器** | **III B** |

## 特殊族群

| 族群 | 建議 | 等級 |
| --- | --- | --- |
| **CKD** | **低或等滲顯影劑、最少量** | I A |
| | 所有 ACS 用 **eGFR** 評估腎功能；**診斷治療策略與腎功能正常者相同**（必要時調劑量） | I C |
| **糖尿病** | 依共病（**HF、CKD、肥胖**）選長期降糖藥 | I A |
| | 初次評估都要看血糖狀態；已知 DM 或高血糖（**≥ 200 mg/dL**）→ 常測血糖 | I B／I C |
| **老人** | **與年輕人用相同的診斷與治療策略** | I B |
| | 依腎功能、共用藥、共病、衰弱、認知調整藥物 | I B |
| **癌症** | 高風險 ACS、**預期存活 ≥ 6 個月 → 侵入性策略** | I B |
| | 懷疑癌症治療造成 ACS → **暫停癌症治療** | I C |
| | **PLT < 10,000 不給 aspirin**；**< 30,000 不給 clopidogrel**；**< 50,000 不給 prasugrel、ticagrelor** | III C |

## 長期治療（Section 13、Figure 17–18）

| 建議 | 等級 |
| --- | --- |
| **所有 ACS 參加運動為主的心臟復健** | **I A** |
| **戒菸**、地中海飲食、限酒、規律有氧與阻力運動 | I B |
| **==高劑量 statin 盡早開始或繼續，不論 LDL-C==** | **I A** |
| **==LDL-C < 1.4 mmol/L（< 55 mg/dL）且下降 ≥ 50%==** | **I A** |
| 最大耐受 statin **4–6 週**未達標 → **加 ezetimibe** | I B |
| statin＋ezetimibe 4–6 週仍未達標 → **加 PCSK9 inhibitor** | I A |
| 2 年內再發血管事件 → **LDL-C < 1.0 mmol/L（< 40 mg/dL）** | IIb B |
| 住院期間就合併高劑量 statin＋ezetimibe | IIb B |
| **Beta-blocker：LVEF ≤ 40%（不論有無 HF 症狀）** | **I A** |
| 所有 ACS 常規 beta-blocker（不論 LVEF） | IIa B |
| **ACE-I：有 HF 症狀、LVEF ≤ 40%、糖尿病、高血壓或 CKD** | **I A** |
| **MRA：LVEF ≤ 40% 且有 HF 或糖尿病** | **I A** |
| 出院前 **LVEF ≤ 40% → 6–12 週後再評估 LVEF**（決定初級預防 ICD） | I C |
| **流感疫苗** | **I A** |
| Polypill 增加服藥順從性 | IIa B |

- **Colchicine 0.5 mg qd**：COLCOT（近期 ACS 4,745 人）降低複合心血管事件，但**肺炎較多**（建議等級見原文）

## 以病人為中心（Section 14）

- **尊重病人偏好、需求與信念**，讓病人參與決策並告知風險、輻射、替代方案；用決策輔助工具（I B）
