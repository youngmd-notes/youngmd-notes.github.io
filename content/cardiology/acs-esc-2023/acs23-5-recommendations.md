> [!abstract] 一句話重點
> 最常考的「不要做」：**SpO₂ > 90% 給常規氧氣**、**NSTE-ACS 預計 24 小時內 cath 卻常規 P2Y12 pretreatment**、**GP IIb/IIIa pretreatment**、**STEMI PPCI 用 fondaparinux**、**常規 thrombus aspiration**、**心因性休克常規 IABP**、**> 48 小時且沒症狀還去打通閉塞的 IRA**、**三合一抗栓用 ticagrelor／prasugrel**、**前 30 天降階抗血小板**。必做的骨架：**ECG < 10 分鐘、hs-cTn 0／1 h**、**PPCI 能在 120 分鐘內做就不打 fibrinolysis**、**DAPT 12 個月**、**高強度 statin、LDL < 55**、**LVEF ≤ 40% 給 beta-blocker、ACE-I、MRA**。

## Table 9：「不要做」清單（全部 Class III）

先把所有 Class III 一次看完，這些最容易出成「何者錯誤」：

| 不要做 | 等級 |
| --- | --- |
| 疑似 ACS 常規早期做 CCTA | III-B |
| ==SpO₂ > 90% 給常規氧氣== | III-A |
| ==STEMI 發作 > 48 小時、沒有持續症狀 → 常規 PCI 打通閉塞的 IRA== | III-A |
| ==Pretreatment 給 GP IIb/IIIa inhibitor== | III-A |
| ==NSTE-ACS 還不知道冠狀動脈解剖、預計 < 24 小時 cath → 常規 P2Y12 pretreatment== | III-A |
| ==STEMI 做 PPCI 用 fondaparinux== | III-B |
| ==三合一抗栓裡用 ticagrelor 或 prasugrel== | III-C |
| ACS 後**前 30 天**降階抗血小板（de-escalation） | III-B |
| 心跳停止救回、血行穩定、沒有持續 ST elevation → 常規立即 cath | III-A |
| ==ACS 心因性休克、沒有機械性併發症 → 常規 IABP== | III-B |
| ==常規 thrombus aspiration== | III-A |
| Index PCI 時對 IRA 的非罪犯節段做侵入性功能評估 | III-C |
| 高度 AV block 在再通後或自行恢復 → 還放永久節律器 | III-B |
| 沒症狀、不影響血行的心室心律不整 → 用抗心律不整藥 | III-C |
| **癌症病人血小板 < 10,000/μL → aspirin** | III-C |
| **癌症病人血小板 < 30,000/μL → clopidogrel** | III-C |
| **癌症病人血小板 < 50,000/μL → prasugrel 或 ticagrelor** | III-C |

> [!tip] Pearl：癌症血小板門檻「10–30–50」
> 抗血小板越強，能接受的血小板下限越高：**aspirin 10k → clopidogrel 30k → prasugrel／ticagrelor 50k**（低於就不給）。

## Table 9：「必做」清單（Class I，依主題）

> 原圖見上方「不要做」清單下的 Table 9 原圖（共 6 段）。

### 診斷與初步評估

| 必做 | 等級 |
| --- | --- |
| 疑似 STEMI → **立刻分流去緊急再灌流** | I-A |
| 用病史、症狀、生命徵象、理學檢查、ECG 與 hs-cTn 一起診斷與做短期風險分層 | I-B |
| ==First medical contact 後盡快做 12-lead ECG 並判讀，目標 < 10 分鐘== | I-B |
| 疑似 STEMI、其他 ECG 變化或持續胸痛、確診 MI → **連續心電監測並備好電擊器** | I-B |
| Inferior STEMI，或懷疑血管完全閉塞但標準導程看不出來 → 加做 **V3R、V4R、V7–V9** | I-B |
| 症狀復發或診斷不確定 → 再做一次 12-lead ECG | I-C |
| ==到院立刻抽 hs-cTn，60 分鐘內拿到結果== | I-B |
| 用 ESC 演算法（**0 h／1 h 或 0 h／2 h**）連續 hs-cTn rule in／rule out NSTEMI | I-B |
| 0 h／1 h 前兩次都不確定、又沒有其他診斷 → **3 小時後再驗** | I-B |
| 疑似 ACS 合併心因性休克或懷疑機械性併發症 → **緊急 TTE** | I-C |

### 院前與到院初步處置

| 必做 | 等級 |
| --- | --- |
| STEMI 院前處置建立區域網絡，讓越多人能做 PPCI | I-B |
| PPCI 中心 **24/7** 都能立即做 | I-B |
| 轉院做 PPCI → **跳過急診與 CCU，直接進 cath room** | I-B |
| **低血氧（SaO₂ < 90%）才給氧氣** | I-C |
| EMS 把疑似 STEMI 直接送 PCI 中心，跳過非 PCI 醫院 | I-C |
| 救護團隊會判讀急性冠狀動脈閉塞的 ECG，並能電擊、必要時打 fibrinolysis | I-C |
| 所有醫院與 EMS 記錄並稽核延遲時間 | I-C |

### 再灌流（STEMI）

| 必做 | 等級 |
| --- | --- |
| Working diagnosis 是 STEMI（持續 ST elevation 或等同）且症狀 **≤ 12 小時** → 再灌流 | I-A |
| ==預計從診斷到 PCI < 120 分鐘 → PPCI 優於 fibrinolysis== | I-A |
| 無法在 120 分鐘內 PPCI → 症狀 12 小時內、無禁忌 → **fibrinolysis** | I-A |
| ==Fibrinolysis 失敗（60–90 分鐘內 ST 下降 < 50%）或血行／電性不穩、缺血惡化、持續胸痛 → rescue PCI== | I-A |
| 症狀 > 12 小時，但仍有缺血症狀、血行不穩或致命心律不整 → PPCI | I-C |

### Fibrinolysis 之後

| 必做 | 等級 |
| --- | --- |
| 打完 fibrinolysis **所有人立刻轉 PCI 中心** | I-A |
| 打完後新發或持續 HF／休克 → 緊急 cath＋IRA PCI | I-A |
| ==Fibrinolysis 成功後 2–24 小時內 cath＋IRA PCI== | I-A |

### Fibrinolysis 本身

| 必做 | 等級 |
| --- | --- |
| 選 fibrinolysis 時，**院前**診斷後盡快打，**目標 < 10 分鐘打 bolus** | I-A |
| 用 fibrin-specific 藥（tenecteplase、alteplase、reteplase） | I-B |
| 併用 **aspirin＋clopidogrel** | I-A |
| 抗凝到再通（若有做）或住院期間（最多 8 天） | I-A |
| 抗凝首選 **enoxaparin IV 再 SC** | I-A |
| 沒有 enoxaparin → UFH 依體重 IV bolus＋infusion | I-B |

### NSTE-ACS 侵入性策略

| 必做 | 等級 |
| --- | --- |
| 有**高風險**特徵或高度懷疑 unstable angina → 住院期間做侵入性策略 | I-A |
| 沒有極高／高風險、ACS 可能性低 → 選擇性侵入（selective invasive） | I-A |
| ==有任一極高風險特徵 → 立即侵入性策略（< 2 小時）==：血行不穩或心因性休克、藥物無效的反覆或難治胸痛、住院中致命心律不整、MI 機械性併發症、推測由缺血造成的 acute HF、反覆動態 ST-T 變化（尤其間歇性 ST elevation） | I-C |

### 抗血小板

| 必做 | 等級 |
| --- | --- |
| **Aspirin**：LD 150–300 mg PO（或 75–250 mg IV），MD 75–100 mg qd 長期 | I-A |
| ==所有 ACS：aspirin＋P2Y12 inhibitor，DAPT 12 個月==（除非出血風險高） | I-A |
| DAPT 且 GI 出血風險高 → 加 **PPI** | I-A |
| **Prasugrel**：沒用過 P2Y12、要做 PCI → LD 60 mg、MD 10 mg qd；**≥ 75 歲或體重 < 60 kg → 5 mg qd** | I-B |
| **Ticagrelor**：不論侵入或保守 → LD 180 mg、MD 90 mg bid | I-B |
| **Clopidogrel**：prasugrel／ticagrelor 沒有、不耐受或禁忌時 → LD 300–600 mg、MD 75 mg qd | I-C |
| 為了 CABG 停 DAPT → 術後恢復 DAPT，至少滿 12 個月 | I-C |

### 抗凝

| 必做 | 等級 |
| --- | --- |
| 所有 ACS **診斷時**就開始 parenteral anticoagulation | I-A |
| 做 PCI → 常規 **UFH bolus 70–100 IU/kg IV** | I-C |
| ==NSTE-ACS 預計 24 小時內不會 cath → fondaparinux== | I-B |
| 在吃 NOAC，或 VKA 但 INR < 2.5 → PCI 時加 UFH bolus | I-C |

### 抗血小板＋OAC

| 必做 | 等級 |
| --- | --- |
| ==AF（CHA₂DS₂-VASc 男 ≥ 1、女 ≥ 2）：三合一最多 1 週 → NOAC（中風預防劑量）＋單一抗血小板（首選 clopidogrel）最多 12 個月== | I-A |
| 有 OAC 的人，**12 個月後停抗血小板**（單用 OAC） | I-B |

### 心跳停止

| 必做 | 等級 |
| --- | --- |
| 救回且 ECG 持續 ST elevation（或等同）→ **PPCI** | I-B |
| 院內或院外心跳停止、ROSC 後仍昏迷 → **溫度控制**（持續監測核心體溫，主動預防發燒 > 37.7°C） | I-B |
| 疑似 ACS 的心跳停止救回者由專門 EMS 直送 24/7 PPCI 醫院 | I-C |
| 昏迷存活者評估神經預後，**入院 72 小時後才評估** | I-C |

### 心因性休克

| 必做 | 等級 |
| --- | --- |
| ACS 併休克 → **立即 cath＋IRA PCI** | I-B |
| IRA 無法 PCI 或失敗 → 緊急 CABG | I-B |
| 血行不穩的機械性併發症 → Heart Team 討論後緊急手術或導管修補 | I-C |

### 住院照護

| 必做 | 等級 |
| --- | --- |
| 照顧高風險病人的醫院要有 ICCU／CCU | I-C |
| 高風險（所有 STEMI、極高風險 NSTE-ACS）→ **心電監測至少 24 小時** | I-C |
| 高風險但再灌流成功、病程平順 → CCU 至少 24 小時，再到 step-down 監測床 24–48 小時 | I-C |

### 侵入性技術

| 必做 | 等級 |
| --- | --- |
| **Radial access** 為標準 | I-A |
| PPCI 時 IRA 放支架 | I-A |
| ==一律用 DES（不用 BMS）== | I-A |
| **SCAD**：只有持續缺血、大範圍心肌受威脅且前向血流下降才 PCI | I-C |

### 多條血管病變

| 必做 | 等級 |
| --- | --- |
| 依臨床狀況、共病與病變複雜度決定 IRA PCI、多條 PCI 或 CABG | I-B |
| ==心因性休克 → index 只做 IRA== | I-B |
| ==血行穩定的 STEMI → 完全再通，在 index PCI 或 45 天內完成== | I-A |
| 非 IRA 的 PCI 依血管攝影嚴重度決定 | I-B |

### MINOCA

| 必做 | 等級 |
| --- | --- |
| Cath 後診斷仍不清楚 → **CMR** | I-B |
| 依最終診斷按相關指引治療 | I-B |
| 所有 working diagnosis 為 MINOCA 者，依診斷流程找出最終診斷 | I-C |

### 併發症：AF

| 必做 | 等級 |
| --- | --- |
| 需要 rate control、沒有 acute HF 或低血壓 → **IV beta-blocker** | I-C |
| 需要 rate control、有 acute HF 但沒有低血壓 → **IV amiodarone** | I-C |
| 血行不穩、藥物無法快速控制 → **立即電擊整流** | I-C |
| 不穩定的新發 AF → IV amiodarone 幫助電擊、減少早期復發 | I-C |

### 併發症：心室心律不整

| 必做 | 等級 |
| --- | --- |
| ICD：有症狀 HF（NYHA II–III）、OMT > 3 個月後 LVEF ≤ 35%、**MI 後至少 6 週**、預期存活 ≥ 1 年 | I-A |
| Polymorphic VT／VF → **IV beta-blocker 和／或 amiodarone** | I-B |
| 反覆 VT／VF → 盡快完整再通治療缺血 | I-C |

### 併發症：心搏過慢

| 必做 | 等級 |
| --- | --- |
| 竇性心搏過慢致血行不穩，或高度 AV block 沒有穩定逸搏 → **IV 正性變時藥（adrenaline、vasopressin、atropine）**；**atropine 無效 → 暫時性起搏**；沒做過再灌流 → 緊急 cath | I-C |
| ==高度 AV block 在 MI 後等至少 5 天仍未恢復 → 永久節律器== | I-C |

### 共病：CKD、糖尿病、老人、癌症

| 必做 | 等級 |
| --- | --- |
| 侵入檢查用低滲或等滲顯影劑，**量越少越好** | I-A |
| 所有 ACS 用 eGFR 評估腎功能 | I-C |
| CKD 用同樣診斷治療策略（必要時調劑量） | I-C |
| 長期降糖藥依共病（HF、CKD、肥胖）選擇 | I-A |
| 所有 ACS 初評估血糖狀態 | I-B |
| 已知 DM 或高血糖（≥ 200 mg/dL）→ 頻繁監測血糖 | I-C |
| 老人用和年輕人相同的診斷與治療策略 | I-B |
| 依腎功能、併用藥、共病、衰弱、認知與禁忌調整抗栓與次級預防用藥 | I-B |
| 衰弱、多共病的老人 → 整體評估、個別化 | I-B |
| 癌症＋高風險 ACS、預期存活 ≥ 6 個月 → 侵入性策略 | I-B |
| 懷疑癌症治療造成 ACS → 暫停癌症治療 | I-C |

### 長期治療

| 必做 | 等級 |
| --- | --- |
| 所有 ACS 參加**運動型心臟復健**計畫 | I-A |
| 健康生活：戒菸、地中海飲食、限酒、有氧與阻力運動、減少久坐 | I-B |
| ==High-dose statin 盡早開始或繼續，不管起始 LDL-C== | I-A |
| ==LDL-C < 55 mg/dL（1.4 mmol/L）且比基準值降 ≥ 50%== | I-A |
| 最大耐受 statin **4–6 週**仍未達標 → 加 **ezetimibe** | I-B |
| Statin＋ezetimibe 4–6 週仍未達標 → 加 **PCSK9 inhibitor** | I-A |
| 入院前就在吃降血脂藥 → 住院中加強 | I-C |
| ==LVEF ≤ 40% → beta-blocker==（不論有無 HF 症狀） | I-A |
| 有 HF 症狀、LVEF ≤ 40%、DM、高血壓和／或 CKD → **ACE-I** | I-A |
| LVEF ≤ 40% 且有 HF 或 DM → **MRA** | I-A |
| 出院前 LVEF ≤ 40% → **6–12 週後**（完整再通與最佳藥物後）再評估 LVEF，決定要不要放 ICD | I-C |
| 所有 ACS 打**流感疫苗** | I-A |

### 以病人為中心

| 必做 | 等級 |
| --- | --- |
| 依病人偏好、需求與信念做決策 | I-B |
| 讓病人參與決策，告知不良事件、輻射風險與替代方案，使用決策輔助工具 | I-B |
| 用幫助病人描述經驗的方法評估症狀 | I-C |
