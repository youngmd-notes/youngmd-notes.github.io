> [!abstract] 一句話重點
> 2024 ESC 把 AF 照護整理成 **AF-CARE** 四步驟：**[C] 共病與危險因子 → [A] 預防中風 → [R] 用 rate／rhythm control 減輕症狀 → [E] 定期再評估**；rhythm control 的選擇依 **AF 類型**和 **LVEF** 走不同路徑。

## Table 1–2：建議等級與證據等級

整份指引每條建議都標 **Class（建議強度）** 和 **Level（證據等級）**，讀後面所有圖表都要先懂這兩個。

| Class | 意思 | 指引用語 |
| --- | --- | --- |
| **I** | 證據或共識認為有益、有效 | is recommended／is indicated（**建議**） |
| **IIa** | 證據傾向有效 | should be considered（**應考慮**） |
| **IIb** | 有效性證據較弱 | may be considered（**可考慮**） |
| **III** | 證據或共識認為無效，甚至有害 | is not recommended（**不建議**） |

| Level | 證據來源 |
| --- | --- |
| **A** | 多個 RCT 或統合分析 |
| **B** | 單一 RCT 或大型非隨機研究 |
| **C** | 專家共識、小型研究、回溯性研究或登錄資料 |

> [!tip] Pearl
> 指引圖中的顏色也對應等級：**綠色 = Class I、黃色 = IIa、橘色 = IIb、紅色 = III**。看 Figure 3–8 時用顏色就能快速分辨強度。

## Table 5：依時間型態分類 AF

| 分類 | 定義 |
| --- | --- |
| **First-diagnosed** | 第一次被診斷，不管有無症狀、型態或持續多久 |
| **Paroxysmal** | 7 天內自行停止，或經介入後停止；多數自行停止的發作 < 48 小時 |
| **Persistent** | 不會自行停止；臨床試驗多以 7 天為切點 |
| **Long-standing persistent** | 持續 ≥ 12 個月，但仍考慮 rhythm control（和 permanent 的差別） |
| **Permanent** | 醫病共同決定**不再嘗試**恢復竇性節律 |

> [!warning] Pitfall
> **==Permanent 不是看時間長短，而是一個「共同決定」==**：決定不再做 rhythm control 才叫 permanent。而且 AF 類型**==不影響是否需要抗凝==**（見 Figure 3 [A]）。

## Table 6：其他與 AF 相關的臨床概念

| 概念 | 重點 |
| --- | --- |
| **Clinical AF** | 有 ECG 記錄證實的 AF（不論有無症狀）；動態 ECG 要多長才算沒有定論，**≥ 30 秒**可視為需要進一步監測或評估栓塞風險 |
| **Device-detected subclinical AF** | 植入式裝置或穿戴裝置偵測到的無症狀 AF，需專業人員看過 EGM 或 ECG 確認；是未來 clinical AF 的預測因子 |
| Atrial high-rate episode（AHRE） | 植入式裝置偵測到、通常 **> 5 分鐘、心房率 ≥ 170 bpm** 的事件，要人工判讀排除雜訊 |
| **AF burden** | 監測期間處於 AF 的時間百分比 |
| Recent-onset AF | 用於急性 cardioversion 的決策，但時間切點尚未建立 |
| **Trigger-induced AF** | 緊接在可逆誘因之後出現的新發 AF |
| Early AF | 診斷後多久算早期沒有共識，大約 3–24 個月；也不代表一定要早期介入 |
| Self-terminating／non-self-terminating | 會不會自行停止，用於急性 rhythm control 的共同決策 |
| **Atrial cardiomyopathy** | 心房結構、電學或功能改變，造成 AF 進展、治療效果差或心衰竭；包含發炎、促血栓重塑、纖維化 |

## Figure 1：AF 帶來的影響與結果

指引把 AF 的衝擊分成三層，我依「多常見、多嚴重」重新整理（數字來自本章內文）：

| 層面 | 內容 |
| --- | --- |
| **病人症狀** | 心悸、喘、疲倦、胸痛、頭暈、運動耐力差、暈厥、焦慮、憂鬱、睡眠障礙 |
| **不良結果** | **心衰竭最常見**（約一半病人會發生，RR 約 4.6–5）、缺血性中風（RR 約 2.3）、缺血性心臟病、其他栓塞、認知退化與**血管性失智**、憂鬱、生活品質下降、反覆住院、死亡（全死因 RR 約 2） |
| **醫療與社會** | 盛行率持續上升（2010 到 2060 年約倍增）、終生風險從 **1/5 升到 1/3**、約占醫療支出 1–2% |

> [!tip] Pearl
> AF 病人**==最常見的死因是心衰竭相關==**，不是中風；即使有抗凝，殘餘死亡風險仍高，所以共病處理（[C]）很重要。

## Table 7：mEHRA 症狀分級

| 分數 | 症狀 | 描述 |
| --- | --- | --- |
| 1 | 無 | 沒有症狀 |
| 2a | 輕度 | 日常活動不受影響 |
| 2b | 中度 | 日常活動不受影響，**但病人被症狀困擾** |
| 3 | 重度 | 日常活動受影響 |
| 4 | 失能 | 無法進行日常活動 |

> [!tip] Pearl
> 2a 和 2b 的差別不在活動能力，而在**病人主觀上是否被困擾**，這也是決定要不要積極 rhythm control 的考量。

## Table 8：AF 病人的診斷檢查

| | 檢查項目 |
| --- | --- |
| **所有病人** | 病史（AF 型態、家族史、共病、栓塞與出血風險）、**12 導程 ECG**、評估症狀與功能（例如 mEHRA）、病人自評量表、**血液檢查：CBC、腎功能、電解質、肝功能、血糖／HbA1c、==甲狀腺功能==**、**TTE**（會影響 AF-CARE 決策時） |
| **選擇性** | 動態 ECG（AF burden、心率控制）、運動 ECG（評估心率控制或 class IC 藥物效果）、NT-proBNP／troponin（心血管疾病與風險分層）、**TEE**（左心房血栓、瓣膜疾病）、冠狀動脈 CT／血管攝影／缺血影像（懷疑 CAD）、心臟 MRI（心肌病變、術前規劃）、腦部影像與認知評估 |

> [!tip] Pearl
> 新診斷 AF 的必驗血液檢查，記得**甲狀腺功能**；TTE 不是每個人都「必做」，而是**會改變處置時**才做。

## Figure 2：多專科團隊照護

以病人為中心，AF-CARE 每一步都有不同團隊成員參與：

| 步驟 | 主要參與者 |
| --- | --- |
| [C] 共病與危險因子 | 基層醫療、心臟科、內科、護理、生活型態協助等 |
| [A] 預防中風與栓塞 | 基層醫療、心臟科、神經科、護理、抗凝門診、e-Health |
| [R] Rate／rhythm control | 基層醫療、心臟科、電生理、心臟外科、e-Health |
| [E] 評估與再評估 | 基層醫療、心臟科、藥師、護理、家屬／照顧者、e-Health |

## Table 9：如何做到以病人為中心

- **照護內容**：照 AF-CARE 路徑治療、生活型態建議、心理社會支持、病人與家屬衛教、基層與專科無縫銜接
- **執行方式**：**醫病共同決策（shared decision-making）**、多專科團隊、病人衛教與自我照護、醫療人員的結構化教育、科技輔助（e-Health、m-Health、遠距醫療）

## Figure 3：AF-CARE 總覽（中央圖）

最上層的原則：照護公平（Class I）、病人家屬與醫療人員衛教（Class I）、以病人為中心的多專科照護（Class IIa）。

### [C] 共病與危險因子

| 共病 | 處置 | Class |
| --- | --- | --- |
| 高血壓 | 降血壓治療 | I |
| 心衰竭 | 利尿劑緩解充血；HFrEF 給適當藥物；**SGLT2 inhibitor** | I |
| 過重／肥胖 | 減重（目標 **10%**） | I |
| | 若要做 rhythm control，可考慮減重手術 | IIb |
| 阻塞性睡眠呼吸中止 | 治療 OSA | IIb |
| 酒精 | **每週 ≤ 3 份** | I |
| 糖尿病 | 有效控制血糖 | I |
| 運動能力 | 量身訂做的運動計畫 | I |
| 其他危險因子 | 積極找出並處理 | I |

### [A] 預防中風與栓塞：五個步驟

1. **評估栓塞風險** → 開始口服抗凝（I）；**AF 類型不影響抗凝決定（III）**；**抗血小板不能取代抗凝（III）**
2. **用經過在地驗證的風險分數或 CHA₂DS₂-VA** → **≥ 2 分給 OAC（I）**；**= 1 分應考慮 OAC（IIa）**
3. **選擇抗凝劑** → **優先 DOAC**，除非是機械瓣或二尖瓣狹窄（I）；用 VKA 時 INR 目標 2.0–3.0（I），INR 在治療範圍時間要 > 70%（IIa），不然改 DOAC（I）
4. **評估出血風險** → 找出並處理可改變的出血因子（I）；**不可用出血分數當作不給抗凝的理由（III）**
5. **預防出血** → 不要為了預防中風合併抗血小板與 OAC（III）；穩定 CCS／周邊動脈疾病的 OAC 病人，**抗血小板不要超過 12 個月（III）**

### [R] 減輕症狀

依 AF 類型走不同路徑（見下方 Figure 4–7），可用工具：rate control 藥物、cardioversion、抗心律不整藥物、導管燒灼、內視鏡／混合式燒灼、外科燒灼、燒灼加節律器。

### [E] 評估與再評估

- **時機**：AF 發作或因其他原因住院時；固定在**診斷後 6 個月，之後至少每年一次**
- **內容（皆 Class I）**：評估新舊危險因子與共病、重新分層中風與栓塞風險、治療前後症狀變化、可改變的出血因子；**做了 rhythm control 仍有栓塞風險就要繼續 OAC**

> [!warning] Pitfall
> **==燒灼成功、恢復竇性節律，不代表可以停抗凝==**；是否抗凝看的是栓塞風險，不是心律。

## Figure 4–7：依 AF 類型的 [R] 路徑

四條路徑的共同前提：都先照 AF-CARE 處理 [C] 共病和 [A] 抗凝。我把四張圖整理成對照表：

| | First-diagnosed（Fig 4） | Paroxysmal（Fig 5） | Persistent（Fig 6） | Permanent（Fig 7） |
| --- | --- | --- | --- | --- |
| 血行動力不穩定 | **電擊整流（I）** | — | 電擊整流（I） | — |
| 心率目標 | 先做 rate control（I） | **休息心率 < 110 bpm**（寬鬆控制），有症狀再嚴格（IIa） | 同左 | 同左 |
| LVEF ≤ 40% | beta-blocker 或 digoxin（I） | 同左 | 同左 | 同左 |
| LVEF > 40% | beta-blocker、digoxin、diltiazem 或 verapamil（I） | 同左 | 同左 | 同左 |
| 單一藥物不夠 | 合併 rate control（IIa） | 同左 | 同左 | 合併時**避免心搏過慢**（IIa） |
| Rhythm control | 有症狀的 persistent AF 做 cardioversion（I）；可先觀察 **48 小時內**是否自行恢復（IIa） | 共同決策（I）→ 抗心律不整藥 **或** 導管燒灼（**I**，可當第一線） | 共同決策（I）→ 抗心律不整藥（I）或導管燒灼（**IIb** 當第一線） | 不做 |
| 藥物失敗 | — | 導管燒灼（I） | 導管燒灼（I）、內視鏡／混合式燒灼（IIa） | — |
| 燒灼失敗 | — | 再次燒灼（IIa）、外科／混合式燒灼（IIb）、改藥物 | 再次燒灼、內視鏡／外科燒灼、藥物，或改 rate control | — |
| 嚴重症狀、HF 住院 | — | — | — | **AV node 燒灼 + CRT**（IIa） |

### 抗心律不整藥依心臟狀況選擇（Fig 5、6 共用）

| 心臟狀況 | 藥物 |
| --- | --- |
| **HFrEF（LVEF ≤ 40%）** | **==只有 amiodarone==**（I） |
| 穩定 HFmrEF（LVEF 41–49%）、冠心病、瓣膜疾病 | amiodarone 或 dronedarone（I）；sotalol（IIb） |
| 沒有或只有輕微心臟病 | dronedarone、flecainide 或 propafenone（I）；sotalol（IIb） |

> [!tip] Pearl
> - **==Paroxysmal AF 的導管燒灼可以是第一線（Class I）==**，persistent AF 當第一線只有 IIb
> - HFrEF 病人的導管燒灼：高度懷疑**心搏過速引起的心肌病變**時 Class I，其餘選擇性病人為改善預後 IIa
> - **==HFrEF 不可用 diltiazem、verapamil==**；rate control 只能用 beta-blocker 或 digoxin
> - Beta-blocker 合併 diltiazem／verapamil 只能在專家指示下使用，並用動態 ECG 監測心搏過慢

### Persistent AF 的電擊整流時機（Fig 6）

- 血行動力不穩定（I）
- 作為 rhythm control 策略的一部分（IIa）
- 用來釐清恢復竇性節律後症狀是否改善（IIa）

### Permanent AF 的追蹤（Fig 7）

心率達標 → 照 AF-CARE 持續追蹤；未達標 → 在觀察下加強 rate control，仍不行時評估 **AV node 燒灼合併節律器**（IIa）。

## Figure 8：處理關鍵共病以減少 AF 復發

**行為改變的原則**：共同決策、聚焦關鍵危險因子、設定可達成的目標、提供資訊但不要資訊過載；為每位病人訂個別化目標。

| 項目 | 目標 | Class |
| --- | --- | --- |
| 整合管理 | 找出並積極處理所有危險因子與共病 | I |
| **高血壓** | 多數成人 **120–129／70–79 mmHg**（或在合理範圍內盡量低） | I |
| 心衰竭 | 利尿劑緩解充血、HFrEF 適當藥物、**所有 LVEF 都給 SGLT2 inhibitor** | I |
| 糖尿病 | 飲食或藥物有效控制血糖 | I |
| **肥胖** | 過重或肥胖者減重 **≥ 10%** | I |
| 睡眠呼吸中止 | 治療 OSA 以減少呼吸中止 | IIb |
| 運動 | 量身訂做，規律中強度到高強度運動 | I |
| **酒精** | **每週 ≤ 3 份標準飲酒量** | I |

> [!tip] Pearl
> 共病控制幾乎都是 Class I，唯一例外是 **OSA（IIb）**。數字記三個：**==血壓 120–129、減重 10%、酒精每週 ≤ 3 份==**。

## Figure 13：心臟超音波在 AF-CARE 的角色

| 步驟 | 為什麼做影像 | 看什麼 |
| --- | --- | --- |
| **[C]** | 找出會讓 AF 復發、進展的共病 | LVEF、室壁運動、舒張功能、右心功能、左心室肥厚（判斷心衰竭類型與病因，例如 cardiac amyloid）；心包膜積液；瓣膜疾病 |
| **[A]** | 評估中風風險、選擇抗凝劑、確保 cardioversion 安全 | **心衰竭（CHA₂DS₂-VA 的 C）**；**中重度二尖瓣狹窄**（決定能不能用 DOAC）；**TEE 看左心耳血栓**（cardioversion 前） |
| **[R]** | 選擇 rate／rhythm 策略、預測燒灼成功率 | **LVEF 決定 rate control 藥物**；瓣膜疾病嚴重度與左心室大小功能決定 rhythm control；**==左心房大小功能預測燒灼後復發==** |
| **[E]** | 偵測會改變處置的結構變化 | 已知瓣膜疾病是否惡化；臨床狀況改變時重新評估左心室 |
