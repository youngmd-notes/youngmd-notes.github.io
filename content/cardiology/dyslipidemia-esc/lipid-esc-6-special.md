> [!abstract] 一句話重點
> - **ACS：盡早開始 high-dose statin（I-A）**，4–6 週驗 LDL-C，未達標依序加 ezetimibe、PCSK9（I-B）
>   - 🆕 2025 改成「**the sooner, the lower, the better**」：**住院期間就加強（I-C），未用藥者可直接 statin＋ezetimibe（IIa-B）**
> - **HF 與 AS（無其他適應症）不要開始降脂藥（III-A）**；**透析且無 ASCVD 不要開始 statin（III-A）**
> - 🆕 2025：**HIV ≥ 40 歲初級預防，不論風險與 LDL-C，都建議 statin（I-B）**；anthracycline 化療高風險者應考慮 statin（IIa-B）

## 一張表看所有族群

| 族群 | 一句話 |
| --- | --- |
| **女性** | 適應症與目標**和男性相同**；**懷孕、哺乳、計畫懷孕不用降脂藥** |
| **老人** | 有 ASCVD → 和年輕人一樣用 statin（I-A）；初級預防 **≤ 75 歲依風險（I-A）**、**> 75 歲高風險以上可考慮（IIb-B）**；**低劑量開始** |
| **DM** | T2DM very high → < 55、high → < 70 mg/dL（I-A）；**計畫懷孕或未避孕的停經前女性不用 statin（III）** |
| **ACS** | 盡早 high-dose statin；🆕 住院中就合併治療 |
| **缺血性中風／TIA** | Very high，強力降 LDL-C（I-A） |
| **HF、AS** | **沒有其他適應症就不開始降脂藥（III-A）** |
| **CKD** | Stage 3 high、stage 4–5 very high；**非透析用 statin±ezetimibe（I-A）**；**透析且無 ASCVD 不開始（III-A）** |
| **移植** | Statin 第一線（IIa-B），**小心 ciclosporin** |
| **PAD** | 最大耐受 statin＋ezetimibe，必要時加 PCSK9（I-A） |
| 🆕 **HIV** | **≥ 40 歲初級預防一律 statin（I-B）** |
| 🆕 **Anthracycline 化療** | 高或極高心毒性風險 → 考慮 statin（IIa-B） |

## 女性（Box 6）

- **高風險女性**的初級預防建議 statin；**次級預防的適應症與目標和男性相同**
- CTT：每降 1 mmol/L 的相對效益**男女相同**；ezetimibe（IMPROVE-IT）、PCSK9 也一樣
- **計畫懷孕、懷孕中、哺乳期不使用降脂藥**；嚴重 FH 可考慮**不被吸收的 bile acid sequestrant** 及／或 **LDL apheresis**
- **低劑量第三代口服避孕藥**不增加冠狀動脈事件，TC 可接受者可用；**LDL-C > 160 mg/dL（4 mmol/L）**、多重危險因子或血栓高風險者改用其他避孕方式
- **停經後荷爾蒙補充**雖改善血脂，但**不能**用來預防 CVD

## 建議：老人（> 65 歲）

| 建議 | 等級 |
| --- | --- |
| 有 ASCVD 的老人，**和年輕病人一樣**使用 statin | **I-A** |
| **≤ 75 歲**的老人，依風險等級用 statin 做初級預防 | **I-A** |
| **> 75 歲**、high risk 以上，可考慮**開始** statin 初級預防 | **IIb-B** |
| 明顯腎功能不全或可能有藥物交互作用時，**statin 從低劑量開始**再往上調到達標 | **I-C** |

- CTT（28 個試驗、18.7 萬人，8% > 75 歲）：每降 1 mmol/L 主要血管事件降 **21%**，**> 75 歲也有直接證據**；但**沒有血管疾病的 > 75 歲**效益證據較少（STAREE 試驗進行中）
- 🆕 2025：EWTOPIA 75 支持 ≥ 75 歲無 CAD 者使用 ezetimibe（見 ④）

## 建議：糖尿病（Box 7）

| 建議 | 等級 |
| --- | --- |
| **T2DM very high**：下降 ≥ 50% 且 **< 55 mg/dL** | **I-A** |
| **T2DM high**：下降 ≥ 50% 且 **< 70 mg/dL** | **I-A** |
| **T1DM 且 high 或 very high** → statin | **I-A** |
| 合併治療前，先考慮**加強 statin** | **IIa-C** |
| 未達標 → statin＋ezetimibe 應考慮 | **IIa-B** |
| **==停經前 DM 女性計畫懷孕或未適當避孕 → 不建議 statin==** | **III-C** |
| **≤ 30 歲**的 T1DM 或 T2DM，有 end organ damage 及／或 LDL-C > 97 mg/dL（2.5 mmol/L），且沒有計畫懷孕 → 可考慮 statin | **IIb-C** |

**Box 7：MetS 與 T2DM 的血脂異常**

- 一群異常：空腹與餐後 **TG、ApoB、small dense LDL 升高**，**HDL-C 與 ApoA1 降低**（atherogenic dyslipidaemia）
- **Non-HDL-C 或 ApoB** 是 TG-rich lipoprotein 與 remnant 的好指標，作為**次要目標**：

| 風險 | Non-HDL-C | ApoB |
| --- | --- | --- |
| High | < 100 mg/dL | < 80 mg/dL |
| Very high | < 85 mg/dL | < 65 mg/dL |
| Very high 且反覆 ASCVD 事件（可考慮） | < 70 mg/dL | < 55 mg/dL |

- 統合分析：DM 病人每降 1 mmol/L，**總死亡降 9%、主要 CV 事件降 21%**，T1DM、T2DM 相同
- 血糖控制良好的 **T1DM 血脂常「超正常」**（TG、LDL-C 偏低、HDL-C 偏高，因皮下 insulin 增加 LPL 活性），但粒子組成仍可能致動脈硬化
- **< 30 歲、無血管損傷（尤其無 microalbuminuria）**的無症狀 DM，延後到 30 歲再開始 statin 是合理的
- 🆕 2025：T2DM 沒有 ASCVD 的風險估計改用 **SCORE2-Diabetes**（見 ①）

## 建議：ACS 與 PCI

| 建議 | 等級 |
| --- | --- |
| 所有 ACS 病人（無禁忌或明確不耐受），**不論初始 LDL-C**，**==盡早==**開始或繼續 **==high-dose statin==** | **I-A** |
| ACS 後 **4–6 週**重驗血脂，確認是否下降 ≥ 50% 且 < 55 mg/dL，並評估安全性調整劑量 | **IIa-C** |
| 最大耐受 statin 4–6 週仍未達標 → **加 ezetimibe** | **I-B** |
| Statin＋ezetimibe 4–6 週仍未達標 → **加 PCSK9 inhibitor** | **I-B** |
| 確定 statin 不耐受或禁忌 → 應考慮 ezetimibe | **IIa-C** |
| ACS 時已在服最大耐受 statin＋ezetimibe 仍未達標 → **事件後早期（盡量住院中）加 PCSK9 inhibitor** | **IIa-C** |
| ACS 或擇期 PCI 前，**常規 high-dose statin 預先治療或 loading**（已長期服用者） | **IIa-B** |

- **SECURE-PCI**：atorvastatin 80 mg 兩次 loading，整體無顯著效益，但實際接受 PCI 者 MACE 降 28%（STEMI primary PCI 次族群降 46%）
- 2019 建議在 index ACS 住院的**前 14 天內**開始 high-intensity statin；已在服低／中強度者要**加強**；老人、肝腎功能不佳或有交互作用疑慮時可用較低強度

> [!info] 🆕 新版指引（2025 Focused Update）Recommendation Table 3（補充 2019 的表）
>
> | 建議 | 等級 |
> | --- | --- |
> | ACS 前**已在服任何降脂藥**者，**index ACS 住院期間就加強**降脂治療 | **I-C** |
> | ACS 前**未用藥**、且**預期單用 statin 無法達標**者，住院期間就開始 **high-intensity statin＋ezetimibe** 應考慮 | **IIa-B** |
>
> 理由：MI 後 **100 天內**第二次 MI、中風或 CV 死亡累積約 **10%**，5 年達 **33%**；照 2019 的階梯式（每 4–6 週加一種）可能要 **12 週**才達最佳治療，而這正是最危險的時期；且出院後常見處方慣性與流失追蹤。**SWEDEHEART** 顯示**早期且持續達標**者事件最少；**HUYGENS、PACMAN-AMI** 顯示 ACS 早期強力降 LDL-C 改善 plaque。因此從「**lower is better**」進一步變成「**==the sooner, the lower, the better==**」與「**strike early and strong**」。之後仍在 **4–6 週**驗 LDL-C，並終身治療達標。（EVOLVE-MI 等早期 evolocumab 試驗預計 2026–2027 公布）

## 建議：中風、HF、瓣膜病

| 建議 | 等級 |
| --- | --- |
| **缺血性中風或 TIA** 屬 very high，建議**強力降 LDL-C** | **I-A** |
| **HF** 病人若**沒有其他適應症**，**==不建議開始==**降脂治療 | **III-A** |
| **Aortic valve stenosis、無 CAD**，**==不建議==**為了延緩 AS 進展而開始降脂治療 | **III-A** |

- Statin 次級預防使復發中風每降 1 mmol/L 減少 **12%**，也減少 MI 與血管死亡；可能小幅增加出血性中風，但證據不確定
- Statin 可**減少 CAD 病人新發 HF**（首次非致命 HF 住院約降 10%），但**對非缺血性 HF 無預防效果**
- 慢性 HF（主要 systolic HF）的兩個大型 RCT 與統合分析：**CV 死亡或中風沒有改善**

> [!warning] Pitfall
> **「HF 不用 statin」是指「沒有其他適應症時不要『開始』」**；已因 CAD 等原因在服 statin 的 HF 病人不必停。AS 也一樣：降脂**不能延緩 AS 進展**（SEAS 等試驗），但 AS 合併 CAD 仍照 CAD 治療。

## 建議：CKD（KDOQI stage 3–5）

| 建議 | 等級 |
| --- | --- |
| Stage 3–5 CKD 屬 **high 或 very high** ASCVD 風險 | **I-A** |
| **非透析** stage 3–5 CKD → **statin 或 statin／ezetimibe** | **I-A** |
| **開始透析時已在服** statin、ezetimibe 或兩者 → 應考慮**繼續**，尤其有 ASCVD 者 | **IIa-C** |
| **透析中、沒有 ASCVD** → **==不建議開始 statin==** | **III-A** |

- CKD 不需要算風險分數：**stage 3 = high，stage 4–5 或透析 = very high**
- CKD 早期血脂：TG 升高、HDL-C 降低、small dense LDL 增加；腎臟參與 Lp(a) 代謝，CKD 時 Lp(a) 升高
- **4D**（DM 血液透析，atorvastatin）、**AURORA**（血液透析，rosuvastatin）**無效**；**SHARP**（CKD 3A–5，simvastatin＋ezetimibe）**減少主要動脈硬化事件**；CTT 合併分析顯示 **eGFR 越低效益越小**，透析者幾乎沒有

## 建議：移植與 PAD

| 建議 | 等級 |
| --- | --- |
| 移植病人以 **statin 為第一線**；**低劑量開始、小心調升**，注意交互作用，**尤其 ciclosporin** | **IIa-B** |
| Statin 不耐受或最大耐受 statin 仍明顯血脂異常 → 可考慮 ezetimibe 替代或加上 | **IIb-C** |
| **PAD**（含 carotid artery disease）：最大耐受 statin，必要時加 ezetimibe 或 PCSK9 inhibitor | **I-A** |

- **==Ciclosporin 經 CYP3A4 代謝，會提高所有 statin 的血中濃度==**；fluvastatin、pravastatin、pitavastatin、rosuvastatin 經其他 CYP，交互作用較少；tacrolimus 也經 CYP3A4，但風險較 ciclosporin 低

## 🆕 HIV 與癌症（2025 新增）

> [!info] 🆕 新版指引（2025 Focused Update）Recommendation Table 6、7
>
> | 建議 | 等級 |
> | --- | --- |
> | **HIV、≥ 40 歲、初級預防**：**==不論估計的心血管風險與 LDL-C==**，都建議 **statin**；**依藥物交互作用選 statin** | **I-B** |
> | 成人**高或極高化療相關心血管毒性風險** → 應考慮 statin 以降低 **anthracycline 心功能障礙** | **IIa-B** |
>
> **HIV**：2019 原本是「HIV 合併血脂異常應考慮降脂，以 high-risk 的 LDL-C 目標治療（IIa-C）」（2019 原文；已更新）。PWH 的 ASCVD 風險約為一般人 **2 倍**，且傳統風險工具會**低估**。**REPRIEVE**（7769 名 40–75 歲、低中風險、接受 ART 者，**pitavastatin 4 mg**）：**MACE 降 35%（HR 0.65）**，因療效提早終止，男女效果相似；5 年 **NNT 106**；肌肉症狀（2.4% vs 1.3%）與新發 DM（5.3% vs 4.0%）略增；pitavastatin 和 ART **沒有交互作用**。Ezetimibe 與 PCSK9 mAb 在 PWH 也能降 LDL-C，但沒有結果試驗。
>
> **癌症**：anthracycline 治療 5 年內 HF 可達 **20%**（依累積劑量）。**STOP-CA**（300 名 lymphoma，atorvastatin 40 mg）：LVEF 絕對下降 ≥ 10% 且 < 55% 的比例 **9% vs 22%**；另三個小試驗結果不一。本建議沿用 **2022 ESC cardio-oncology 指引**的 IIa；non-statin 尚無資料。

## 慢性發炎與其他高風險族群（2019 Section 9.11、10）

- **慢性免疫發炎疾病、HIV、嚴重精神疾病**：疾病本身與治療藥物都會增加風險或造成血脂異常，原則相同，但要注意藥物安全性
- **Inflammation**：statin 降 CRP；**JUPITER**（CRP > 2 mg/L 的初級預防）rosuvastatin 明顯減少事件；**CANTOS**（canakinumab）減少復發事件但增加致命感染，**FDA 未核准**；**CIRT**（低劑量 methotrexate）無效 → 2019 **不對抗發炎藥物做建議**（🆕 2025 把**持續 hs-CRP > 2 mg/L** 列為 risk modifier，見 ①）
