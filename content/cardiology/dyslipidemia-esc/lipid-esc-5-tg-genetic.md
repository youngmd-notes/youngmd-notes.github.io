> [!abstract] 一句話重點
> - **高 TG 降 CV 風險的第一線還是 statin（I-B）**
>   - high／very high 風險、TG **135–499 mg/dL** 仍高 → 加 **high-dose icosapent ethyl 2 g bid（IIa-B）**
>   - fibrate 只是 IIb
> - **TG > 880 mg/dL（10 mmol/L）要預防胰臟炎**
> - **FH** 用 **Dutch Lipid Clinic Network** 診斷（> 8 分 definite），有 ASCVD 或另一主要危險因子算 **very high**，否則算 **high**
>   - 確診後做 **cascade screening**
> - 🆕 2025：FCS 可考慮 **volanesorsen**（IIa-B）

## 高三酸甘油脂：TG-lowering 藥物重點（2019＋🆕 2025，自己整理）

| 藥物 | 降 TG 效果與 CV 證據 |
| --- | --- |
| **Statin** | TG 降 10–20%（強效 statin 在高 TG 者更明顯）；**降 CV 風險的相對效益在高 TG 者相同，絕對效益更大** |
| **Fibrate**（PPAR-α agonist） | TG 降約 **50%**、LDL-C 降 ≤ 20%（高 TG 時 LDL-C 可能反升）、HDL-C 升 ≤ 20%；**==FIELD、ACCORD 對總 CV 事件無效==**，只在 **高 TG＋低 HDL-C** 次族群看到 non-fatal MI 下降；副作用：myopathy（**gemfibrozil＋statin 最危險**）、肝酵素、膽結石、**肌酸酐可逆性上升**、胰臟炎風險略增 |
| 🆕 **Pemafibrate** | **PROMINENT**（10,497 名 T2DM、輕中度高 TG、低 HDL-C）：**MACE 沒有下降**，而且 **ApoB 與 LDL-C 上升** |
| **n-3 PUFA** | 降 TG 需要 **> 2 g/天**；1 g/天的試驗（ASCEND、VITAL）無效；**REDUCE-IT**（icosapent ethyl 2 g bid，statin 治療中、TG 150–499）：**MACE 降 25%**（絕對降 4.8%），但 **AF／flutter 住院增加約 1%**；可能增加出血傾向 |
| 🆕 **STRENGTH** | EPA＋DHA 混合物（13,078 人）**無效**；和 REDUCE-IT 不一致可能來自族群、**純化 EPA vs 混合物**、**安慰劑（corn oil vs mineral oil）**差異 |

> [!info] 🆕 新版指引（2025 Focused Update）Recommendation Table 5
>
> | 建議 | 等級 |
> | --- | --- |
> | **==High-dose icosapent ethyl（2 × 2 g/天）==** 合併 statin，用於 high 或 very high 風險、**空腹 TG 135–499 mg/dL（1.52–5.63 mmol/L）**者以降低 CV 事件 | **IIa-B** |
> | **Volanesorsen（300 mg／週）** 用於 **familial chylomicronaemia syndrome（FCS）**造成的嚴重高 TG（**> 750 mg/dL、> 8.5 mmol/L**），以降 TG 與胰臟炎風險 | **IIa-B** |
>
> 2025 把 2019 的「n-3 PUFAs（icosapent ethyl 2 × 2 g/天）」**明確限定為純化的 high-dose icosapent ethyl**（因 STRENGTH 陰性）；**fenofibrate、bezafibrate 的 IIb 維持**；**fibrate 不用來降膽固醇或 LDL-C**。Volanesorsen 是 ApoC-III mRNA 的 antisense，3 個月降 TG 約 77%，常見副作用是**血小板低下**（需頻繁監測）與注射部位反應；EMA 核准、FDA 未核准。研發中的 ApoC-III RNA 藥物可降 TG 達 80%。

## 建議：高 TG 的藥物治療（2019）

| 建議 | 等級 |
| --- | --- |
| 高風險且 **TG > 200 mg/dL（2.3 mmol/L）** → **==statin 是降 CVD 風險的首選==** | **I-B** |
| High 以上風險、statin 治療下 TG **135–499 mg/dL**（1.5–5.6 mmol/L）→ 應考慮合併 **n-3 PUFAs（icosapent ethyl 2 × 2 g/天）**（2019 原文；已更新，見上方 🆕） | **IIa-B** |
| **初級預防**、LDL-C 已達標但 **TG > 200 mg/dL** → 可考慮 statin＋**fenofibrate 或 bezafibrate** | **IIb-B** |
| **高風險**、LDL-C 已達標但 TG > 200 mg/dL → 可考慮 statin＋fenofibrate 或 bezafibrate | **IIb-C** |

## 嚴重高 TG：預防急性胰臟炎（2019 Section 9.1.4）

- **TG > 880 mg/dL（10 mmol/L）**胰臟炎風險有臨床意義（尤其 familial chylomicronaemia），**必須積極預防**；**440–880 mg/dL** 也可能發生；**高 TG 約佔所有胰臟炎的 10%**
- 單基因嚴重高 TG：**LPL、APOC2、APOA5、LMF1、GPIHBP1、GPD1**（體染色體隱性），TG 常 > 1000 mg/dL（11.2 mmol/L），血清呈**乳白色**
- 最常見的加重因子：**酒精**
- 處置：有症狀就住院，或密切追蹤 TG；**限制熱量與脂肪（10–15% 熱量）**、**絕對戒酒**；開始 **fenofibrate**，輔以 **n-3 脂肪酸 2–4 g/天**；嚴重者可考慮 lomitapide；DM 要用 **insulin** 控糖；TG 通常 **2–5 天**內明顯下降；急性期 **plasmapheresis** 可快速降 TG

> [!danger] 數字
> **==TG > 880 mg/dL（10 mmol/L）→ 胰臟炎高風險==，戒酒、極低脂飲食、fenofibrate**。另記：**TG > 400 mg/dL 時 Friedewald LDL-C 不能用**（見 ②）。

## Table 11：脂蛋白代謝的遺傳疾病

<div class="orig-fig" data-src="心臟科/dyslipidemia-esc-originals/table-11.png" data-label="Table 11（2019）"></div>

| 疾病 | 盛行率 | 基因 | 脂蛋白變化 |
| --- | --- | --- | --- |
| **HeFH** | **1／200–250** | LDLR、APOB、PCSK9 | ↑ LDL-C |
| **HoFH** | 1／160,000–320,000 | LDLR、APOB、PCSK9 | ↑↑ LDL-C |
| **FCH**（familial combined hyperlipidaemia） | **1／100–200** | USF1＋修飾基因 | ↑ LDL-C、↑ VLDL-C、↑ ApoB |
| **Familial dysbetalipoproteinaemia** | 1／5000 | **APOE** | ↑↑ IDL 與 chylomicron remnant（β-VLDL） |
| **Familial LPL deficiency（FCS）** | 2／10⁶ | LPL、APOC2、APOA5、GPIHBP1、LMF1 | ↑↑ chylomicron 與 VLDL-C |
| **Tangier disease**（analphalipoproteinaemia） | 1／10⁶ | **ABCA1** | ↓↓ HDL-C |
| **Familial LCAT deficiency** | 1／10⁶ | LCAT | ↓ HDL-C |

**各疾病重點**（2019 Section 9.1，自己整理）：

- **FCH**：最常見的混合型血脂異常，LDL-C 及／或 TG 升高，是**早發 CAD** 的重要原因；不是單基因病，和 T2DM／MetS 表現重疊，常被漏診。線索：**ApoB > 120 mg/dL＋TG > 133 mg/dL（1.5 mmol/L）＋早發 CVD 家族史**
- **HeFH**：約 **95%** 是 **LDLR** 突變；未治療的男性 55 歲前、女性 60 歲前發生 CAD；臨床確診者能找到突變的只有 60–80%（其餘可能是 polygenic）
- **HoFH**：大量 xanthoma、TC **> 500 mg/dL（13 mmol/L）**；多數 **20 歲前**出現 CAD 與 **aortic stenosis**，未治療常活不過 30 歲；治療為強力降脂藥＋**lipoprotein apheresis**（每 1–2 週，LDL-C 降 55–70%）
- **Familial dysbetalipoproteinaemia（type III）**：TC 與 TG **都升高、常各在 7–10 mmol/L**（TC 約 270–390、TG 約 620–890 mg/dL，**兩者差不多高**是線索）；**==tuberoeruptive xanthoma==**（手肘、膝蓋）與**==手掌紋路的 palmar xanthoma==** 是特徵；多為 **ApoE2 同型合子**，需要合併 HTG、DM、肥胖或**甲狀腺低下**等誘因才表現；停經前女性少見；不是 ApoE2/E2 的老人出現類似黃色瘤要找 **paraprotein**；治療用 statin 或 fibrate，常需合併
- **低血脂遺傳病**：hypobetalipoproteinaemia（LDL-C 20–60 mg/dL）、abetalipoproteinaemia（脂肪瀉、神經症狀）；**CETP deficiency** 的 HDL-C 很高但**不增加**動脈硬化

## Table 12：Dutch Lipid Clinic Network FH 診斷標準

| 類別 | 條件 | 分數 |
| --- | --- | :---: |
| **1）家族史** | 一等親有早發（男 < 55、女 < 60 歲）冠心病或血管疾病，或一等親 LDL-C > 95 百分位 | 1 |
| | 一等親有 **tendon xanthoma** 及／或 **arcus cornealis**，或 < 18 歲子女 LDL-C > 95 百分位 | 2 |
| **2）臨床病史** | 本人**早發 CAD**（男 < 55、女 < 60 歲） | 2 |
| | 本人早發腦血管或周邊血管疾病 | 1 |
| **3）身體檢查**（兩者擇一，最多 6 分） | **Tendinous xanthoma** | **6** |
| | **Arcus cornealis（< 45 歲）** | 4 |
| **4）未治療 LDL-C** | **≥ 325 mg/dL**（8.5 mmol/L） | **8** |
| | 251–325 mg/dL（6.5–8.4） | 5 |
| | 191–250 mg/dL（5.0–6.4） | 3 |
| | 155–190 mg/dL（4.0–4.9） | 1 |
| **5）DNA** | **LDLR、APOB 或 PCSK9 功能性突變** | **8** |

每一組**只取最高的一項**，再加總：**==> 8 分為 definite==**；**6–8 分 = probable**；**3–5 分 = possible**。

> [!tip] Pearl
> 單一項就能拿 8 分的只有兩個：**LDL-C ≥ 325 mg/dL** 和**基因突變**；tendon xanthoma 給 6 分。所以「LDL-C 很高＋早發 CAD」就可以算到 definite（8＋2 = 10）。

## 建議：HeFH 的偵測與治療

| 建議 | 等級 |
| --- | --- |
| 下列情況要考慮 FH：**CHD 且男 < 55、女 < 60 歲**；親屬有早發致命或非致命 CVD；親屬有 tendon xanthoma；**LDL-C 嚴重升高（成人 > 190 mg/dL、兒童 > 150 mg/dL）**；FH 病人的一等親 | **I-C** |
| 用**臨床標準**診斷 FH，可能時以 **DNA 分析**確認 | **I-C** |
| 確診 index case 後，做家族 **==cascade screening==** | **I-C** |
| **==FH＋ASCVD 或另一主要危險因子 → very high==**；沒有 ASCVD 或其他危險因子 → **high** | **I-C** |
| FH＋ASCVD（very high）→ 下降 **≥ 50%** 且 **< 55 mg/dL**；達不到就合併用藥 | **I-C** |
| 初級預防、FH 且 very high → 下降 ≥ 50% 且 < 55 mg/dL **應考慮** | **IIa-C** |
| Very high 的 FH，最大耐受 statin＋ezetimibe 未達標 → **PCSK9 inhibitor** | **I-C** |
| **兒童從 5 歲開始檢測 FH**，懷疑 HoFH 則更早 | **I-C** |
| FH 兒童要學習正確飲食，**8–10 歲開始 statin**；**> 10 歲目標 LDL-C < 135 mg/dL（3.5 mmol/L）** | **IIa-C** |

- 找 index case 的線索：**未治療成人 TC ≥ 310 mg/dL（8 mmol/L）**（或 > 95 百分位）、本人或家人早發 CHD、tendon xanthoma、家族早發猝死
- 一確診就開始降膽固醇，**多數一開始就 high-intensity statin＋ezetimibe**；可用影像偵測無症狀動脈硬化
- **兒童**：有高膽固醇或早發 CHD 家族史者，LDL-C **≥ 160 mg/dL（4.0）**可診斷；**父母有已知突變**則 **≥ 130 mg/dL（3.5）**；< 10 歲的目標是下降 ≥ 50%
- 🆕 2025：**HoFH ≥ 5 歲**、最大治療仍未達標 → **evinacumab（IIa-B）**（見 ④）
