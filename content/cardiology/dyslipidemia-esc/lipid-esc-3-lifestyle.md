> [!abstract] 一句話重點
> - **飽和脂肪對 LDL-C 影響最大**：< 10% 熱量（高膽固醇者 < 7%），**避免 trans fat**；減重 5–10%、每天 ≥ 30 分鐘中強度運動
> - **降 TG 最有效的是減少酒精**
> - 🆕 2025：**沒有證實安全性與降 LDL-C 效果的營養補充品或維生素，不建議用來降低 ASCVD 風險（III-B）**；歐盟已禁售每天 ≥ 3 mg monacolin 的紅麴補充品

## Table 8：各種生活型態改變對血脂的影響

效果大小：**+++ > 10%**、**++ 5–10%**、**+ < 5%**（對該脂蛋白的血漿濃度）；等級是對血脂的影響證據，**不是 CV 事件的 RCT 證據**。

| 目的 | 介入 | 效果 | 證據 |
| --- | --- | :---: | :---: |
| **降 TC、LDL-C** | 避免 trans fat | ++ | A |
| | 減少飽和脂肪 | ++ | A |
| | 增加膳食纖維 | ++ | A |
| | 富含 phytosterol 的機能性食品 | ++ | A |
| | 紅麴（red yeast rice）營養品 | ++ | A |
| | 減去多餘體重 | ++ | A |
| | 減少膳食膽固醇 | + | B |
| | 增加日常身體活動 | + | B |
| **降 TG-rich lipoprotein** | 減去多餘體重 | + | A |
| | **==減少酒精==** | **+++** | A |
| | 增加日常身體活動 | ++ | A |
| | 減少總碳水化合物 | ++ | A |
| | n-3 PUFA 補充品 | ++ | A |
| | 減少單醣與雙醣 | ++ | B |
| | 以單元或多元不飽和脂肪取代飽和脂肪 | + | B |
| **提高 HDL-C** | 避免 trans fat | ++ | A |
| | **==增加日常身體活動==** | **+++** | A |
| | 減去多餘體重 | ++ | A |
| | 減少碳水化合物並以不飽和脂肪取代 | ++ | A |
| | 已有飲酒習慣者可維持適量 | ++ | B |
| | 戒菸 | + | B |

> [!tip] Pearl
> 三個「+++」最好記：**降 TG → 戒酒**、**升 HDL → 運動**。降 LDL-C 沒有任何單一生活介入能超過 10%，所以 high／very high 風險者幾乎都需要藥物。

## 飲食細節（2019 Section 7，自己整理）

| 項目 | 建議 |
| --- | --- |
| **飽和脂肪** | **==對 LDL-C 影響最大==**（每增加 1% 熱量，LDL-C 升約 0.8–1.6 mg/dL）；**==< 10% 總熱量==**，**高膽固醇血症 < 7%** |
| **Trans fat** | 和飽和脂肪一樣升 LDL-C，而且**降 HDL-C** → **==完全避免==**（多來自部分氫化植物油） |
| 總脂肪 | 範圍可寬，但 > 35–40% 熱量通常伴隨飽和脂肪與熱量過多；以單元不飽和脂肪與 n-6、n-3 PUFA 為主 |
| 膳食膽固醇 | **< 300 mg/天**，尤其高膽固醇者 |
| **碳水化合物** | 佔熱量 **45–55%**（> 70% 或 < 40% 死亡率都較高，U 型關係）；**不建議極低碳飲食** |
| **纖維** | 總纖維 **25–40 g/天**，其中**可溶性 ≥ 7–13 g**（燕麥、大麥的 β-glucan 每天 3–10 g 可降 LDL-C 3–5%） |
| 添加糖 | **< 10% 熱量**；高 TG、MetS、DM 或需減重者更嚴格；含糖飲料要大幅限制 |
| **果糖** | 每天 > 10% 熱量會升 TG；15–20% 熱量時 TG 可升 30–40% |
| **酒精** | 若 TG 不高，**男女每天 ≤ 10 g（1 單位）**可接受 |
| 減重 | 即使只減 **5–10%** 體重也改善血脂；熱量赤字 **300–500 kcal/天**，飲食加運動 |
| 運動 | 不論胖瘦，都建議每天 **≥ 30 分鐘**中強度運動；每公斤減重 HDL-C 升約 0.4 mg/dL |
| 飲食型態 | **Mediterranean diet**（PREDIMED：初榨橄欖油或堅果，主要 CV 事件約降 30%）、DASH |

## Table 9：降低 LDL-C、改善整體脂蛋白的食物選擇

| 食物類別 | 優先選擇 | 適量 | 偶爾、少量 |
| --- | --- | --- | --- |
| 穀類 | 全穀 | 精緻麵包、白飯、麵、餅乾、玉米片 | 酥皮點心、馬芬、派、可頌 |
| 蔬菜 | 生或熟的蔬菜 | 馬鈴薯 | 用奶油或鮮奶油烹調的蔬菜 |
| 豆類 | 扁豆、各種豆、豌豆、鷹嘴豆、黃豆 | — | — |
| 水果 | 新鮮或冷凍水果 | 果乾、果醬、罐頭水果、冰品、果汁 | — |
| 甜食 | 無熱量代糖 | 蔗糖、蜂蜜、巧克力、糖果 | 蛋糕、冰淇淋、**果糖、汽水** |
| 肉與魚 | **瘦肉魚與油脂魚**、去皮家禽 | 瘦的牛、羊、豬肉、海鮮、貝類 | **香腸、臘腸、培根、排骨、熱狗、內臟** |
| 乳品與蛋 | 脫脂奶與優格 | 低脂奶、低脂起司、**蛋** | 一般起司、鮮奶油、全脂奶與優格 |
| 烹調油與醬料 | 醋、芥末、無油醬料 | **橄欖油**、非熱帶植物油、軟質人造奶油、美乃滋、番茄醬 | **trans fat、硬質人造奶油（最好避免）、棕櫚油、椰子油、奶油、豬油** |
| 堅果與種子 | — | 各種無鹽堅果（椰子除外） | 椰子 |
| 烹調方式 | 烤、煮、蒸 | 快炒、烘烤 | **油炸** |

> [!warning] Pitfall
> **==椰子油、棕櫚油屬於「偶爾、少量」==**（飽和脂肪高），不是健康油；**蛋屬於「適量」**而非禁止。

## Box 10：提升生活型態改變遵從性的方法

1. **探索動機、找出矛盾心理**：權衡改變的利弊，建立自我效能，避免繞圈討論
2. 提供支持，和病人與家屬建立同盟
3. 讓伴侶、同住家人或照顧者一起參與
4. 使用 **OARS**：Open-ended questions、Affirmation、Reflective listening、Summarising
5. 依病人的文化、習慣與處境調整建議
6. 使用 **SMART** 目標：Specific、Measurable、Achievable、Realistic、Timely，並追蹤記錄

指引建議以**病人與家庭為中心、在同一醫療場域**整合處理，而不是在不同地方各自處理單一危險因子。

## 營養補充品與機能性食品

| 品項 | 2019 重點 |
| --- | --- |
| **Phytosterol／stanol** | 每天 **2 g（隨主餐）**降 TC、LDL-C **7–10%**，對 HDL-C、TG 幾乎無影響；**沒有 CV 結果研究**。可考慮用於：不需藥物的高膽固醇者、statin 未達標或不能用 statin 的高風險者、**> 6 歲的 FH 兒童與成人** |
| **紅麴（monacolin K）** | 機轉同 statin（抑制 HMG-CoA reductase）；每天 2.5–10 mg monacolin K 可降 LDL-C 達 20%；各產品含量不一、可能有污染物、也有類似 statin 的副作用 |
| **β-glucan 纖維** | 燕麥、大麥，每天 3–10 g 降 LDL-C 3–5% |
| 黃豆、policosanol、berberine | 證據不足或不一致 |

> [!info] 🆕 新版指引（2025 Focused Update）Recommendation Table 8
>
> | 建議 | 等級 |
> | --- | --- |
> | **==沒有證實安全性與顯著降 LDL-C 效果的營養補充品或維生素，不建議用來降低 ASCVD 風險==** | **III-B** |
>
> 依據：**SPORT**（199 人，28 天）：rosuvastatin 5 mg 降 LDL-C 明顯優於魚油、肉桂、大蒜、薑黃、植物固醇、紅麴與安慰劑，**沒有任何補充品比安慰劑顯著降 LDL-C**；**OMEMI**（70–82 歲、近期 MI、TG 不高者給 DHA＋EPA）**沒有減少事件**。
>
> 其他 2025 重點：phytosterol 每天 ≤ 2 g 可降 LDL-C 約 10%，但**沒有 CV 結果證據**；**歐盟 2022 年起禁售每日 ≥ 3 mg monacolin 的紅麴補充品**，較低劑量需警語。PUFA 補充品除了高 TG 情境的 **high-dose icosapent ethyl**（見 ⑤），都沒有證據能降 LDL-C 或事件。2019 對 phytosterol、紅麴「可考慮」的說法因此被這條 III 建議收緊。（2019 原文；已更新）
