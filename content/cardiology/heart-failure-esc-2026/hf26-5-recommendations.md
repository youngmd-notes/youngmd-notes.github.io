> [!abstract] 一句話重點
> 2026 版 **MRA 不論 LVEF、有症狀就給（I A）**、**住院中穩定後就開始 SGLT2-I（I B1）**、**FMT 至少每 1–2 週調升一次、LVEF 改善也不停（I C）**、**高血壓或 stage B → SBP < 130（I A）**；升級的有 **M-TEER（IIa → I）**、**LVAD（IIa → I）**、**digoxin（IIb → IIa）**、**TTR 用 vutrisiran／tafamidis／acoramidis（I A）**；降級的有 **CRT 取代 RV pacing（I → IIa）**。新的「不要做」：**未篩選的 MI 休克用 temporary MCS、懷孕用 RAAS 抑制劑／MRA／ivabradine／SGLT2-I**。

> 本篇涵蓋：Table 5（新增）、Table 6（修訂），逐條用中文整理。表中「I-B1」代表 Class I、Level B1；2026 版沒有獨立的 What to do／What not to do 表

> [!note] 2026 版的證據等級（Table 2）多了 B1、B2
> - **A**：≥ 2 個夠大、無重大偏差的 RCT（或其 meta-analysis），結論明確
> - **B1**：至少 1 個夠大的 RCT（或其 meta-analysis），**有提示性證據**
> - **B2**：≥ 2 個控制良好的非隨機研究，或小型 RCT 的 meta-analysis
> - **C**：非隨機研究、單一小型 RCT 或專家共識

先看修訂，因為「升級、降級」最容易考。

### 預防與診斷

| 主題 | 2021 版 | 2026 版 | 變化 |
| --- | --- | --- | --- |
| **血壓** | 治療高血壓預防 HF（I-A） | **高血壓或 stage B：SBP 目標 < 130 mmHg**（I-A） | ==有明確數字== |
| CMR | 超音波窗口差 → CMR（I-C）；疑似心肌病或病因不明 → 顯影 CMR（I-C）；浸潤性等疾病 → CMR（I-C）；DCM 用 LGE 分缺血與非缺血（IIa-C） | **疑似心肌病、或 HF 病因不明且 CMR 會有幫助 → 顯影 CMR**（I-C） | 合併成一條 |
| ICA（有心絞痛） | 藥物治療下仍心絞痛或有症狀的心室心律不整 → ICA（I-B） | HF＋心絞痛＋阻塞性 CAD 機率高、可能再通 → ICA（I-C） | 改寫條件 |
| **ICA（HFrEF）** | 中到高 PTL＋非侵入檢查有缺血 → 可考慮（IIb-B） | **HFrEF＋阻塞性 CAD 機率高 → 應考慮 ICA**（IIa-C） | **IIb → IIa**，不必先做壓力測試 |

### 慢性 HF 治療

| 主題 | 2021 版 | 2026 版 | 變化 |
| --- | --- | --- | --- |
| **MRA** | HFrEF（I-A）；HFmrEF 可考慮（IIb-C） | ==有症狀 HF 不論 LVEF 都給 MRA==（HFrEF 用 steroidal；HFpEF 用 steroidal 或 non-steroidal）（**I-A**） | ==HFmrEF／HFpEF 升為 I== |
| **Digoxin** | HFrEF 竇律、ACE-I／BB／MRA 後仍有症狀 → 可考慮（IIb-B） | **Digoxin 或 digitoxin：有症狀 HFrEF、LVEF ≤ 40%、optimal FMT 後 → 應考慮**（**IIa-B1**） | ==IIb → IIa==，加入 digitoxin |
| Vericiguat | NYHA II–IV、ACE-I／BB／MRA 下仍惡化 → 可考慮（IIb-B） | 有症狀 HFrEF、**LVEF < 45%**、optimal FMT 下 → 可考慮（IIb-B1） | 不再要求「惡化事件」 |
| **CRT vs RV pacing** | HFrEF 因高度 AV block 需心室起搏 → CRT 優於 RV pacing（I-A） | 同樣情境 → **應考慮** CRT（**IIa-B1**） | ==I → IIa（降級）== |

### Decompensated HF 與休克

| 主題 | 2021 版 | 2026 版 | 變化 |
| --- | --- | --- | --- |
| **利尿劑阻抗** | Loop 加量仍無效 → 加 thiazide 類（IIa-B） | 之前用過 loop、仍 fluid overload → **加短期 IV acetazolamide 或口服 HCTZ**（IIa-B1） | 加入 acetazolamide |
| **IABP** | MI 後心因性休克不常規用（III-B） | **未篩選的心因性休克不建議 IABP**（沒效）（III-B1） | 範圍擴大到所有休克 |
| Temporary MCS | 心因性休克作 BTR、BTD、BTB（IIa-C） | HF 相關血行不穩，選擇性作 BTR、BTD、BTB、BTC 或 BTT（IIa-C） | 擴大到 bridge to candidacy／transplant |

### Advanced HF

| 主題 | 2021 版 | 2026 版 | 變化 |
| --- | --- | --- | --- |
| **Inotrope** | 低心輸出＋器官低灌流，作為 MCS 或換心的橋樑 → 可考慮持續 inotrope／vasopressor（IIb-C） | Advanced HFrEF、低心輸出＋低灌流或器官功能不良 → **應考慮持續 inotrope**，作 BTD、BTT 或 durable MCS 的橋樑（**IIa-C**） | **IIb → IIa** |
| **LVAD** | 不能換心 → 長期 MCS（IIa-A）；作換心橋樑（IIa-B） | **選擇性 advanced HFrEF，FMT＋GDIT 後 → durable MCS（LVAD）**，作 BTT、BTC、BTR 或 destination therapy（**I-C**） | ==IIa → I== |

### 共病

| 主題 | 2021 版 | 2026 版 | 變化 |
| --- | --- | --- | --- |
| **AF rate control** | HF＋AF：beta-blocker 應考慮（IIa-B） | ==穩定 HFrEF＋AF：beta-blocker 是第一線==（**I-C**） | **IIa → I** |
| AF 燒灼 | AF 和 HF 惡化明確相關 → 應考慮燒灼（IIa-B） | 有症狀 AF＋HFrEF → 選擇性燒灼改善生活品質、降 HFH 與死亡（IIa-C） | 改寫條件 |
| **冠狀動脈再通** | HFrEF＋CCS、OMT 下仍心絞痛 → 應考慮（IIa-C） | **HF＋阻塞性 CAD、FMT＋抗心絞痛藥下仍心絞痛 → 再通**（**I-C**） | **IIa → I** |
| AS | 嚴重 high-gradient AS → TAVI 或 SAVR（I-B） | 嚴重 AS＋HF → SAVR 或 TAVI（I-B1） | 不限 high-gradient |
| **M-TEER** | 不能開刀、不需再通、OMT 下仍有症狀的 secondary MR → 應考慮（IIa-B） | ==血行穩定、有症狀 HFrEF、optimized FMT（及需要時 CRT）後仍嚴重 secondary MR、符合臨床與超音波條件 → M-TEER==（**I-B1**） | ==IIa → I== |

### 多專科照護與特殊情況

| 主題 | 2021 版 | 2026 版 | 變化 |
| --- | --- | --- | --- |
| **PA pressure 遠端監測** | 有症狀 HF → 可考慮（IIb-B） | **NYHA III＋12 個月內 HFH → 應考慮**（**IIa-B1**） | **IIb → IIa**，條件更明確 |
| **TTR amyloidosis** | hTTR 或 wtTTR、NYHA I–II → tafamidis（I-B） | ==Variant 或 wild-type TTR-CA、NYHA I–III → TTR silencer（vutrisiran）或 stabilizer（tafamidis、acoramidis）==（**I-A**） | 擴大到 NYHA III、加入新藥，證據升為 A |

## Table 5：2026 新增的建議

<div class="orig-fig" data-src="心臟科/hf-esc-2026-originals/table-05-1.png,心臟科/hf-esc-2026-originals/table-05-2.png,心臟科/hf-esc-2026-originals/table-05-3.png" data-label="Table 5 新建議"></div>

### 「不要做」（新增的 Class III）

| 不要做 | 等級 |
| --- | --- |
| ==未篩選的急性 MI 心因性休克 → 用 temporary MCS==（有害） | III-B1 |
| ==懷孕時用 ACE-I、ARB、ARNI、MRA、ivabradine、SGLT2-I==（胎兒毒性或致畸） | III-C |

### 預防（Stage A、B）

| 新建議 | 等級 |
| --- | --- |
| Stage A、B 都要衛教健康生活：維持體重、均衡飲食、少久坐、戒菸、不酗酒，不用 cocaine、amphetamine、anabolic steroid | I-C |
| T2DM＋至少一個其他 CV 危險因子 → **GLP-1 RA** 降 HF 或 CV 死亡 | IIa-A |
| ==Stage B、LVEF ≤ 40% → ACE-I（不耐受用 ARB）== | I-A |
| ==Stage B、LVEF < 50% → beta-blocker== | I-B1 |
| MI 後 LVEF ≤ 40%，有 HF 徵象或 DM → **eplerenone** | I-B1 |

### 診斷

| 新建議 | 等級 |
| --- | --- |
| ==懷疑 cardiac amyloidosis → serum／urine immunofixation＋serum free light chain＋骨掃描（DPD／PYP／HMDP）== | I-B |
| 符合心肌病診斷、且有助診斷、預後、治療、生育或家族篩檢 → **基因檢測** | I-C |
| 懷疑 cardiac sarcoidosis → **18F-FDG-PET** | IIa-C |
| 有 CIED 的人新發或惡化 HFrEF → 檢查 **RV pacing 比例** | IIa-C |
| Persistent AF，不確定恢復竇律對症狀或 LV 功能有沒有幫助 → **診斷性電擊整流** | IIb-C |

### 慢性 HF 治療

| 新建議 | 等級 |
| --- | --- |
| ==FMT 至少每 1–2 週調升一次==，依症狀、生命徵象與檢驗，達到試驗目標劑量 | I-C |
| ==沒症狀或 LVEF 改善也要繼續最高耐受劑量的 FMT== | I-C |
| 極少數：可逆病因治好後無症狀、LV 功能與容積及 NP 完全正常 → 依病人意願，密集監測下**逐步**停 FMT | IIb-C |
| 有症狀 HFpEF → ACE-I／ARB／ARNI 可考慮降 HFH | IIb-C |
| 有症狀 HFrEF、LBBB＋QRS ≥ 150 ms、LVEF ≤ 35% → **開始 FMT 和規劃 CRT 可同時進行**（放之前要再評估 LVEF） | IIb-C |

### Decompensated HF 與休克

| 新建議 | 等級 |
| --- | --- |
| 前幾天用 **urine Na 導引利尿** | IIb-B1 |
| ==穩定後住院中就開始 SGLT2-I==，改善生活品質與鬱血、降 HFH | I-B1 |
| 可能用 temporary MCS 的人 → **Shock Team** 決定裝置種類 | I-C |
| STEMI 心因性休克＋LV 收縮功能差、沒有缺氧腦傷 → **microaxial flow pump** | IIa-B1 |
| MI 機械性併發症 → temporary MCS 作為確定治療前的橋樑 | IIa-C |

### Advanced HF

| 新建議 | 等級 |
| --- | --- |
| ==Advanced HF 或可能進展、有意願、沒有換心或 durable MCS 絕對禁忌 → 盡早諮詢 advanced HF 中心== | I-A |
| Advanced HFrEF、治療後仍器官低灌流 → **減量或停 beta-blocker／ivabradine** 增加心輸出 | IIa-C |
| 非缺血性 HF 裝 LVAD 或換心時，取下的心臟組織送病理找可治療病因或供家族篩檢 | IIa-C |

### 共病

| 新建議 | 等級 |
| --- | --- |
| 嚴重症狀的 permanent AF、藥物 rate control 不佳、至少 1 次 HFH → **AV node ablation＋CRT** | IIa-B1 |
| 血行不穩的 HFrEF＋AF → **IV amiodarone 或 digoxin** 快速控制心跳 | IIb-C |
| ==有症狀 HF、LVEF ≥ 45%、BMI ≥ 30 → semaglutide 或 tirzepatide==（不論有無 DM） | IIa-B1 |
| BMI ≥ 35、生活型態加減重藥仍無法維持 → 減重手術 | IIb-C |
| HFrEF＋以**阻塞型**為主的睡眠呼吸障礙 → adaptive servo-ventilation 可考慮 | IIb-C |
| 評估焦慮、憂鬱與衰弱，訂個人化照護 | IIa-C |

### 多專科照護、復健、安寧

| 新建議 | 等級 |
| --- | --- |
| 穩定病人參加**運動型心臟復健**中的個人化運動訓練 | I-B1 |
| 心臟復健以外，長期持續個人化運動訓練 | I-B2 |
| LVAD 病人心臟復健 | I-B1 |
| DHF 安全時盡早心臟復健 | IIa-B1 |
| Advanced HF：主動討論病程、照護目標與預立醫療照護計畫 | I-B1 |
| Advanced HF：整合式 HF 安寧照護團隊 | I-B2 |

### 懷孕與生育

| 新建議 | 等級 |
| --- | --- |
| HF 病人做孕前諮詢（治療、懷孕、避孕、胚胎植入前基因篩檢、人工生殖） | I-C |
| 懷孕的 HFrEF：**non-selective beta-blocker 換成 beta1-selective（metoprolol、bisoprolol）**，密切監測母胎 | I-C |
