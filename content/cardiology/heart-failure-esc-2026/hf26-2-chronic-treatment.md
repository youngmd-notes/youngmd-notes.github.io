> [!abstract] 一句話重點
> **不論 LVEF，有症狀就給：==SGLT2-I（I A）＋MRA（I A；HFrEF 用 steroidal，HFpEF 可用 steroidal 或 finerenone）==**，有鬱血再加 **loop diuretic 依容積調整**。**HFrEF（LVEF < 50%）再加：beta-blocker＋ACE-I 或 ARNI（I A；ACE-I／ARB 換 ARNI I B1）**。**==至少每 1–2 週調升一次 FMT==** 到試驗目標劑量（I C）；**LVEF 改善或沒症狀也要繼續最高耐受劑量**（I C）。HFpEF：ACE-I／ARB／ARNI 可考慮（IIb C）。AMT：**digoxin／digitoxin（LVEF ≤ 40%，IIa B1）**、**ivabradine**（竇律、HR > 70）、**vericiguat**（LVEF < 45%）、H-ISDN。**ICD**：缺血性 LVEF ≤ 35%、FMT ≥ 3 個月（I B1）；非缺血性（IIa B1）；**MI 40 天內不放**。**CRT**：LVEF ≤ 35%、竇律、**LBBB＋QRS ≥ 150 ms（I A）**。

## FMT：誰吃什麼（Recommendation Table 5）

| 族群 | 藥物 | 等級 |
| --- | --- | --- |
| **==所有有症狀的 HF（不論 LVEF）==** | **SGLT2-I**（dapagliflozin 或 empagliflozin） | **I A** |
| | **MRA**（HFrEF：steroidal；HFpEF：steroidal 或 **non-steroidal finerenone**） | **I A**（修訂：以前只限 HFrEF） |
| | **Loop diuretic** 依容積狀態**動態調整**（有鬱血時） | I A |
| **==HFrEF（LVEF < 50%）==** | **Beta-blocker**（穩定的病人） | **I A** |
| | **ACE-I 或 ARNI** | **I A** |
| | **ACE-I／ARB 換成 ARNI** | I B1 |
| | ARB：**不耐受 ACE-I 和 ARNI** 才用 | I A |
| **HFpEF（LVEF ≥ 50%）** | **ACE-I／ARB／ARNI** 降低 HFH | IIb C（新） |

| 怎麼用 | 等級 |
| --- | --- |
| **==至少每 1–2 週調升一次==**，依症狀、生命徵象、檢驗，目標是試驗證實的劑量 | **I C**（新） |
| **LVEF 改善或沒有症狀也要繼續最高耐受劑量** | **I C**（新） |
| 極少數：可逆原因治好後**完全正常化**（LV 功能與大小、NP）、沒症狀 → 在密切監測下**逐步停藥**，尊重病人意願 | IIb C（新） |

## AMT：FMT 都上了還不夠（HFrEF）

| 藥物 | 條件 | 等級 |
| --- | --- | --- |
| **Digoxin 或 digitoxin** | 有症狀、**LVEF ≤ 40%**，optimal FMT 下 → 降低 HFH | **IIa B1**（修訂：升級） |
| **Ivabradine** | LVEF ≤ 35%、**竇律、休息 HR > 70**，已用最高耐受的 ACE-I／ARNI、MRA、SGLT2-I、beta-blocker | IIa B1 |
| **Ivabradine** | LVEF ≤ 35%、竇律、**不能耐受 beta-blocker** | IIa C |
| **Hydralazine＋ISDN** | **自我認定為黑人**、LVEF ≤ 40%，加在 FMT 之上 | IIa B2 |
| **Hydralazine＋ISDN** | LVEF ≤ 40%、**不能耐受 ARNI、ACE-I、ARB** | IIb C |
| **Vericiguat** | 有症狀、**LVEF < 45%**，optimal FMT 下 | IIb B1（修訂） |

> [!tip] Pearl：為什麼 MRA、SGLT2-I 變成「不分 LVEF」
> SGLT2-I 在 HFrEF 與 HFpEF 的試驗都降低 HFH 或 CV 死亡；MRA 在 HFrEF（steroidal）、HFpEF（finerenone）都有效 → 2026 把兩者放進**所有有症狀 HF 的基礎治療**。HFrEF 再多兩根柱子：**beta-blocker＋ACE-I／ARNI**。

## ICD（Recommendation Table 6）

| 建議 | 等級 |
| --- | --- |
| **次級預防**：從造成血行動力不穩的心室心律不整恢復、預期存活 > 1 年且功能好、沒有可逆原因（**MI 後 < 48 h 發生的除外**） | **I A** |
| **==缺血性 HFrEF、NYHA II–III、LVEF ≤ 35%、optimal FMT ≥ 3 個月==**（MI 40 天內除外），預期存活 > 1 年 | **I B1** |
| **非缺血性**、其他條件同上 | IIa B1 |
| 換 generator 前與病人共同決策 | IIa C |
| **Wearable defibrillator**：暫時的 SCD 風險（等待決定或等換心） | IIb C |
| **==MI 40 天內不放初級預防 ICD==** | **III B1** |
| **NYHA IV 藥物無效**（除非要 CRT、VAD 或換心）不放 | III C |

- **抗心律不整藥（amiodarone、dronedarone）不延長存活、甚至可能縮短**；ICD 才能預防 SCD

## CRT（Recommendation Table 7、Figure 10）

| 建議 | 等級 |
| --- | --- |
| **==有症狀 HFrEF、LVEF ≤ 35%、竇律、LBBB、QRS ≥ 150 ms==** | **I A** |
| 竇律、**non-LBBB、QRS ≥ 150 ms** | IIa C |
| 竇律、**LBBB、QRS 130–149 ms** | IIa C |
| 竇律、non-LBBB、QRS 130–149 ms | IIb |
| **HFrEF 需要心室起搏（高度 AV block）→ CRT 而非 RV pacing**（不論 NYHA、QRS） | IIa B1（修訂） |
| 已有 pacemaker 或 ICD、LVEF ≤ 35%、**RV pacing 比例高、HF 惡化 → upgrade 成 CRT** | IIa B1 |
| LBBB＋QRS ≥ 150、LVEF ≤ 35% → **FMT 起始與 CRT 規劃可同時進行**（放之前再評估 LVEF） | IIb C（新） |
