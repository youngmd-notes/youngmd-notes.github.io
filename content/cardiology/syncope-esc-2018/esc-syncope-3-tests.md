> [!abstract] 一句話重點
> 每項檢查都有「**適應症**」和「**診斷標準**」兩組建議。必背：**CSM 用在 > 40 歲（I-B）**；**active standing 3 分鐘（I-C）**；**tilt test 降為 IIa**，代表的是 **hypotensive susceptibility** 而非確診；**ILR 有兩個 I-A**；**bifascicular block＋HV ≥ 70 ms → pacemaker（I-B）**；**HCM＋syncope、靜止 gradient < 50 → exercise echo（I-B）**。

## 一張表看所有檢查

| 檢查 | 什麼時候做 | 陽性代表什麼 |
| --- | --- | --- |
| **CSM** | **> 40 歲**、原因不明、符合 reflex 機轉（I-B） | 重現症狀的 asystole／低血壓 → **CSS**（I-B） |
| **Active standing** | 初次評估就做：躺著與站立 **3 分鐘**量 BP、HR（I-C） | 重現症狀的 OH → 確診 OH syncope（I-C） |
| **Tilt test** | 懷疑 reflex、OH、POTS、PPS（IIa-B） | 重現症狀＋特徵血行動力 → 「應考慮」該診斷（IIa-B） |
| **Autonomic tests** | 懷疑 **neurogenic OH**：Valsalva、deep breathing（IIa-B） | Autonomic failure |
| **ABPM** | Autonomic failure 找 **nocturnal hypertension**（I-B） | Non-dipping／reverse dipping |
| **In-hospital monitoring** | **High-risk**（I-C） | |
| **Holter** | **≥ 1 次／週**（IIa-B） | 症狀與心律相關才算 |
| **External loop recorder** | 症狀間隔 **≤ 4 週**，事件後早期（IIa-B） | |
| **ILR** | 反覆不明 syncope、無 high-risk（**I-A**）；high-risk 完整檢查後仍不明（**I-A**） | 症狀－心律相關 → 確診（I-B） |
| **Video** | 家中錄下發作（IIa-C） | |
| **EPS** | 舊 MI／scar（I-B）、bifascicular block（IIa-B） | HV ≥ 70 ms → pacemaker（I-B） |
| **Echo** | 懷疑 structural heart disease（I-B） | AS、腫瘤、tamponade、dissection（I-C） |
| **Exercise test** | **運動中或剛運動完**昏倒（I-C） | 運動中出現 2°／3° AV block（I-C） |
| **Coronary angiography** | 和沒有 syncope 的病人適應症相同（IIa-C） | 單靠 angiography **不能**診斷 syncope 原因 |

## 建議：Carotid sinus massage（CSM）

| 建議 | 等級 |
| --- | --- |
| **適應症**：**> 40 歲**、原因不明、符合 reflex 機轉的 syncope | **I-B** |
| **診斷標準**：CSM 引發 bradycardia（asystole）及／或低血壓並**重現平常的症狀**，且臨床符合 reflex 機轉 → **確診 CSS** | **I-B** |

- **Carotid sinus hypersensitivity（CSH）**：CSM 引發 **pause > 3 秒**及／或 **SBP 下降 > 50 mmHg**；常見於沒有 syncope 的老年男性（可達 **≤ 40%**），所以是**非特異的發現**
- **CSS = 有 syncope 病史＋CSM 重現症狀**；CSS 通常表現為 **asystole > 6 秒**。CSH 在 **< 40 歲非常少見**
- CSM 要在**平躺和站立**兩種姿勢做，並持續 beat-to-beat BP 監測（tilt lab 較方便）
- 神經學併發症很少（四個研究合計 **0.24%**），但 **==曾 TIA、stroke 或已知 carotid stenosis > 70%== 要小心**
- 2018 版**拿掉了**舊版的「CSM 禁忌症」建議（舊版 III → 刪除）

## 建議：Active standing（主動站立測試）

<div class="orig-fig" data-src="心臟科/syncope-esc-originals/table-08.png" data-label="Table 8 與 Active standing 建議"></div>

| 建議 | 等級 |
| --- | --- |
| 初次評估時用血壓計間歇量測**平躺與主動站立 3 分鐘**的 BP、HR | **I-C** |
| 懷疑短暫 BP 變化（例如 **initial OH**）時，偏好用**連續 beat-to-beat** 非侵入量測 | **IIb-C** |
| **確診 OH syncope**：SBP 下降 **≥ 20 mmHg** 或 DBP **≥ 10 mmHg**，或 **SBP 降到 < 90 mmHg**，且**重現平常症狀** | **I-C** |
| 無症狀的上述血壓下降＋病史**符合** OH → 應認為 OH 可能 | **IIa-C** |
| 有症狀的血壓下降＋病史**不完全**符合 → 應認為 OH 可能 | **IIa-C** |
| **POTS**：站立 10 分鐘內 HR 上升 **> 30 bpm** 或到 **> 120 bpm**，沒有 OH，且重現症狀 → 應認為可能 | **IIa-C** |
| 無症狀的血壓下降＋病史**較不符合** → 可認為 OH 有可能 | **IIb-C** |

## Table 8：Orthostatic intolerance 病史 × 站立血壓的診斷強度

| 站立血壓結果 ＼ 病史 | **高度提示 OH**<br/>（站著才有症狀、躺下就好；早上較嚴重；運動後、飯後、熱天變差；沒有 autonomic activation） | **可能是 OH**<br/>（只有部分特徵） |
| --- | --- | --- |
| **有症狀**的異常血壓下降 | <span style="color:#2e7d32">**Syncope 由 OH 造成（I）**</span> | **很可能是 OH（IIa）** |
| **無症狀**的異常血壓下降 | **很可能是 OH（IIa）** | **可能是 OH（IIb）** |
| 沒有血壓下降 | 未證實 | 未證實 |

> [!tip] Pearl
> OH 的診斷**一定要病史和站立血壓兩邊都對上**；只有血壓下降而病史不像，最多只能說「可能」。

## 建議：Tilt testing

| 建議 | 等級 |
| --- | --- |
| **適應症**：懷疑 **reflex syncope、OH、POTS 或 PPS** | **IIa-B** |
| 可用來**教育病人**認識症狀、練習 physical manoeuvres | **IIb-B** |
| **診斷標準**：tilt 重現症狀，並出現該疾病特徵的循環變化 → 應認為 reflex、OH、POTS 或 PPS 可能 | **IIa-B** |

**補充觀點**：

- **==Tilt 陰性不能排除 reflex syncope==**
- 在「原因不明」的真實族群，tilt 陽性代表的是 **hypotensive susceptibility**（低血壓傾向），這種傾向也存在於部分 cardiac syncope；它的價值在於**指引 pacemaker 與降壓藥的決策**（見 ④）
- **Cardioinhibitory 陽性反應**高度預測自發性 syncope 也是 asystole；但 vasodepressor、mixed 甚至陰性反應**都不能排除**自發時的 asystole
- 可幫助區分：syncope 合併抽動 vs epilepsy、syncope vs falls、syncope vs **PPS**（懷疑 PPS 時最好同時做 **EEG**，EEG 正常支持 PPS；沒有 EEG 就錄影）
- **==不可用 tilt 評估藥物療效==**（舊版 III → 2018 刪除此項）

| --- | --- |

| **原因不明**的 syncope | 30–36% |
| **沒有 syncope 的對照組** | **8–13%** |

> [!warning] Pitfall
> **==最需要 tilt 的時候（不典型、原因不明），它的陽性率反而只有三到五成==**；而 cardiac syncope 也有將近一半是陽性。所以 tilt 陽性 ≠ 排除 cardiac syncope，只代表這個人有低血壓傾向。

## 建議：基本 autonomic function tests 與血壓監測

| 建議 | 等級 |
| --- | --- |
| **Valsalva maneuver**：懷疑 neurogenic OH 時評估自律神經 | **IIa-B** |
| Valsalva 用來確認某些 situational syncope（咳嗽、吹銅管、唱歌、舉重）的低血壓傾向 | **IIb-C** |
| **Deep-breathing test**：懷疑 neurogenic OH | **IIa-B** |
| 其他（30:15 ratio、cold pressor、sustained hand grip、mental arithmetic） | **IIb-C** |
| **ABPM 找 autonomic failure 病人的 nocturnal hypertension** | **I-B** |
| ABPM 監測 autonomic failure 病人日常的 OH 與 supine hypertension | **IIa-C** |
| ABPM、HBPM 確認疑似 orthostatic intolerance 發作時 BP 是否過低 | **IIb-C** |

- **Valsalva 時沒有 BP overshoot、也沒有 HR 上升**，是 neurogenic OH 的**特徵性表現**
- Deep breathing：健康 > 50 歲者吸吐間 HR 差（E/I index）**≥ 15 bpm**；變異變小代表 parasympathetic dysfunction
- 懷疑 situational syncope 時，盡量在 beat-to-beat 監測下**重現該情境**（咳嗽、吞嚥、大笑等）

## 建議：ECG monitoring（含 ILR）

| 建議 | 等級 |
| --- | --- |
| **High-risk**（Table 6）→ **立即住院監測**（床邊或 telemetry） | **I-C** |
| **Holter**：syncope 或 presyncope **≥ 1 次／週** | **IIa-B** |
| **External loop recorder**：事件後早期、症狀間隔 **≤ 4 週** | **IIa-B** |
| **ILR**：**早期**用於反覆不明 syncope、**沒有 high-risk 條件**、且電池壽命內很可能再發 | **I-A** |
| **ILR**：**有 high-risk 條件**、完整評估仍找不到原因或無法給特定治療、且**沒有** primary prevention ICD 或 pacemaker 的傳統適應症 | **I-A** |
| ILR：懷疑或確定 reflex syncope、但發作**頻繁或嚴重** | **IIa-B** |
| ILR：懷疑 **epilepsy 但治療無效** | **IIb-B** |
| ILR：**unexplained falls** | **IIb-B** |
| **診斷標準**：記錄到 syncope 與 arrhythmia（brady 或 tachy）**相關** → 確診 arrhythmic syncope | **I-B** |
| 沒有 syncope，但記錄到 **Mobitz II 2°／3° AV block**、**ventricular pause > 3 秒**（年輕運動員、睡眠中、rate-controlled AF 可能例外）、或快速持續的 SVT／VT → 應認為 arrhythmic syncope 可能 | **IIa-C** |

**補充觀點**：

- 選對病人最重要：選**心律不整機率高、短期內會再發、找到原因後有特定治療可給**的人；已經有明確 ICD／pacemaker 適應症者**不必再監測**
- 可能要等 **4 年以上**才抓到相關性
- 沒有心律不整時，**presyncope 不能當 syncope 的替代指標**；但 presyncope 時記錄到顯著心律不整可視為診斷
- **==Syncope 發作當下沒有心律不整，就排除 arrhythmic syncope==**

> [!tip] Pearl
> **ILR 的證據**：5 個 RCT 統合分析，及早放 ILR 的診斷機率是傳統檢查（external loop、tilt、EPS）的 **3.7 倍**，而且更符合成本效益。完整檢查都陰性後放 ILR 的 506 人中，**35%** 抓到症狀－心律相關：其中 **56% 是 asystole**（少數 bradycardia）、11% tachycardia、**33% 沒有心律不整**。

## 建議：Video recording

| 建議 | 等級 |
| --- | --- |
| **應鼓勵病人與家屬在家錄下自發性發作** | **IIa-C** |
| Tilt test 時加上錄影，增加觀察的可靠性 | **IIb-C** |

## 建議：Electrophysiological study（EPS）

| 建議 | 等級 |
| --- | --- |
| **適應症**：syncope＋**previous MI 或其他 scar**，非侵入檢查後仍不明 | **I-B** |
| syncope＋**bifascicular BBB**，非侵入檢查後仍不明 | **IIa-B** |
| syncope＋**無症狀 sinus bradycardia**，非侵入檢查無法證明兩者相關 | **IIb-B** |
| syncope 前有**突發短暫心悸**，非侵入檢查後仍不明 | **IIb-C** |
| **EPS-guided**：不明 syncope＋bifascicular BBB，若 **baseline HV ≥ 70 ms**、incremental atrial pacing 或藥物激發出 **2°／3° His-Purkinje block** → **pacemaker** | **I-B** |
| 舊 MI 或 scar 的不明 syncope，誘發出 **sustained monomorphic VT** → 依 ESC VA 指引處理 | **I-B** |
| 沒有 structural heart disease、syncope 前突發心悸，誘發出重現症狀的**快速 SVT 或 VT** → 依指引給適當治療 | **I-C** |
| syncope＋無症狀 sinus bradycardia，**corrected SNRT 延長** → 應考慮 pacemaker | **IIa-B** |

- SNRT 異常：**≥ 1.6–2 秒**，或 **corrected SNRT ≥ 525 ms**
- Bifascicular block 的藥物激發：ajmaline、procainamide、disopyramide；EPS 陽性預測未來 AV block 的 **PPV 可達 ≥ 80%**，因此 HV ≥ 70 ms 的 pacing 建議由 **IIa 升為 I**
- 但 **EPS 的 negative predictive value 低**：EPS 陰性後放 ILR，約**三分之一**之後出現 AV block
- 缺血性心肌病或 DCM 誘發出 **polymorphic VT 或 VF** **不能**當作 syncope 的診斷
- **ECG 正常、沒有心臟病、沒有心悸**的 syncope，EPS 通常沒有用

> [!note] Adenosine（ATP）test
> 快速（< 2 秒）推 **20 mg** ATP／adenosine：誘發 **AV block 合併 asystole > 6 秒**或 **AV block > 10 秒**為異常。因為和 ILR 記錄到的自發事件**相關性低**，**不支持常規用來挑 pacemaker 病人**；2018 版把舊版的 ATP test 建議（III）刪除，只把陽性當作「懷疑 asystolic syncope、需長期監測確認」的線索。

## 建議：Echocardiography

| 建議 | 等級 |
| --- | --- |
| **懷疑 structural heart disease** 時，用於診斷與風險分層 | **I-B** |
| **HCM＋syncope**，靜止或激發的 peak LVOT gradient **< 50 mmHg** → 站、坐或半臥姿 **exercise 2D／Doppler echo** 找可誘發的 LVOTO | **I-B** |
| **診斷標準**：echo 顯示 **AS、阻塞性腫瘤或血栓、tamponade、aortic dissection** 的典型表現 → 是最可能的原因 | **I-C** |

- 病史、PE、ECG 都**不懷疑心臟病**的人，echo 沒有額外資訊：**==syncope 本身不是 echo 的適應症==**
- Echo 無法確診時，選擇性考慮 **CT 或 MRI**

## 建議：Exercise testing 與 coronary angiography

| 建議 | 等級 |
| --- | --- |
| **運動中或剛運動後**昏倒 → exercise test | **I-C** |
| 運動中出現 **2° 或 3° AV block**（即使沒昏倒）→ 確診該 AV block 造成的 syncope | **I-C** |
| **運動後立即**重現 syncope 合併嚴重低血壓 → 確診 **reflex syncope** | **I-C** |
| Syncope 病人的 coronary angiography 適應症和沒有 syncope 者相同 | **IIa-C** |

- **沒有資料支持常規做 exercise test**
- 運動**中**昏倒偏向 cardiac；運動**後**昏倒偏向 reflex
- 運動誘發的 AV block 通常在 **AV node 以下**（tachycardia-dependent），預示會進展成永久性 AV block
