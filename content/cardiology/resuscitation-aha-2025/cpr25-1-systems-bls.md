> [!abstract] 一句話重點
> **一條救命之鏈**同時適用成人、兒童、院內、院外（從**預防與準備**開始，到**康復與存活**）。**成人 BLS 最重要的就是早期高品質 CPR＋盡快電擊**。2025 重點更新：**==沒有 advanced airway 前，民眾和醫護都用 30:2==**（可以看胸部有沒有起伏，確認通氣有效）；**每次通氣有明顯胸部起伏**，避免通氣不足或過度；**病人放在硬的平面、軀幹約在施救者膝蓋高度**；**肥胖病人照一般方式 CPR**；**不常規用機械 CPR**；**胸罩可以調整位置、不必脫掉**再貼電擊貼片。**==成人與兒童嚴重異物哽塞：5 次背擊 → 5 次腹戳，重複==**（嬰兒用胸戳；孕婦晚期或抱不住腹部用胸戳）。

## 建議等級怎麼讀（Figure 1–2）

| COR | 意義 | 常見寫法 |
| --- | --- | --- |
| **1（strong）** | 好處 ≫ 風險 | is recommended、should |
| **2a（moderate）** | 好處 > 風險 | is reasonable |
| **2b（weak）** | 好處 ≥ 風險 | may be considered |
| **3: No Benefit** | 好處＝風險 | is not recommended |
| **3: Harm** | 風險 > 好處 | potentially harmful |

- 760 條建議：**Class 1 有 233 條**、**Class 2 有 451 條**、**Class 3 有 76 條**（55 條無益、21 條有害）；**Level A 只有 11 條（1.4%）**
- Highlights 不標 COR／LOE，只標 **2025 (New)**、**2025 (Updated)**；本系列照此呈現

## 倫理（2025 全新章節）

| 主題 | 重點 |
| --- | --- |
| **四大原則** | beneficence、nonmaleficence、**respect for autonomy**、justice |
| **成人 arrest 的預設** | **開始 CPR**；例外：**施救者有嚴重危險**、**明顯不可逆死亡徵象**、**有拒絕急救的預立醫療指示** |
| 預立醫療 | **最好用可攜式維生醫療醫囑**（portable orders）記錄；沒有時由**代理人以病人的意願判斷**（substituted judgement） |
| 家屬口頭拒絕 CPR | 某些情況下接受是合乎倫理的 |
| **無實際益處的治療** | 醫護**沒有義務提供**，即使代理人要求；盡量由**倫理委員會或諮詢**依機構政策決定 |
| 終止急救 | **事先定好的 termination of resuscitation 規則**可減少無效治療 |
| **家屬在場** | 可**減少複雜性悲傷**；機構要訂政策與資源 |
| ECPR | 資源密集、選擇病人資料有限、公平分配問題 |
| 器官捐贈 | **腦死或計畫撤除維生治療**的 arrest 後病人都應考慮；**臨終決定要先做、且獨立於捐贈討論** |

- 醫護人員的**道德困擾**（moral distress）：機構要提供政策與支持，不能只靠個人承擔

## 救命之鏈與醫療系統（Figure 3）

**單一救命之鏈**（成人、兒童、IHCA、OHCA 共用）：

```mermaid
    A["預防與準備"] --> B["辨識與<br/>啟動急救系統"] --> C["高品質 CPR"] --> D["電擊"] --> E["高級急救"] --> F["ROSC 後照護"] --> G["康復與存活"]
```

| 主題 | 2025 建議 | 狀態 |
| --- | --- | --- |
| **預防 IHCA** | 高風險住院病人做 **safety huddle**（提升情境警覺）可減少 arrest；與 early warning system、rapid response team 合併建議 | New |
| **Naloxone 公共取得** | 法律應允許民眾**持有、使用，並對善意使用免責**；**naloxone 發放計畫**可降低鴉片類過量死亡 | New |
| 民眾 CPR | 社區措施組合、**增加講師帶領的課程**、媒體宣傳、要求一般民眾取得 CPR 認證 | Updated／New |
| **電話指導 CPR** | **成人 → Hands-Only CPR**；**兒童 → 含人工呼吸的傳統 CPR**；用 **No-No-Go** 辨識 OHCA（沒反應、沒正常呼吸 → 開始） | Updated |
| **Debriefing** | **立即（hot）＋延遲（cold）**都做，可找到不同的改善機會 | New |
| OHCA 團隊 | 現場有 **ALS 級人員**有益；EMS 人數要足以分工 | New |
| **院內 code team** | 成員要有 **ALS 訓練**；**角色明確、模擬訓練**的專責團隊可改善預後 | New |
| **現場急救 vs 轉送** | 多數 OHCA **先在現場達到 sustained ROSC 再轉送**；轉送中 CPR 品質差、施救者危險；EMS 要會**現場終止急救與告知家屬** | New |
| ECPR 系統 | 定期檢討**選病人標準**、經驗豐富的經皮插管者、**區域化**；極少數高度選擇的 OHCA 可考慮**急救中快速轉送做 ECPR** | New |
| 器官捐贈 | 機構要建立 arrest 後器官捐贈的系統 | New |
| **康復** | 出院前評估、出院後再評估、持續滿足需求的整合系統 | New |

## 成人 BLS：2025 更新

| 主題 | 2025 建議 | 狀態 |
| --- | --- | --- |
| **頭頸部外傷的呼吸道** | 先 **jaw thrust＋呼吸道輔助器**；打不開 → **head tilt–chin lift**（呼吸道暢通優先） | Updated |
| **按壓姿勢** | 病人在**硬的平面**，**軀幹約在施救者膝蓋高度** | 新重點 |
| **==通氣量==** | 給到**看得到胸部起伏**的潮氣量 | Updated |
| **通氣** | **避免通氣不足（太少、太小）也避免過度通氣（太多、太大）** | Updated |
| **呼吸停止（有脈搏）** | **每 6 秒 1 次（10 次/分）**，每次有胸部起伏 | 新重點 |
| **==按壓：通氣比==** | **放 advanced airway 之前，民眾與醫護都用 30:2** | Updated |
| **電擊貼片** | 可以**調整胸罩位置**，不一定要脫掉 | New |
| **肥胖病人** | **照一般技巧 CPR** | New |
| **機械 CPR** | **不常規使用**；手動按壓困難或危險的特殊情境（並嚴格減少中斷）可考慮 | Updated／New |
| 演算法 | **醫護 BLS 演算法加入 naloxone**（疑似鴉片類過量的呼吸或心跳停止） | Updated |

- **30:2 的理由**：多數研究顯示 30:2 與連續按壓的結果沒差，但**通氣常常不夠**；30:2 讓施救者**能看胸部起伏、確認通氣有效**
- 女性接受公共 AED 的比例**明顯低於男性**，需要露出胸部可能是原因之一 → 允許調整胸罩

## 異物哽塞 FBAO（Figure 6 依內容重新整理）

**嚴重哽塞的徵象**：**咳不出來或咳嗽微弱**、**無法說話**、**發紺**、意識改變、呼吸停止

| 對象 | 有意識、嚴重哽塞 | 失去意識 |
| --- | --- | --- |
| **==成人==** | **5 次背擊（拍背）→ 5 次腹戳**，重複到異物出來或失去意識 | **開始 CPR**（先按壓）；**給呼吸前先看口中有沒有看得到的異物** |
| **成人：孕婦晚期、或抱不住腹部** | **5 次背擊 → 5 次胸戳** | 同上 |
| **兒童** | **5 次背擊 → 5 次腹戳**（2025 改為先背擊） | 同上 |
| **嬰兒** | **5 次背擊 → 5 次胸戳**（**用單手掌根**）；**不做腹戳**（傷腹部器官） | 同上 |

- 輕度哽塞（能咳嗽）→ **鼓勵咳嗽**、持續觀察
- **嚴重哽塞要先啟動急救系統**：失去意識後可能很快心跳停止
- **為什麼先背擊**：成人研究中**背擊的解除率較高、受傷較少**；為了和嬰兒、兒童的做法一致，改成交替

## 兒童 BLS：2025 更新

- 兒童 arrest **多半不是心因性**，而是**呼吸衰竭或休克**惡化的結果 → 早期辨識重病兒童最重要
- 每年美國 **> 7,000 例兒童 OHCA**、約 **20,000 例 IHCA**；**嬰兒 OHCA 存活率特別差**

| 主題 | 2025 建議 | 狀態 |
| --- | --- | --- |
| **中斷** | **按壓暫停 < 10 秒**（暫停越多越久，ROSC 越少） | New |
| **==嬰兒按壓手法==** | **單手掌根**或**雙拇指環抱法**；**==兩指法不再建議==**（深度不足） | Updated |
