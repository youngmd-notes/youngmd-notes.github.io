> [!abstract] 一句話重點
> - **所有 PE 至少抗凝 3 個月（I-A）**
>   - 之後依 **Table 11 的復發風險**決定：**major transient／reversible factor（如大手術、骨折外傷）→ 3 個月停（I-B）**
>   - **反覆 VTE、APS → 終生（I-B，APS 用 VKA）**
>   - **沒有可辨識危險因子、persistent 或 minor transient factor → 應考慮無限期（IIa）**，延長期可用 **apixaban 2.5 mg bid 或 rivaroxaban 10 mg qd（IIa-A）**
> - **癌症**：前 6 個月 **LMWH（IIa-A）**，非 GI 癌可用 **edoxaban 或 rivaroxaban**，之後**無限期或到癌症治癒**

## 抗凝療程的基本結論

- **所有 PE 至少 3 個月**
- 停藥後的復發風險，**3–6 個月停**和**更久（12–24 個月）才停**差不多 → 延長一段時間再停沒有好處，要決定的是「**停」還是「無限期**」
- 延長口服抗凝可**減少復發約 90%**，但部分被出血抵消
- 抗凝**只在吃藥期間**有效，停藥後風險回來
- 復發率在 PE 與 proximal DVT 之後相近；但 **PE 後復發較常以 PE 表現**，**PE 後復發的致死率是 DVT 後的 2 倍**
- **==指引不再使用 provoked／unprovoked、idiopathic 等詞==**：容易誤導，也無助於決定療程

| 長期復發風險（3 個月後停藥） | 危險因子類別 | 例子 |
| --- | --- | --- |
| **Low（< 3%／年）** | **Major transient 或 reversible factor**（使首次 VTE 風險增加 **> 10 倍**） | **全身麻醉 > 30 分鐘的手術**；因急性病或慢性病惡化**住院臥床 ≥ 3 天**（只能下床上廁所）；**骨折外傷** |
| **Intermediate（3–8%／年）** | **Transient 或 reversible factor**（風險增加 **≤ 10 倍**） | **Minor surgery**（全身麻醉 < 30 分鐘）；急性病**住院 < 3 天**；**estrogen 治療或避孕藥**；**懷孕或產褥期**；急性病**院外臥床 ≥ 3 天**；**腿受傷（沒骨折）活動減少 ≥ 3 天**；**長途飛行** |
| | **Non-malignant persistent factor** | **IBD**、**active autoimmune disease** |
| | **沒有可辨識的危險因子** | — |
| **High（> 8%／年）** | — | **==Active cancer==**；**沒有 major transient factor 的 VTE 反覆發生**；**==Antiphospholipid antibody syndrome==** |

> [!note] 表註
> 分類與 ISTH 的建議一致。

> [!tip] Pearl
> 這張表直接對應療程：**low → 3 個月停**；**intermediate → 應考慮無限期**（看出血風險與病人意願）；**high → 無限期**（APS 用 VKA、癌症看 8.6 的建議）。

**其他復發相關重點**：

- PE 後停藥：transient risk factor 每年復發 **2.5%**，沒有已知癌症、thrombophilia 或 transient factor 的 **4.5%**
- **遺傳性 thrombophilia**：**antithrombin、protein C、protein S deficiency**，**homozygous factor V Leiden**、**homozygous prothrombin G20210A** → 首次 PE（沒有 major reversible factor）後常是無限期抗凝的對象
- **Heterozygous factor V Leiden 或 prothrombin 20210A**：延長抗凝**沒有證據**顯示有益
- **何時驗 thrombophilia（含 APS 抗體、lupus anticoagulant）**：**年輕（例如 < 50 歲）、沒有可辨識危險因子**，尤其有**強烈家族史**時可考慮
- 復發預測模型（Supplementary Table 13）在 NOAC 時代的價值不清楚

## 抗凝出血風險

- VKA 年 major bleeding 約 **3%**；NOAC 比 VKA **減少約 40%**
- **第一個月出血風險最高**，之後下降並維持穩定
- **危險因子**：**高齡（尤其 > 75 歲）**、**過去出血或貧血**、**active cancer**、**過去 stroke（出血性或缺血性）**、**慢性腎病或肝病**、**併用 antiplatelet 或 NSAID**、其他嚴重疾病、**抗凝控制不佳**
- **開始抗凝時評估**，之後定期再評估（低風險每年、高風險每 3 或 6 個月）；用來**找出並矯正可改變的因子**，也影響療程與劑量

## 延長抗凝的藥物證據

| 藥物 | 試驗重點 |
| --- | --- |
| **Dabigatran** | 對 warfarin 不劣、優於 placebo；major bleeding **0.9% vs 1.8%**（vs warfarin） |
| **Rivaroxaban** | 20 mg qd vs placebo：復發 **減少 80%**，major 或 CRNM bleeding 6.0% vs 1.2%；**EINSTEIN-CHOICE：20 或 10 mg qd vs aspirin 100 mg** → 兩種劑量復發都**減少約 70%**，出血沒差 |
| **Apixaban** | **2.5 或 5 mg bid** vs placebo（已治療 6–12 個月）：兩劑量都減少復發或死亡，沒有安全疑慮 |
| **Aspirin** | vs placebo 減少復發 **30–35%**；但 **rivaroxaban 優於 aspirin** |
| **Sulodexide** | 首次、無危險因子的 VTE，減少復發約 50%，出血未增加（PE 只占 8%） |
| **APS（triple positive）** | **==Rivaroxaban 比 warfarin 更多血栓與出血（HR 6.7）==** → NOAC **不能取代** VKA |

- 延長試驗都**排除高出血風險**的人，VKA 試驗也是 → 挑選延長抗凝的對象時要考慮
- 延長期的 NOAC 試驗中 PE 約占 1/3；臨床實務的出血率可能比試驗高（試驗中 major ~1%、CRNM 可達 6%）

## 建議：沒有癌症的 PE 抗凝療程（Section 8.4）

| 建議 | 等級 |
| --- | --- |
| **==所有 PE 治療性抗凝 ≥ 3 個月==** | **I-A** |
| **首次 PE／VTE 由 major transient／reversible factor 造成 → 3 個月後停** | **I-B** |
| **反覆 VTE**（至少一次過去的 PE 或 DVT，且不是 major transient factor 造成）→ **無限期** | **I-B** |
| **==Antiphospholipid antibody syndrome → 無限期 VKA==** | **I-B** |
| 首次 PE、**沒有可辨識危險因子** → 應考慮**無限期** | **IIa-A** |
| 首次 PE 合併 **APS 以外的 persistent risk factor** → 應考慮無限期 | IIa-C |
| 首次 PE 合併 **minor transient／reversible factor** → 應考慮無限期 | IIa-C |
| 決定延長、且沒有癌症：**6 個月治療劑量後**應考慮減量為 **==apixaban 2.5 mg bid 或 rivaroxaban 10 mg qd==** | **IIa-A** |
| 拒絕或無法耐受任何口服抗凝 → 可考慮 **aspirin 或 sulodexide** 做延長預防 | IIb-B |
| 延長抗凝者**定期評估**耐受性與服藥順從度、**肝腎功能**、出血風險 | **I-C** |

> [!note] 表註
> - 選 **dabigatran 或 edoxaban** 延長抗凝時**劑量不變**：減量方案沒有在專門的延長試驗中研究過
> - 腎功能監測對 NOAC 尤其重要
> - 特殊臨床情境的建議在線上附錄 Supplementary Table 9

## 癌症病人的 PE

| 研究 | 結果 |
| --- | --- |
| LMWH vs VKA（5 個 RCT） | **LMWH 減少復發約 40%**，major bleeding 相近 → LMWH 成為標準；但 LMWH 治療下的復發率仍高（**7–9%**，非癌症 1.5–3%） |
| **Hokusai VTE Cancer：edoxaban vs dalteparin**（1050 人；先 LMWH 5 天，edoxaban 60 mg qd，特定情況 30 mg） | 復發或 major bleeding **不劣**（HR 0.97）；**major bleeding 6.9% vs 4.0%**，主要來自 **GI cancer** |
| **SELECT-D：rivaroxaban vs dalteparin**（406 人，58% 轉移） | 復發減少（HR 0.43）；major bleeding 6% vs 4%（多為 GI）；**CRNM bleeding 13% vs 4%** |

**怎麼選**：

- **==GI cancer、口服吸收有問題、嚴重腎功能不全 → 繼續 LMWH（3–6 個月）==**
- 其他（尤其低出血風險、非 GI 腫瘤）→ LMWH 或 edoxaban、rivaroxaban 由醫師與病人決定
- **癌症病人首次 VTE 後應無限期抗凝**；癌症治癒後風險可能下降可停，但「治癒」的定義常不清楚
- 癌症 PE 復發預測分數：**breast cancer −1、TNM stage I–II −1；女性、lung cancer、過去 VTE 各 +1**；**≤ 0 → 前 6 個月復發 ≤ 4.5%**，**≥ 1 → ≥ 19%**
- 3–6 個月後：繼續 LMWH 或換口服抗凝**個別決定**（抗癌治療成效、復發與出血風險、病人偏好），並定期再評估
- **Filter**：只在**無法抗凝**（活動性出血、出血風險過高）時；**不能延遲可以安全抗凝時的開始**；**不建議當抗凝的輔助**

### Occult cancer 篩檢

- 沒有危險因子的 PE，一部分在一年內發現癌症
- 兩個大型 RCT：**腹部 CT 或 FDG-PET 沒有比 limited screening 找到更多癌症**
- **==只需仔細病史、理學檢查、基本檢驗、CXR==**（若診斷時沒做 CTPA）

### Incidental PE

- 癌症病人偶然發現的 PE，若是 **segmental 或更近端**、**多處 subsegmental**、或**單一 subsegmental 合併 DVT** → **與有症狀的 PE 一樣處理**

## 建議：active cancer 的 PE 抗凝（Section 8.6）

| 建議 | 等級 |
| --- | --- |
| 前 6 個月應考慮**依體重皮下 LMWH**（優於 VKA） | **IIa-A** |
| **Edoxaban** 可替代 LMWH（**沒有 GI cancer**） | IIa-B |
| **Rivaroxaban** 可替代 LMWH（**沒有 GI cancer**） | IIa-C |
| 6 個月後應考慮**無限期或直到癌症治癒** | IIa-B |
| Incidental PE（segmental 以上、多處 subsegmental、或單一 subsegmental＋DVT）→ 與有症狀 PE 一樣處理 | IIa-B |
