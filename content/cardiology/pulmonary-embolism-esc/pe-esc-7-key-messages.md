## 2019 版的新觀念（相對 2014 版）

| 主題 | 新觀念 |
| --- | --- |
| **診斷** | D-dimer 可用 **age-adjusted** 或**依臨床機率調整**的 cut-off 取代固定值；更新 CTPA 與 lung scan 的輻射劑量（Table 6） |
| **風險評估** | 明確定義 **hemodynamic instability 與 high-risk PE**（Table 4）；除了共病與整體死亡風險，也要評估 **PE 嚴重度與 PE 相關早期風險**；提醒**臨床分數低風險的人仍可能有 RV dysfunction** |
| **急性期治療** | 全面改寫 high-risk 的**呼吸循環支持**；high-risk 專屬處置流程（Supplementary Figure 1）；**符合條件者 NOAC 為首選**、VKA 為替代；**Figure 6** 改為同時考慮臨床嚴重度、共病與 RV dysfunction |
| **3 個月後的長期治療** | 依復發風險分 **high／intermediate／low**（Table 11）；討論 minor transient、persistent、無危險因子者的延長抗凝；**==不再使用 provoked／unprovoked==**；同時呈現復發與出血分數；**6 個月後可減量 apixaban 或 rivaroxaban** |
| **癌症** | **Edoxaban 或 rivaroxaban** 可替代 LMWH，但 **GI cancer 要小心**（出血） |
| **懷孕** | 專屬診斷流程（Figure 7）；更新輻射吸收資料（Table 12） |
| **長期後遺症** | 整合式照護模式；建議擴及**所有 PE 後症狀與功能受限**（不只 CTEPH）；新的追蹤流程（Figure 8） |

## 等級有變的建議（2014 → 2019）

| 建議 | 2014 | 2019 |
| --- | --- | --- |
| 血行動力惡化 → **rescue thrombolysis** | IIa | **I** |
| 血行動力惡化 → **surgical embolectomy 或 catheter-directed treatment** 替代 rescue thrombolysis | IIb | **IIa** |
| 懷孕或產後用 **D-dimer 與 prediction rule** 排除 PE | IIb | **IIa** |
| **無症狀但 CTEPH 高風險**的 PE 存活者進一步評估 | III | **IIb** |

## 2019 版主要的新建議

| 主題 | 建議 | 等級 |
| --- | --- | --- |
| 診斷 | **Age-adjusted 或依臨床機率調整的 D-dimer** 替代固定 cut-off | IIa |
| 診斷 | 用 **proximal CUS 陽性**確診時，應做風險評估 | IIa |
| 診斷 | **V/Q SPECT** 可用於診斷 | IIb |
| 風險評估 | **即使 PESI 低或 sPESI 0，也要用影像或 biomarker 評估 RV** | IIa |
| 風險評估 | 結合臨床、影像、檢驗的驗證分數進一步分層 | IIb |
| 急性期 | 符合條件者 **NOAC 為首選** | **I** |
| 急性期 | 建立 high-risk 與部分 intermediate-risk 的**多專科團隊** | IIa |
| 急性期 | 難治性循環衰竭或 cardiac arrest：**ECMO**＋手術或導管治療 | IIb |
| 長期 | **APS → 無限期 VKA** | **I** |

## 10 個 Key messages（Section 12）

| # | 重點（自己的話） |
| --- | --- |
| 1 | **血行動力不穩 → 先做 bedside TTE**，快速區分 high-risk PE 與其他致命急症 |
| 2 | **一懷疑 PE 就開始抗凝**，不必等檢查結果（除非正在出血或有絕對禁忌） |
| 3 | 用**驗證過的診斷流程**（標準化臨床機率＋D-dimer），避免昂貴、有害、帶輻射的不必要影像 |
| 4 | **==CTPA 報告只有單一 subsegmental PE → 想到可能是偽陽性==**，和放射科再討論或尋求第二意見，避免不必要的抗凝 |
| 5 | 穩定的 PE 確診後**一定要再做風險評估**（臨床、RV 大小功能、biomarker），以決定要不要 reperfusion、監測，或可以門診治療 |
| 6 | **High-risk → 依病人狀況與醫院資源選最好的 reperfusion**（溶栓、手術、導管）；**intermediate-high 不以 reperfusion 為第一線**，但要和團隊**事先擬好惡化時的備案** |
| 7 | **==優先用 NOAC==**，除非有禁忌，才用傳統 LMWH→VKA |
| 8 | **除了 strong transient／reversible factor 造成的 PE，首次 PE 後終生都有復發風險** → 3–6 個月時重新評估、權衡延長與劑量、考慮病人意願，並建議**每年追蹤** |
| 9 | 孕婦疑似 PE → **CTPA 或 V/Q 都可安全使用**，依流程診斷 |
| 10 | PE 後**不要失聯**：除了復發、癌症、出血，也要問**有沒有持續或新的喘與功能受限**；有就逐步排除 CTEPH／CTED 並處理共病或 deconditioning；**無症狀者不常規追蹤影像**，有 CTEPH 危險因子才考慮 |

## 必做與不做（Section 14）

### 診斷

| 必做（I） | 不做（III） |
| --- | --- |
| 疑似 high-risk：**bedside echo 或緊急 CTPA** | **==High clinical probability 不驗 D-dimer==** |
| 疑似 high-risk：**立即 IV UFH（含 bolus）** | **不做 CT venography** 當 CTPA 的附加 |
| 穩定者用**驗證過的診斷標準** | **不用 MRA 排除 PE** |
| 穩定者 **high／intermediate 機率：診斷期間就抗凝** | |
| 診斷策略以 **clinical probability** 為基礎 | |
| 門診／急診 **low／intermediate（或 unlikely）驗 D-dimer** | |
| Low／intermediate 機率 **CTPA 正常 → 排除** | |
| **Perfusion scan 正常 → 排除** | |
| Intermediate／high 機率 **CTPA segmental 以上 → 確診** | |
| **CUS 有 proximal DVT → 確診 VTE** | |

### 風險評估

| 必做（I） |
| --- |
| 依 **hemodynamic instability** 分層，找出 high-risk |
| 穩定者進一步分成 **intermediate 與 low** |

### 急性期治療

| 必做（I） | 不做（III） |
| --- | --- |
| **High-risk → systemic thrombolysis** | **==NOAC 不用於嚴重腎功能不全或 APS==** |
| High-risk 溶栓禁忌或失敗 → **surgical pulmonary embolectomy** | **==Intermediate／low-risk 不常規 primary systemic thrombolysis==** |
| 穩定者注射抗凝 → **LMWH 或 fondaparinux 優於 UFH** | **不常規放 IVC filter** |
| 符合條件者 → **NOAC 優先** | |
| 用 VKA → 與注射抗凝重疊到 **INR 2.5（2.0–3.0）** | |
| 抗凝中惡化 → **rescue thrombolysis** | |

### 長期治療與預防復發

| 必做（I） |
| --- |
| **所有 PE 抗凝 ≥ 3 個月** |
| 首次 PE 由 **major transient／reversible factor** 造成 → **3 個月停** |
| **反覆 VTE**（非 major transient factor 造成）→ **無限期** |
| **APS → 無限期 VKA** |
| 延長抗凝者**定期評估**耐受性、順從度、肝腎功能、出血風險 |

### 懷孕

| 必做（I） | 不做（III） |
| --- | --- |
| 懷孕或產後疑似 PE → **驗證過的方法正式評估** | **最後一劑 LMWH 後 24 小時內不放 spinal／epidural needle** |
| 多數穩定孕婦 → **依早期懷孕體重的固定治療劑量 LMWH** | **拔 epidural catheter 後 4 小時內不給 LMWH** |
| | **懷孕與哺乳不用 NOAC** |

### PE 後照護

| 必做（I） |
| --- |
| PE 後 **3–6 個月常規再評估** |
| **整合式照護模式** |
| 有症狀＋3 個月後 V/Q **mismatch** → 轉 **PH／CTEPH 中心** |

## 證據缺口（Section 13，摘要）

- **診斷**：D-dimer 門檻怎麼調最好；**isolated subsegmental filling defect** 的意義；**incidental PE** 要不要治療；胸痛的 triple rule-out CT
- **風險分層**：哪些臨床與生化組合最能找出 intermediate-risk 中需要 reperfusion 的人；判斷 low vs intermediate 時是否一定要評估 RV
- **急性期**：intermediate-high 的**減量溶栓**與**導管治療**需要 RCT；ECMO 的角色；**CrCl < 30** 的最佳抗凝；早期出院的選擇標準
- **長期**：NOAC 時代的復發與出血分數；高復發風險者的減量延長；癌症病人 NOAC 證據、6 個月後的方案與停藥時機
- **懷孕**：現代低輻射影像流程的驗證；LMWH 最佳劑量；懷孕中誤用 NOAC 的結果登錄
- **後遺症**：持續症狀者的最佳追蹤策略；無症狀者哪些人值得篩檢 CTEPH
