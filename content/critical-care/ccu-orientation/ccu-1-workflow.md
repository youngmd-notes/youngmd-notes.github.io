> [!abstract] 一句話重點
> - **兩次床邊**：接班看一輪、交班前再看一輪；**夜班 ==05:30 看 data 並矯正電解質==**
> - 病歷：Admission note 一定寫 **occupation**、**impression 寫全名**、plan 寫滿四項（diagnostic、therapeutic、patient education、goal）
> - 交班單五件事：**PCI 術者**、**APACHE II**、**藥物增減**、**隔離與解隔條件**、**key data 邊抄邊矯正**
> - 血鉀：**==AMI 3.5–4.5==**（不必更高）；**HF 補到 ≥ 4.0**，不追到 5.0
> - 鎂：沒有試驗支持的目標，入院 Mg ≥ 2.4 死亡率反而較高 → **補到 2 左右就好、別追高**
> - **==高血鉀有 ECG 變化 → calcium gluconate 先上==**，再 insulin＋glucose；calcium resonium 不再常規用
> - 抗生素每天問兩句：**還需要嗎？能不能降階？**

## 白班與夜班的時間軸

> [!tip] 晨會 07:30 之前，抽血、I/O 與體重都要已經出來

| 白班（順序就是優先順序） | 夜班 |
| --- | --- |
| 1. 接班：看一輪病人、對一次交班單 | 1. 接班，看一輪病人 |
| 2. CCU 晨會（週一至四 07:30、週五 08:00；月底那週另有 case conference、journal meeting） | 2. 寫一篇病程記錄（夜班這篇寫**五大任務**） |
| 3. 開明天抽血單，處理晨會交辦事項 | 3. 補明天抽血單，處理問題 |
| 4. 看 CXR 並寫判讀；家屬病情解釋，有檢查先備同意書 | 4. 休息前改一輪交班單（AM 版） |
| 5. 寫一篇病程記錄 | 5. **==05:30 看 data、矯正電解質==** |
| 6. 更新交班單（PM 版） | 6. 做白班交班單：key 重要 data |
| 7. 交班前**再看一輪病人** | 7. 交班前看一輪病人 |

- **兩次床邊**（接班一次、交班前一次）能少掉一半的意外
- 05:30 的 data 沒人看，白班就會從錯的數字開始

## 病歷節奏：AN → PS → WS → TN

| 時機 | 哪一篇 | 重點 |
| --- | --- | --- |
| 入院第一篇 | **Admission note（AN）** | **Occupation 一定要寫**（職災、暴露史、回歸工作）；**Impression 寫全名**（病歷是法律文件，導管報告除外）；Plan 寫四項 |
| 每天 | **Progress note（PS）** | Plan 同樣四項；夜班那篇寫五大任務 |
| 每週 | **Weekly summary（WS）** | 一週的問題與方向 |
| 轉出 | **Transfer note（TN）** | 把 CCU 的事交代完，病房才接得住 |

- **Plan 四項**：Diagnostic、Therapeutic、Patient education、**Goal**（接手的人一眼看到目標）

## 交班單

| 重點 | 要寫什麼 | 常見漏洞 |
| --- | --- | --- |
| **做 PCI 的主治** | 確實寫術者姓名 | 半夜出事找不到人 |
| **嚴重度** | 要知道 APACHE II | 抄到錯日期的分數 |
| **藥物增減** | 有刪減一定改交班單 | 交班單上還有昨天停掉的藥 |
| **抗藥性菌** | 隔離狀態＋**解除隔離的條件**，主動想辦法解隔 | 沒人追，隔離到出院 |
| **Key data** | 抄 data 的同時開矯正醫囑 | 抄了 K 3.2 卻沒補 |

- 建議用 **I-PASS** 架構；最後一格是**接班的人自己複述一次**
- 寫完把自己當夜班讀一遍

## 電解質

### 血鉀目標

| 情境 | 建議區間 | 依據 |
| --- | --- | --- |
| **AMI** | **==3.5–4.5 mEq/L==** | Goyal 2012（38,689 位 AMI）：3.5 到 < 4.5 住院死亡率最低；4.5 到 < 5.0 死亡率 10.0%（vs 3.5 到 < 4.0 的 4.8%，校正 OR 1.99）；VF／arrest 只在 K < 3.0 與 ≥ 5.0 才明顯增加 |
| **Heart failure** | **補到 ≥ 4.0**，不追到 5.0 | Ferreira 2020：< 4.0 開始有風險、< 3.5 陡升；用 RAASi、MRA 的人 > 5.5 同樣有害（風險曲線，不是目標） |

### 鎂與磷

- **鎂**：沒有試驗支持的目標
  - CICU 8,498 人：入院血鎂與 QTc、猝死無關；**Mg ≥ 2.4 mg/dL 住院死亡率高於 2.0 到 < 2.2**（校正 OR 1.80，觀察性）
  - 疑似 AMI 常規 IV 補鎂：**ISIS-4（58,050 人）沒有益處**
  - 心臟手術後預防性補鎂可減少 SVT（RR 0.77）與 VA（RR 0.52），死亡率不變
  - **TdP 用 IV Mg 是標準處置**（見 [[critical-care/ccu-orientation/ccu-6-arrhythmia|⑥]]）
  - 「Mg 補到 2 以上」是專家意見 → ==別追高==
- **磷**：ICU hypophosphatemia 20–80%
  - 與 ICU、住院天數延長（各 +2.2 天）、**呼吸器天數較長**（7.4 vs 5.6 天）有關，與死亡率無關
  - 開始營養後磷掉越快，**拔管失敗越多**（每降 10%，OR 1.22；單中心）
  - 是嚴重度的標記，也和肌力、weaning 有關 → **先找原因**（refeeding、利尿、透析）**再補**；講義所述院內慣用 phosphate 口服液

### 補鉀怎麼開

| 途徑 | 怎麼開 | 上限（仿單） |
| --- | --- | --- |
| **口服** | 能吃就口服（例如 Radi-K 1# TID） | — |
| **周邊 IV** | KCl **稀釋後用 pump** | **==≤ 10 mEq/h、每天 ≤ 200 mEq==** |
| **中央 IV、緊急** | 最高濃度（400 mEq/L）只能走中央 | **最多 40 mEq/h**，要連續 ECG |

- ICU 研究：20 mEq KCl in 100 mL 每小時一袋，平均每袋升 0.25 mmol/L，495 次沒有致命心律不整
- 速度越快越要 ECG 監測與回抽；**依院內藥局的濃度與速率規定**

### 高血鉀緊急處置

| 步驟 | 做法 | 備註 |
| --- | --- | --- |
| **有 ECG 變化**（K 常 ≥ 6.5） | **==10% calcium gluconate 30 mL IV==** | 先穩定心肌；K ≥ 6.5 但沒 ECG 變化 → 12 導程、監測、先推鉀 |
| 推鉀進細胞 | **Insulin 10 U＋glucose 25 g** | 監測血糖 |
| 輔助 | Salbutamol 吸入 | 只當輔助，不單獨用 |
| 排鉀 | **SZC 或 patiromer**；**calcium resonium 不再常規用** | 腎功能差 → 透析 |

（依據：UK Kidney Association hyperkalaemia guideline 2023）

## 抗生素

- 講義所述院內規則：抗生素開立 **3 天自動審核**，限用一次
- **Surviving Sepsis 2021**：每天評估能否**降階**，不要固定天數不回頭看（弱建議）；procalcitonin＋臨床判斷可協助決定何時停藥（弱建議）
- 抗生素管理架構：IDSA／SHEA 2016

> [!tip] 模組 1 帶走
> - 接班看一輪、交班前再看一輪；05:30 的 data 一定有人看
> - 交班單五件事：術者、APACHE II、藥物增減、隔離解隔、key data 順便矯正
> - 血鉀 AMI 3.5–4.5、HF ≥ 4.0；鎂別追高；低磷先找原因
> - 高血鉀有 ECG 變化 → 鈣先上，再 insulin–glucose
> - 流程以院內 SOP 最新版為準

## 📝 講義小考

> [!question]- Q1：AMI 病人 K 4.6 mEq/L，要補嗎？
> (A) 補到 5.0，心肌梗塞要高一點
> (B) 不補，3.5–4.5 是死亡率最低的區間
> (C) 補到 4.0 就好
> (D) 看 Mg 再決定
>
> > [!success]- 答案與詳解
> > **(B)**。Goyal 2012：AMI 血鉀 3.5 到 < 4.5 住院死亡率最低，4.5 到 < 5.0 反而較高，不需要再往上補。

> [!question]- Q2：高血鉀 7.1 mmol/L 合併 QRS 變寬，第一個動作？
> (A) 口服 calcium resonium
> (B) 10% calcium gluconate 30 mL IV
> (C) Insulin 10 U＋glucose
> (D) 直接安排透析
>
> > [!success]- 答案與詳解
> > **(B)**。有 ECG 變化先用鈣穩定心肌，再用 insulin–glucose 把鉀推進細胞，最後才是排鉀（結合劑或透析）。
