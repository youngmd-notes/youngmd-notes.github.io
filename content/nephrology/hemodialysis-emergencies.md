> [!abstract] 一句話重點
> 透析中出事，先想「**管路裡的血要不要回輸**」：**==Dialyzer reaction（type A）、air embolism、hemolysis → 停機且不回血==**。另外三個高頻考點：**DDS 用低血流（約 200 mL/min、2 小時、BUN 降幅 ≤ 40%）預防**、**uremic pericarditis 透析時不用 heparin、有 tamponade 不能洗**、**HD 病人猝死最常在長週末後**。

## 總覽

| 急症 | 關鍵線索 | 立即處置 | 管路血回輸？ |
| --- | --- | --- | --- |
| **Dialyzer reaction type A** | 開始 **20–30 分鐘內**；搔癢、wheezing、低血壓 | 停機、epinephrine、輸液、類固醇、抗組織胺 | **==不回輸==** |
| Dialyzer reaction type B | 較晚、較輕；胸痛、背痛 | 輕微可繼續，考慮換 dialyzer | — |
| **DDS** | 首次透析、BUN 很高；頭痛 → seizure | 停機，支持治療；嚴重時降 ICP | — |
| **Uremic／dialysis-associated pericarditis** | 胸痛、friction rub；ECG 少見 diffuse ST elevation | 開始或加強透析、**不用 heparin**；tamponade → pericardiocentesis | — |
| **Air embolism** | 突然咳嗽、低血氧、低血壓、**持續性雜音** | 停機、**100% O₂**、擺位 | **==不回輸==** |
| Venous needle dislodgement | 警報可能**不會響** | 輸液、升壓劑、輸血 | — |
| Vascular access hemorrhage | 多發生在**家裡**；瘤體皮膚發亮變薄 | **直接持續壓迫**，不要用止血帶 | — |
| **Hemolysis** | 管路血**櫻桃紅**、血清粉紅、腹痛、高血壓、高血鉀 | 停機、輸血、必要時透析治高血鉀 | **==不回輸==** |
| 透析水污染 | 同一班多位病人同時發病 | 依污染物處理 | — |
| Arrhythmia／cardiac arrest | 長週末後（週一、週二） | CPR | — |

## Dialyzer reactions 與其他過敏反應

Dialyzer reaction 是對**透析膜本身**或**滅菌用的物質**過敏，現在因為生物相容膜普及、少用 ethylene oxide 滅菌，已經很少見。

| | Type A | Type B |
| --- | --- | --- |
| 時間 | **開始後 20–30 分鐘內**，多在第一次使用，但也可在多次後發生 | 較晚 |
| 嚴重度 | 可致命 | 較輕 |
| 表現 | 搔癢、urticaria、laryngeal edema、**bronchospasm**、dyspnea、胸痛、嘔吐、低血氧、**低血壓**、cardiac arrest | 胸痛、背痛、噁心嘔吐 |
| 機轉 | **IgE-mediated anaphylaxis**：**ethylene oxide（最多）**、formaldehyde（重複使用處理）；**ACEI＋AN69 膜** → bradykinin 大量累積；polysulfone 也有嚴重 IgE 反應的報告 | **Complement activation**：cuprophane、polysulfone／polyethersulfone |
| 處置 | **==停機，管路血不回輸==**；依需要給輸液、**epinephrine**、類固醇、抗組織胺 | 症狀輕可繼續透析，考慮換 dialyzer |
| 預防 | 換**不同滅菌方式**的 dialyzer（例如改 gamma ray 滅菌）；==使用 AN69 膜時避免 ACEI== | 換 dialyzer |

- 區分是不是 anaphylaxis：可測 **total IgE 與 tryptase**
- AN69 膜用 polyethyleneimine 預處理（中和膜的負電）可預防 bradykinin 反應

**透析中給的藥也會過敏**

- **Heparin**：部分 **HIT** 病人再次接觸 heparin 後立刻出現 IgG 媒介的 anaphylactoid reaction；2007–2008 年曾因 heparin 被 oversulfated chondroitin sulfate 污染，產生 C3a、C5a，引起群聚嚴重反應
- **IV iron**：致命反應以 **high-molecular-weight dextran 最高**，**iron sucrose 最低**（目前最常用）
- **ESA** 與其添加物
- 處置：避開致敏藥物、改用替代品

## Dialysis disequilibrium syndrome（DDS）

### 表現與危險因子

- 透析中或剛結束時出現**神經症狀**：頭痛、噁心嘔吐、confusion、agitation、**seizure**、coma，甚至死亡；CT／MRI 可見 **cerebral edema**
- 危險因子：**==BUN 很高的第一次透析==**、**BUN 下降太快**、年紀很大或很小、**metabolic acidosis**、低／高血鈉、肝病、**原本就有神經疾病**（例如 stroke）
- 現在很少見（較低血流、較早開始透析），但輕微症狀可能被低估

### 機轉：水跑進腦細胞

| 理論 | 說明 |
| --- | --- |
| **Reverse urea effect**（最主流） | 透析快速清掉血中 urea，但腦內 urea 降得慢 → **血漿滲透壓相對比腦低** → 水往腦細胞移動；當年量到透析後 **CSF urea 明顯高於血中**。尿毒動物腦部 aquaporin（AQP4、AQP9）增加、urea transporter UT-B1 減少，讓水更容易移動 |
| Idiogenic osmoles | 腦在高滲透狀態下生成的未知溶質；後續研究未再證實 |
| Intracerebral acidosis | 快速矯正酸中毒 → CSF pH 下降，H⁺ 取代結合的 Na⁺、K⁺ → 腦內滲透壓上升；也可能增加 opioid 進入 CNS，造成類似 DDS 的意識變化 |

### 處置

- 透析中出現疑似症狀 → **停機**
- 輕微：支持治療
- 嚴重：降 ICP（hypertonic saline、mannitol、過度換氣），但報告的預後差

### 預防（最重要）

- **==短時間內 BUN 降幅不超過 40%==**
- **==第一次透析用低血流：約 200 mL/min、2 小時==**（體型小的人更低）
- 長期透析病人 BUN 很高時，也用較低血流
- BUN 非常高：考慮用 **CKRT** 緩慢降低（但 CKRT 也有 DDS 案例）
- 減少滲透壓變化：**提高透析液 Na**；也有人用 mannitol、glucose、glycerol、urea

> [!example] 個案
> 75 歲、有 stroke 病史，BUN 170、Na 128、HCO₃⁻ 12，第一次透析：2 小時、**血流 400 mL/min**、透析液流速 800、脫水 2 L。結束前頭痛、接著 seizure。
> 要降低 DDS 風險，處方應該改的是 **==降低血流==**（不是延長時間、不是減少脫水、不是降低透析液 Na）。

## Uremic pericarditis 與 dialysis-associated pericarditis

### 定義

| | Uremic pericarditis | Dialysis-associated pericarditis |
| --- | --- | --- |
| 時間 | **透析前，或開始透析 8 週內** | **透析超過 8 週後** |
| 原因 | 尿毒素累積 | 常見於**透析不足** |
| 對透析的反應 | **好**：開始 HD 後約 87% 改善 | 較差：加強透析後約 53% 改善 |

- 仍是腎衰竭病人心包疾病最常見的原因；其他原因：感染、自體免疫、惡性腫瘤、外傷、MI
- 慢性發炎可演變為 **constrictive pericarditis**（少見）

### 臨床表現：和一般 pericarditis 不太一樣

- **Pleuritic chest pain** 常見，但「**前傾改善**」**不常見**
- 可有發燒、畏寒、喘、咳嗽、倦怠
- **大多數聽得到 pericardial friction rub**（典型三相：心房收縮、心室收縮、舒張早期快速充填）
- **==Diffuse ST elevation 在透析病人 < 10%==**（可能因 LVH，或心外膜沒有受侵犯）
- ESR、CRP 上升；約一半有白血球增加；心包液為 **exudate**、以單核球為主
- 心臟超音波看 effusion 與 tamponade

### Cardiac tamponade（約 10–20%）

- 低血壓、心搏過速、心音模糊、JVP 上升
- **Pulsus paradoxus**（吸氣時收縮壓下降 > 10 mmHg）→ 需緊急評估
- 超音波：**右心房、右心室舒張早期塌陷**；三尖瓣與二尖瓣血流速度隨呼吸變化加大（ventricular interdependence）
- **==有 tamponade → 緊急 pericardiocentesis（通常放引流管）或 pericardial window，不要先透析==**

### 治療

| | 處置 |
| --- | --- |
| Uremic pericarditis（還沒透析） | **開始 HD**，很少需要其他介入 |
| Dialysis-associated | **加強透析：每天 HD，持續 10–14 天** |
| 共同原則 | **==透析時避免 heparin==**（怕 hemorrhagic pericarditis）；**脫水要非常小心**（可能誘發 tamponade） |
| 藥物 | Indomethacin、colchicine、口服或心包內類固醇：小型研究**沒有證實有效** |
| 加強透析仍不改善的大量積液 | Pericardiocentesis（±引流管，未放管要追蹤再積液）、pericardial window |
| Constrictive pericarditis | Complete pericardiectomy |

## Air embolism

### 空氣怎麼進去

- 動脈端（病人 → 血液幫浦）是**負壓**：動脈針與管路接觸不良、管路破損 → 吸入空氣
- 不當給 saline 或藥物、dialyzer 沒有排好氣
- **Catheter 沒有夾住或沒蓋、置放或拔除 catheter 時**
- 大量空氣會被 **air-foam detector** 偵測並停幫浦，所以致命的 air embolism 很少見，近年案例多是**人為疏失**
- 微小氣泡不會觸發警報，可能和透析病人的慢性肺、腦損傷有關

### 表現

- 進入右心與肺動脈：肺動脈壓上升、pulmonary edema、**低血氧、低血壓**、cardiac arrest
- 經 **PFO** 或大量空氣穿過肺微血管 → 進入體循環 → **cerebral air embolism**（意識改變、神經學缺損、seizure、stroke）；坐姿時空氣也可沿 internal jugular vein 逆流到顱內
- 成人約 **100–300 mL** 空氣可致命

### 處置

1. **停機，管路血不回輸**
2. **==給 100% O₂==**：矯正低血氧，並加速氮氣移除、縮小氣泡
3. 依需要輸液、升壓劑
4. 擺位：

| 情況 | 姿勢 | 原因 |
| --- | --- | --- |
| 疑似**靜脈** air embolism | **Left lateral decubitus** | 讓空氣留在右心室，不進入肺循環 |
| **動脈** air embolism | **Supine** | 左側臥不足以阻止進入體循環；**頭低腳高可能加重腦水腫** |

5. 其他：有 catheter 時嘗試抽出空氣、hyperbaric oxygen

> [!warning] Pitfall
> 原文個案（CABG 後 AKI、用 non-tunneled catheter 透析，突然咳嗽、低血氧、低血壓、持續性雜音）的正解是 **100% O₂**；thrombolytic、類固醇＋抗組織胺、reverse Trendelenburg、先做心臟超音波都不是第一步。治療選項有限、預後差，所以重點在**預防**。

### 預防

- 避免過高血流、維持 air trap 內高液面、訓練人員（含居家透析的病人與照顧者）
- **放 catheter 時**：矯正低血容、**Trendelenburg**、先 prime catheter、**吐氣時**進針、針座與管腔保持封閉
- **拔 catheter 時**：Trendelenburg、在 **Valsalva** 或吸飽氣閉氣時拔除、**occlusive dressing 貼 24 小時**

## Venous needle dislodgement

- AVF／AVG 的**靜脈針**完全脫落 → 以血流速度（**300–450 mL/min**）持續失血，**幾分鐘內就可能致命**
- **為什麼警報可能不響**：
  - 靜脈壓警報上下限通常設在實際值 ±50 mmHg（設太緊會一直誤報）
  - 針脫落時，靜脈壓只會下降**相當於 access 內壓力**的量；**AVF 內壓常常很低**（例如 20 mmHg）→ 下降 20 mmHg 不足以觸發警報
  - 被子蓋住針與管路、警報下限設太低 → 更難發現
- 處置：輸液、升壓劑、輸血
- 預防：固定的貼針方式、**針與管路接頭隨時可見**、規律巡視、**禁止人員擅自調整警報範圍**；高風險病人（躁動、失智、意識改變、困難 access、膠帶過敏、居家單獨或夜間透析）放在護理站附近
- 可加用失血偵測裝置（例如貼在針上的光學感測貼片），但不能取代預防措施

## Vascular access hemorrhage

- 約佔 HD 病人死亡的 0.4%；**==約 80% 發生在透析室外，最常在家裡==**
- 多數是 **AVF／AVG 破裂**；少數是 CVC 相關（穿孔、沒蓋、脫接、意外拔除）
- 破裂多在管壁變弱處：

| | Aneurysm | Pseudoaneurysm |
| --- | --- | --- |
| 定義 | 血管壁局部擴張 | 經管壁缺損與 access 相通的血腫 |
| AVF | 可以 | 可以 |
| AVG | **不會** | **較常見**（內壓高、缺損修復能力差）→ AVG 出血風險較高 |

- 促進形成：同一位置反覆穿刺、高血流、反覆擴張狹窄、感染、**venous outflow stenosis**；致命出血的病人超過一半在前幾週到幾個月有 access 相關問題（感染、阻塞、出血）

### 處置

- **==直接持續壓迫出血點，直到急救人員到達==**；**不要**用止血帶、血壓計袖帶或在該肢體纏繃帶
- 破裂的 AVF／AVG 需要**結紮**（會失去 access）

### 預防

- 穿刺用 **rope ladder technique**（沿 access 輪流換位置），避開瘤狀擴張處
- 規律檢查 access；**快速變大、皮膚發亮變薄、皮膚壞死、疼痛、感染** → 盡快轉介血管外科；有即將破裂或感染徵象可能需要結紮
- 小而穩定的瘤體 → 評估 **outflow stenosis**：**舉手時引流靜脈不會塌**、**高頻 bruit** → 轉血管外科處理狹窄，降低 access 內壓

## Hemolysis

### 原因

| 類別 | 例子 |
| --- | --- |
| **機械性** | 小號針配高血流、**動脈端負壓過大**、針位置不正、**管路扭折或阻塞**（1998 年多州群聚：一批管路有狹窄處） |
| **透析液／水** | **Chloramine**、copper、nitrate（氧化劑）；formaldehyde；**透析液溫度過高**；**==低張透析液==**（致命） |
| 病人因素 | Sickle cell anemia、hypophosphatemia、部分藥物 |

- 輕度溶血可能只表現為 **ESA 阻抗**（曾有 chloramine 案例）

### 表現與處置

- 症狀：噁心、嘔吐、腹瀉、**腹痛／背痛／胸痛**、喘、畏寒、**高血壓**
- 線索：**==管路內血液呈櫻桃紅、較透亮==**；**血清呈粉紅色**（游離血紅素）
- 檢驗：Hb、haptoglobin 下降；LDH、bilirubin、**K⁺** 上升
- 處置：**立即停機**，**==管路血不回輸（會造成嚴重高血鉀）==**；送急診、追蹤 Hb 與 K⁺，必要時輸血、**透析治療高血鉀**
- 大量溶血的併發症：心律不整、ACS、呼吸窘迫、**嚴重壞死性胰臟炎**、死亡
- 事後調查：測透析液**溫度與滲透壓**、驗污染物；檢查並**保留管路**送驗

> [!example] 個案
> 同一班多位病人透析中出現腹痛、嘔吐、高血壓，管路血呈櫻桃紅，Hb 掉到 5–8、輕中度高血鉀。可能原因：**低張透析液、管路扭折、chloramine 都可能**。

## 透析水污染

每位 HD 病人**每週接觸超過 400 L 透析液**，透析膜可讓許多毒物通過，所以水處理非常重要。

### 水處理系統（依原文 Table 1 重新整理）

| 階段 | 元件 | 功能 |
| --- | --- | --- |
| 前處理 | 溫度混合閥 | 調整水溫，讓 RO 正常運作 |
| | 多層介質過濾 | 濾除固體 |
| | **Activated carbon** | **吸附有機物與 chlorine／chloramine** |
| | Softener | 樹脂交換去除 Ca²⁺、Mg²⁺ |
| 水處理 | **Reverse osmosis（RO）** | 去除有機與無機溶質（含 fluoride、endotoxin） |
| | Deionization | 離子交換去除無機離子 |
| | UV | 殺菌 |
| | Endotoxin-retentive filter | 去除細菌與 endotoxin |

### 污染物

| 污染物 | 原因 | 表現 | 處置 |
| --- | --- | --- | --- |
| **Chloramine**（自來水消毒用） | **Carbon tank 耗盡**、水源濃度太高 | **Hemolysis**、**methemoglobinemia**（喘、cyanosis、**巧克力色靜脈血**） | 嚴重 methemoglobinemia：**methylene blue**（**G6PD deficiency 除外**）；每天多次測 total chlorine 監測 |
| Hydrogen peroxide | 醫院儲水槽消毒，量超過 carbon tank 負荷 | Hemolysis、methemoglobinemia | 同上 |
| **Fluoride** | Deionization 樹脂耗盡、水廠意外加過量 | 搔癢、胸痛、嘔吐、腹瀉、昏厥、**tetany**、**VF**、cardiac arrest；**低血鈣、低血鎂、高血鉀** | HD 移除 fluoride、治療高血鉀；補鈣、鎂 |
| **Aluminum** | Deionization 耗盡、鋁製幫浦外殼、水泥內襯水管 | **神經毒性**：seizure、myoclonus、encephalopathy | HD＋**deferoxamine** 螯合 |
| Copper | Deionization 部分耗盡（銅管） | 肌痛、腹痛、腹瀉、酸中毒、胰臟炎、hemolysis、methemoglobinemia | 支持治療，可能螯合 |
| **細菌／endotoxin**（gram-negative、NTM） | 水處理與機器消毒不當、dialyzer 重複使用、catheter | **Pyrogenic reaction**：透析中或結束數小時內發燒、畏寒、低血壓、頭痛、肌痛；bacteremia 可致死 | 抗生素、支持治療；規律做水培養與 endotoxin 檢測 |

> [!tip] Pearl
> 透析中出現**巧克力色靜脈血＋cyanosis** → chloramine（或 hydrogen peroxide）造成的 methemoglobinemia；**櫻桃紅管路血＋粉紅血清** → hemolysis。

## Arrhythmia 與 sudden cardiac death

- Cardiac arrest 與 arrhythmia 是腎衰竭**最常見的死因**（2015 年佔透析病人死亡 29%）
- 和一般族群不同：
  - 透析病人猝死者 **LVEF 降低較少見**，反而 **LVH 很常見**（部分系列 > 70%）
  - 植入式心律記錄器研究（Monitoring in Dialysis Study）：**==bradyarrhythmia 比 ventricular arrhythmia 更常見==**
- **時間點**：**==長週末後風險最高（週一、週二）==**；有意義的心律不整最常發生在**一週第一次透析**中，以及**長間隔的最後 12 小時**
- 誘發因子：**高血鉀**、透析中電解質與體液快速變化、**低鉀透析液（< 2 mEq/L）**、**低鈣透析液（< 2.5 mEq/L）**與較大的血清－透析液鈣濃度差、**metabolic alkalosis**（QT 延長）

### 預防策略（依原文 Table 2 重新整理）

| 方向 | 做法 |
| --- | --- |
| 心肌病變 | Dilated cardiomyopathy 用 **carvedilol**；LVH／舒張功能異常：考慮更頻繁透析、spironolactone、ACEI、ARB |
| **鉀** | 常測透析前 K⁺、調整透析液；**避免 < 2 mEq/L 的鉀浴** |
| **鈣** | **避免 < 2.5 mEq/L 的鈣浴**，尤其合併 QT 延長藥物 |
| 鹼中毒 | 鹼中毒病人避免高 HCO₃⁻ 透析液；把 acetate 等所有鹼來源算進去 |
| 快速脫水 | 限鹽限水；延長透析時間，讓 **UFR ≤ 10 mL/kg/h** |
| 透析引起的心肌缺血 | 透析液溫度調低到**比體溫低 0.5–2 °C**，減少透析中低血壓 |
| 藥物 | 避免 QT 延長藥物，定期核對 |
| 裝置 | 有 bradycardia 考慮 permanent pacemaker；ICD 用於 secondary prevention（但透析病人植入併發症較多，效益不確定）；可考慮 leadless 裝置 |
| 急救 | 透析室人員熟悉 BLS，鼓勵病人與家屬學 CPR |

處置：發生 cardiac arrest → **CPR**。目前**沒有**證實能預防透析病人猝死的介入。

## 事後：Root cause analysis

任何透析併發症發生後，都要用 **root cause analysis** 找出根本原因、改善流程，避免再發生。
