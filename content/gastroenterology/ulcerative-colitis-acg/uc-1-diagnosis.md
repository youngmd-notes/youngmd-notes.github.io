> [!abstract] 一句話重點
> - **懷疑 UC**：hematochezia、排便次數增加、bowel urgency → 先**排除感染**，一定要驗 ==C. difficile==（Statement 1）
> - **確診**：==大腸鏡進到 terminal ileum，病灶與看似正常處都要切片==；嚴重發炎只做 flexible sigmoidoscopy（避免穿孔）
> - **不要用 serology**（pANCA、ASCA）診斷或判斷預後（Statement 2–3）
> - **嚴重度**看四件事：症狀（出血、排便、urgency）、發炎負擔（內視鏡、FC、CRP、albumin）、病程（住院、類固醇、治療失敗）、對生活的影響
> - **預後不好的因子**：年輕、extensive colitis、MES 3／UCEIS ≥ 7、曾住院、CRP 高、albumin 低 → ==即使症狀輕，也要用中重度的治療==
> - **治療目標**：==內視鏡改善（Mayo endoscopic score 0–1）==（Statement 4）；用 ==fecal calprotectin== 追蹤反應、懷疑復發與維持期（Statement 5）

## 診斷

### 什麼時候懷疑？

- **主要症狀**：bloody diarrhea、黏液便、**bowel urgency**、tenesmus、腹部絞痛
- **要問的**：每天幾次（含**夜間排便**）、幾成的排便帶血、urgency、腹痛、體重減輕
- **腸道外表現**：關節腫痛、皮膚病灶、眼睛發炎、口腔潰瘍、angular cheilitis、黃疸或搔癢（肝膽）
- **誘發因子**：==最近戒菸==、**NSAID**、腸道感染

### 一定要排除感染

> [!tip] Statement 1（strong）
> 懷疑 UC 時，==驗糞便排除 C. difficile==。

- IBD 新診斷或復發時，CDI 盛行率 5–47%；合併 CDI **死亡率較高**、住院和切除大腸較多
- 其他會像 UC 的感染：**E. coli O157:H7、Salmonella、Shigella、Yersinia、Campylobacter**、**amebiasis**
- 很多醫院用 multiplex PCR 一次驗多種病原

### 內視鏡與切片

| 重點 | 內容 |
| --- | --- |
| **大腸鏡** | ==要進到 terminal ileum==（排除 Crohn's disease）；看 ileocecal valve：**UC 不會造成潰瘍或狹窄的 ileocecal valve** |
| **嚴重發炎時** | 全大腸鏡穿孔風險較高 → **flexible sigmoidoscopy＋切片**就夠 |
| **典型外觀** | 從**直腸開始、往近端連續**發炎：血管紋路消失、顆粒狀、易出血（friability）、糜爛；嚴重時深潰瘍、自發出血 |
| **切片位置** | **病灶處**，也要切**看起來正常的近端大腸**（組織學範圍可能更廣）；直腸看起來正常也要另外切 |
| **上消化道內視鏡** | 成人**不常規做**，有上消化道症狀才做（兒童會常規做） |
| **小腸影像** | Terminal ileum 正常就不需要；懷疑 Crohn's（水瀉、體重減輕、腹痛為主）、內視鏡解釋不了的症狀、準備開刀時才做 |

> [!warning] Statement 2–3（strong）
> ==不要用 serology 抗體（pANCA、ASCA）來診斷、排除 UC 或判斷預後==：pANCA 在 UC 可高達 70% 陽性，但整體 sensitivity 低。

<div class="orig-fig" data-src="腸胃肝膽科/uc-acg-2025-originals/figure-01.png" data-label="Figure 1"></div>

| Montreal 分型 | 範圍 |
| --- | --- |
| **E1 Proctitis** | 只有直腸（內文：通常 ≤ 15 cm；Key concept 4：距肛門 18 cm 內、在 rectosigmoid junction 以下） |
| **E2 Left-sided colitis** | 超過直腸，但停在 **splenic flexure** 或以下 |
| **E3 Extensive colitis** | 超過 splenic flexure；**pancolitis** 是整個大直腸到 cecum |

> [!note] 看圖重點
> - **a–e**：傳統依範圍分的型：isolated proctitis、proctosigmoiditis、left-sided、extensive、pancolitis
> - **f：PSC 型**：直腸相對或完全不受影響、近端大腸發炎較重（可能和膽酸有關，近端也較容易長腫瘤）；治療方式相同
> - **g：Cecal（periappendiceal）patch**：遠端 UC 的人在盲腸闌尾開口周圍也發炎；意義不明，治療相同
> - 範圍會變：==proctitis 最多 46%、left-sided 最多 70% 之後變成 extensive colitis==

> [!warning] Pitfall
> 範圍影響預後，但 ==不應該限制治療選擇==：中重度的 proctitis 一樣要用對中重度有效的藥（Key concept 26、39）。

## 嚴重度

### Table 4：ACG UC 活動度指標

<div class="orig-fig" data-src="腸胃肝膽科/uc-acg-2025-originals/table-04.png" data-label="Table 4"></div>

| | **Remission** | **Mild** | **Moderate–severe** | **Fulminant** |
| --- | --- | --- | --- | --- |
| 每天排便次數 | 成形 | < 4 | **> 6** | **> 10** |
| 便血 | 無 | 間歇 | 頻繁 | 持續 |
| Urgency | 無 | 輕微、偶爾 | 常常 | 持續 |
| Hb | 正常 | 正常 | **< 正常值 75%** | **需要輸血** |
| ESR | < 30 | < 30 | > 30 | > 30 |
| CRP（mg/L） | 正常 | 升高 | 升高 | 升高 |
| **Fecal calprotectin**（μg/g） | **< 150–200** | > 150–200 | > 150–200 | > 150–200 |
| 內視鏡 **MES** | **0–1** | 1 | 2–3 | 3 |
| 內視鏡 **UCEIS** | 0–1 | 2–4 | 5–8 | 7–8 |
| 腸道超音波（IUS） | 結腸壁 ≤ 3 mm、直腸壁 ≤ 4 mm、mLimberg 0 | 結腸壁 > 3 mm、直腸壁 > 4 mm、mLimberg > 0（後三欄相同） | | |

> [!note] 看表重點
> - 這是**大致的參考**：除了 remission 要全部符合，其他類別**不需要每一項都符合**
> - 新版把 **urgency、FC、UCEIS、腸道超音波**加進來
> - mLimberg：黏膜下血流增加的程度（0 沒有，1 小點，2 長段在腸壁內，3 長段延伸到腸繫膜）
> - ==只要不是輕度，就照中重度治療==（新版定義把病程一起考慮）

> [!tip] Pearl：Truelove and Witts（1955）
> - **Mild**：排便 < 4 次／天，體溫、心跳、Hb（> 11 g/dL）、ESR（< 20 mm/h）都正常
> - **Severe**：排便 > 6 次／天，加上發燒、心跳快、貧血或 ESR 升高
> - 簡單、適合判斷要不要住院，但不能量化、沒有 urgency、夜間症狀、腸道外表現和內視鏡

### Table 5：Mayo score

<div class="orig-fig" data-src="腸胃肝膽科/uc-acg-2025-originals/table-05.png" data-label="Table 5"></div>

| 項目（各 0–3 分） | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| 排便次數 | 正常 | 比平常多 1–2 次 | 多 3–4 次 | 多 ≥ 5 次 |
| 直腸出血 | 沒有 | 不到一半的排便有血絲 | 大部分排便有明顯血 | 只排血沒有糞便 |
| **內視鏡（MES）** | 正常或不活動 | **輕度**：紅斑、血管紋路減少、輕度 friability | **中度**：明顯紅斑、血管紋路消失、friability、糜爛 | **重度**：==自發出血、潰瘍== |
| 醫師整體評估 | 正常 | 輕 | 中 | 重 |

- **Modified Mayo score**：拿掉主觀的醫師評估，現在是臨床試驗的標準終點
- 試驗中 clinical remission 的定義：**MES 0–1、排便次數分數 ≤ 1、沒有直腸出血**

| --- | --- | --- | --- | --- |

> [!note] 看圖重點

## 預後

### Table 8：預後不好的因子

<div class="orig-fig" data-src="腸胃肝膽科/uc-acg-2025-originals/table-08.png" data-label="Table 8"></div>

| 預後不好的因子 |
| --- |
| 診斷時 **< 40 歲** |
| **Extensive colitis** |
| **內視鏡嚴重**（MES 3、UCEIS ≥ 7） |
| **曾因大腸炎住院** |
| **CRP 升高** |
| **Albumin 低** |

- ==因子越多，切除大腸的機會越高==
- 內文另外提到：深潰瘍、需要全身性類固醇、**< 30 歲**診斷、CRP 或 ESR 升高都和切除大腸較多有關（Table 8 寫 < 40 歲）
- 基因、serology 預測力很差，不建議用

> [!tip] Key concept 18：輕到中度但預後差
> 輕到中度 UC，若有幾個會增加住院或開刀風險的因子 → ==用中重度的治療==。各因子份量不同：**單純年輕**比**內視鏡嚴重**弱，但**年輕＋另一個因子**就可能足夠。要和病人共同決策。

## 抽血與糞便指標

| 指標 | 重點 |
| --- | --- |
| **CRP、ESR** | 常和內視鏡嚴重度相關、可預測切除大腸與治療反應；但 ==約 1/4 內視鏡活動的人 CRP 正常== → 診斷時先建立基準值 |
| **Hb、albumin** | 診斷時量；**albumin 低**＝住院、開刀較多、治療反應較差 |
| **Fecal calprotectin（FC）** | 嗜中性球的蛋白，**發炎性**腹瀉（感染、IBD）會升高，IBS 不會；診斷 UC 的 sensitivity 0.88、specificity 0.79、**LR− 0.15** |

### Fecal calprotectin 怎麼用（Statement 5）

> [!tip] Statement 5（strong）
> 用 FC ==評估治療反應、懷疑復發、維持期追蹤==。

- FC 和內視鏡、組織學發炎程度相關，比血液指標更敏感、更特異，已可**取代**部分 sigmoidoscopy／colonoscopy 追蹤
- **數值和範圍不一定相關**：FC 反映發炎嚴重度，不代表範圍多廣
- 參考切點（研究間差異大，沒有前瞻性驗證）：

| FC（μg/g） | 意義 |
| --- | --- |
| **< 60** | 預測 deep remission |
| **< 187** | 預測 mucosal healing |
| **> 321**（臨床緩解時） | 6、12 個月內復發風險高 |
| **50** | Meta-analysis：sensitivity 最好（90%） |
| **> 100** | Meta-analysis：specificity 最好（約 78%） |

- **會讓 FC 升高的其他原因**：感染、**NSAID**；輕度升高：**PPI**、肥胖
- 最好看**同一個病人的連續變化**

### 腸道超音波（IUS，新版加入）

- 經腹部高頻探頭量**腸壁厚度**、彩色都卜勒（充血）；直腸要用經會陰
- 對照內視鏡：pooled **sensitivity 85%、specificity 92%**
- 輕度 UC 敏感度低；中重度會看到腸壁增厚（> 3 mm）、黏膜下水腫、血流增加
- ==治療後最快 2 週就能看到反應==

## 治療目標（Statement 4、Key concept 9–17）

> [!tip] Statement 4（strong）
> 治療要達到 ==內視鏡改善：Mayo endoscopic score 0 或 1==，才能提高無類固醇緩解、減少住院與開刀。

| 名詞 | 定義 |
| --- | --- |
| **Symptomatic remission** | 沒有直腸出血、排便正常、**沒有 urgency** |
| **Endoscopic healing** | 黏膜完整、沒有 friability；**MES 0–1** 和 MES 0 的結果相近 |
| **Deep remission** | 症狀緩解＋內視鏡癒合，**最理想的目標** |
| **Steroid-free remission** | 沒有用類固醇、維持一段時間（通常 **> 12 週**） |
| **Histologic remission** | 有預後價值（嗜中性球浸潤＝較易復發），但 ==還不是必須達到的目標== |

- **STRIDE II** 的 UC 目標：直腸出血消失、排便正常、**MES 0–1**；活動期**至少每 3 個月**評估一次；FC、CRP 可以當替代指標
- **症狀緩解比黏膜癒合慢**；也有人黏膜發炎但沒症狀 → 要靠客觀指標確認
- **每種治療在固定時間點評估**：一般 **6–12 週**；輕到中度在 **8 週內**評估誘導是否有效
- 控制黏膜發炎**可能降低 dysplasia 風險**
- **定期回診**：監測復發、藥物併發症、預防保健（疫苗、癌症篩檢等另有 ACG 指引）
- ==篩檢焦慮與憂鬱==，有的話提供資源

> [!note] 復發時要評估
> 症狀嚴重度＋誘發因子：**腸道感染（尤其 C. difficile）、NSAID、最近戒菸、沒按時吃藥**（社區中不順從約 40%）；再用 FC、CRP、內視鏡或 IUS 客觀確認。局部治療後可能看到「直腸相對正常」的假象。
