> [!abstract] 一句話重點
> - **Strong「不要做」**：
>   - 用 serology 診斷或判斷預後
>   - thiopurine、methotrexate **單用誘導**
>   - 任何類固醇**維持**
>   - ASUC **常規抗生素**
> - **Conditional「不要做」**：
>   - 5-ASA 失敗**換另一種 5-ASA**
>   - advanced therapy **加 5-ASA**
>   - methotrexate 維持
>   - ASUC 用 **TPN 讓腸道休息**
> - **重點的 strong「要做」**：
>   - 驗 **C. difficile**
>   - 目標 **MES 0–1**、用 **FC** 追蹤
>   - **infliximab 合併 thiopurine**；**vedolizumab 優於 adalimumab**
>   - ASUC：**LMWH 預防**、**methylprednisolone 60 mg**、**Day 3 沒反應用 infliximab 或 cyclosporine**

## Table 1：建議強度與證據等級

<div class="orig-fig" data-src="腸胃肝膽科/uc-acg-2025-originals/table-01.png" data-label="Table 1"></div>

| | 意思 | 對病人與醫師 |
| --- | --- | --- |
| **Strong**（we recommend） | 好處明顯大於壞處 | 大多數病人都會選；大多數病人應該接受 |
| **Conditional**（we suggest） | 證據品質低，或好壞相近 | 病人選擇會不同 → **共同決策** |
| 證據 **High／Moderate／Low／Very low** | 對效果估計的信心由高到很低 | — |

- **Key concept**：不適合用 GRADE 評估（題目結構或證據不足），根據外推或專家意見
- 本指引**以直接證據為主**，不只靠 network meta-analysis 來排序藥物

## Table 2：GRADE 建議（54 條）

<div class="orig-fig" data-src="腸胃肝膽科/uc-acg-2025-originals/table-02-1.png,腸胃肝膽科/uc-acg-2025-originals/table-02-2.png,腸胃肝膽科/uc-acg-2025-originals/table-02-3.png" data-label="Table 2"></div>

「S」＝strong、「C」＝conditional；證據 H／M／L／VL＝high／moderate／low／very low。

### 診斷、評估與目標

| # | 建議 | 強度 |
| --- | --- | --- |
| 1 | 懷疑 UC → 驗糞便排除 **C. difficile** | S／VL |
| 2 | ==不要用 serology 抗體診斷或排除 UC== | S（against）／VL |
| 3 | 不要用 serology 抗體判斷預後 | S（against）／VL |
| 4 | 治療目標：==內視鏡改善（MES 0–1）==，以維持無類固醇緩解、減少住院與手術 | S／M |
| 5 | 用 **fecal calprotectin** 評估治療反應、懷疑復發、維持期追蹤 | S／M |

### 輕到中度：誘導與維持

| # | 建議 | 強度 |
| --- | --- | --- |
| 6 | Proctitis：**rectal 5-ASA 1 g／天**誘導 | S／M |
| 7 | Proctitis 對局部 5-ASA 沒反應：**tacrolimus 或 beclomethasone 栓劑** | C／L |
| 8 | Proctitis 或 left-sided：**局部類固醇**（栓劑、泡沫、灌腸） | C／VL |
| 9 | Proctitis 或 left-sided：==rectal 5-ASA ≥ 1 g 優於 rectal 類固醇== | S／M |
| 10 | Left-sided：**rectal 5-ASA ≥ 1 g＋口服 5-ASA ≥ 2 g**，優於單用口服 | C／L |
| 11 | Left-sided，對口服＋rectal 5-ASA 不耐受或沒反應：**budesonide MMX 9 mg** | S／M |
| 12 | Extensive：**口服 5-ASA ≥ 2 g** | S／M |
| 13 | 任何範圍，5-ASA 沒反應：**口服全身性類固醇** | S／L |
| 14 | 5-ASA 劑量足夠仍沒緩解：==不要換另一種 5-ASA==，改用別類藥 | C（against）／L |
| 15 | 輕度：**低劑量 2.0–2.4 g** 和 4.8 g 一樣 | C／VL |
| 16 | 口服 5-ASA 沒反應：**加 budesonide MMX 9 mg** | S／M |
| 17 | 5-ASA **qd 或分次**都可以，依病人偏好提高順從性 | S／M |
| 18 | 輕度 proctitis 維持：**rectal 5-ASA 1 g** | S／M |
| 19 | 輕度 left-sided 或 extensive 維持：**口服 5-ASA ≥ 1.5 g** | S／M |
| 20 | ==全身性、budesonide MMX、局部類固醇都不可以維持== | S（against）／M |

### 中重度：誘導

| # | 建議 | 強度 |
| --- | --- | --- |
| 21 | 中度：**budesonide MMX** 誘導 | S／M |
| 22 | 中重度：**口服全身性類固醇** | S／L |
| 23 | ==Thiopurine 或 methotrexate 單用不能誘導== | S（against）／L |
| 24 | **S1P modulator**：ozanimod、etrasimod | S／M |
| 25 | **Ustekinumab** | S／M |
| 26 | **IL-23p19**：guselkumab、mirikizumab、risankizumab | S／M |
| 27 | **Vedolizumab** | S／M |
| 28 | **Infliximab** | S／**H** |
| 29 | **Adalimumab、golimumab** | S／M |
| 30 | **Tofacitinib** | S／M |
| 31 | **Upadacitinib** | S／**H** |
| 32 | 5-ASA 失敗、改用 biologic 或 JAK：==不要再加 5-ASA== | C（against）／VL |
| 33 | ==Infliximab 誘導時合併 thiopurine== | S／M（azathioprine） |

### 中重度：維持

| # | 建議 | 強度 |
| --- | --- | --- |
| 34 | 5-ASA 失敗、用 anti-TNF 維持：不要再加 5-ASA | C（against）／L |
| 35 | ==不要用全身性類固醇維持== | S（against）／M |
| 36 | 類固醇誘導後：**thiopurine** 維持（優於不治療或類固醇） | C／L |
| 37 | **不要用 methotrexate 維持** | C（against）／L |
| 38 | 繼續 **ozanimod 或 etrasimod** | S／M |
| 39 | 繼續 **ustekinumab** | S／M |
| 40 | 繼續 **guselkumab、mirikizumab、risankizumab** | S／M |
| 41 | 繼續 **vedolizumab**（IV 或 SC） | S／M |
| 42 | 繼續 **adalimumab、golimumab、infliximab**（IV 或 SC） | S／M |
| 43 | 繼續 **tofacitinib 或 upadacitinib** | S／M |

### 怎麼選藥

| # | 建議 | 強度 |
| --- | --- | --- |
| 44 | Anti-TNF 有效後失去反應：**驗藥物濃度**，濃度不夠再驗 **anti-drug antibody** | C／VL |
| 45 | ==Vedolizumab 優於 adalimumab==（誘導與維持） | S／M |

### 住院的 ASUC

| # | 建議 | 強度 |
| --- | --- | --- |
| 46 | **驗 C. difficile** | S／M |
| 47 | ==藥物預防 DVT== | S／L |
| 48 | ==不常規使用廣效抗生素== | S（against）／L |
| 49 | 不用 **TPN 讓腸道休息** | C（against）／VL |
| 50 | ==Methylprednisolone 60 mg／天==，或 hydrocortisone 100 mg tid–qid | S／L |
| 51 | IV 類固醇 **3 天**反應不足：==infliximab 或 cyclosporine== rescue | S／M |
| 52 | Infliximab 救回 → **infliximab 維持** | S／M |
| 53 | Cyclosporine 救回 → **thiopurine 維持** | C／L |
| 54 | Cyclosporine 救回 → **vedolizumab 維持** | C／VL |

## Table 3：Key concept statements（57 條）

<div class="orig-fig" data-src="腸胃肝膽科/uc-acg-2025-originals/table-03-1.png,腸胃肝膽科/uc-acg-2025-originals/table-03-2.png,腸胃肝膽科/uc-acg-2025-originals/table-03-3.png" data-label="Table 3"></div>

### 診斷、評估與預後（1–8）

| # | 重點 |
| --- | --- |
| 1 | **Hematochezia、排便次數增加、bowel urgency** → 懷疑 UC |
| 2 | 診斷時要**排除感染** |
| 3 | **大腸鏡進到 ileum**，病灶與正常處都切片，最好由腸胃病理專家判讀 |
| 4 | 範圍：**proctitis**（距肛門 18 cm 內）、**left-sided**（到 splenic flexure）、**extensive**（超過 splenic flexure，含 pancolitis） |
| 5 | Terminal ileum 正常 → 不需上消化道內視鏡或小腸影像，除非懷疑 Crohn's |
| 6 | 嚴重度依：**病人症狀**（出血、排便、urgency）、**發炎負擔**（內視鏡、FC、CRP、albumin）、**病程**（住院、類固醇、治療失敗）、**對生活的影響** |
| 7 | 內視鏡嚴重度用**驗證過的量表**（MES 或 UCEIS） |
| 8 | 追蹤反應與復發：**FC、CRP、內視鏡、腸道超音波** |

### 治療目標（9–17）

| # | 重點 |
| --- | --- |
| 9 | 分**誘導**和**維持**；目標是**無類固醇緩解**與生物指標或內視鏡改善 |
| 10 | 策略要反映病人與醫師的目標，承認是慢性病 |
| 11 | **Symptomatic remission**＝症狀改善；**endoscopic healing**＝黏膜完整無 friability；兩者合起來＝**deep remission**（首選目標）；**無類固醇緩解**通常 > 12 週 |
| 12 | 一開始先恢復正常排便、控制出血與 urgency；內視鏡癒合＝持續緩解、較少切除大腸 |
| 13 | **組織學緩解**有好處，但還沒前瞻性驗證為目標 |
| 14 | 控制黏膜發炎**可能降低 dysplasia 風險** |
| 15 | 監測疾病與藥物併發症，做預防保健 |
| 16 | **定期回診** |
| 17 | ==篩檢焦慮與憂鬱== |

### 輕到中度（18–23）

| # | 重點 |
| --- | --- |
| 18 | ==有預後不好的因子 → 用中重度治療==；年輕單獨較弱，年輕＋另一因子可能足夠 |
| 19 | **8 週內**評估誘導反應 |
| 20 | Probiotics、prebiotics 等**不建議**當主要誘導 |
| 21 | **FMT** 沒有最佳做法，不當主要誘導 |
| 22 | 緩解後要用**有效的維持治療** |
| 23 | Probiotics 維持**證據不足** |

### 中重度：誘導（24–32）

| # | 重點 |
| --- | --- |
| 24 | ==對 5-ASA 沒反應或不耐受 → 當作中重度== |
| 25 | 門診中度與重度處理相似，例外：(a) 5-ASA 只能單用在**中度**；(b) 中度先考慮 **budesonide MMX**；(c) 重度用**全身性**類固醇；(d) 有其他有效誘導藥時**可以不用類固醇** |
| 26 | **範圍不限制 advanced therapy**，含 isolated proctitis |
| 27 | Anti-TNF＋immunomodulator 的資料**只有 infliximab＋thiopurine** |
| 28 | Anti-TNF 沒反應或失去反應 → **驗 trough 濃度**決定優化或換藥 |
| 29 | ==濃度足夠仍 primary nonresponse → 換另一種機轉==，不在 anti-TNF 之間換 |
| 30 | **Biosimilar** 可取代原廠（anti-TNF、ustekinumab），換藥不應延誤 |
| 31 | **SC infliximab、SC vedolizumab** 維持＝IV 標準維持；誘導或取代加量尚未確立 |
| 32 | 對藥物無效或不耐受 → **照會外科、考慮切除大腸** |

### 中重度：維持（33–39）

| # | 重點 |
| --- | --- |
| 33 | 5-ASA 維持對**之前重度**的人效果可能較差 |
| 34 | Budesonide MMX **沒有研究**用於中重度維持 |
| 35 | ==用誘導有效的藥來維持== |
| 36 | **Proactive TDM** 在一般緩解病人證據不足 |
| 37 | **Vedolizumab、ustekinumab、IL-23p19 不建議驗濃度** |
| 38 | 最佳藥物治療仍無法維持 → **擇期 proctocolectomy** |
| 39 | 不論範圍（含 isolated proctitis），用對該嚴重度有效的藥 |

### 怎麼選藥（40–47）

| # | 重點 |
| --- | --- |
| 40 | **沒有驗證過的預測 biomarker** |
| 41 | ==保險與 step therapy 不應擋在醫病之間== |
| 42 | ==第一個 advanced therapy 反應最好== |
| 43 | 分清楚 **primary nonresponse** 與 **secondary nonresponse** |
| 44 | 事後分析與 network meta-analysis 只能產生假說，不能用來為個人選藥 |
| 45 | ==Infliximab 是首選 anti-TNF== |
| 46 | 感染風險高 → **vedolizumab 或 anti-IL-23** |
| 47 | 依**腸道外表現**（關節、皮膚）選兩邊都有效的藥 |

### 住院的 ASUC（48–57）

| # | 重點 |
| --- | --- |
| 48 | ==72 h 內（最好 24 h）flexible sigmoidoscopy==，評估嚴重度、切片找 **CMV** |
| 49 | 評估 **toxic megacolon** |
| 50 | 監測：排便次數、直腸出血、腹部檢查、生命徵象、**連續 CRP** |
| 51 | ==避免 NSAID、opioid、anticholinergic== |
| 52 | **3 天**沒反應或懷疑毒性 → **照會外科** |
| 53 | Infliximab vs cyclosporine：看**醫師經驗、之前 immunomodulator 或 anti-TNF 失敗、albumin** |
| 54 | 手術適應症：==toxic megacolon、穿孔、嚴重止不住的出血、藥物無效== |
| 55 | Infliximab、cyclosporine **不增加術後併發症**，不要延後手術 |
| 56 | IV 類固醇或 infliximab 失敗：**JAK（tofacitinib、upadacitinib）資料不足**，不常規使用 |
| 57 | 開始 infliximab 時 **albumin < 2.5 g/dL → 考慮加量** |
