> [!abstract] 一句話重點
> TG18 **完全沿用 TG13** 的診斷與分級。Cholangitis 看 **A 全身發炎＋B cholestasis＋C imaging**（A 必備）；cholecystitis 看 **A 局部徵象＋B 全身發炎＋C imaging**。兩者 **Grade III 的器官衰竭定義相同**，**Grade II 完全不同**：cholangitis 是「五項中 **≥ 2 項**」，cholecystitis 是「四項中 **任 1 項**」。

## Acute cholangitis 的診斷

### 為什麼不用 Charcot's triad？

Charcot's triad（fever、RUQ pain、jaundice）**specificity 很高**，出現時強烈支持 cholangitis；但 sensitivity 太低，大型多中心研究只有約 **2 成多**的病人符合，所以**不能當診斷標準**。TG13 把 triad 裡的 abdominal pain 拿掉（因為它讓 cholecystitis 大量偽陽性），改成「發炎＋膽汁淤積＋影像」三軸，日台大型研究中約 **90%** 臨床上當作 cholangitis 治療的病人能被診斷出來（TG07 約 79%）。

> [!tip] Pearl：sensitivity 比 specificity 重要
> Cholangitis 延誤診斷會致命，所以這套標準刻意偏向**抓得到**；代價是 mild case、沒有明顯全身發炎、或影像看不出原因的病人仍可能漏掉。

### Table 2：TG18/TG13 cholangitis 診斷標準

<div class="orig-fig" data-src="腸胃肝膽科/tg18-originals/kiriyama-table-02.png" data-label="Kiriyama Table 2"></div>

| 類別 | 項目 | 門檻 |
| --- | --- | --- |
| **A. Systemic inflammation** | A-1 Fever 和／或 shaking chills | BT **> 38°C** |
| | A-2 Lab 有發炎反應 | WBC **< 4,000 或 > 10,000**／µL；CRP **≥ 1 mg/dL** |
| **B. Cholestasis** | B-1 Jaundice | T-bil **≥ 2 mg/dL** |
| | B-2 肝功能異常 | ALP、GGT、AST、ALT **> 1.5 × ULN** |
| **C. Imaging** | C-1 Biliary dilatation | |
| | C-2 影像看到病因 | stricture、stone、stent 等 |

- **Suspected**：A 一項 ＋ **B 或 C** 一項
- **Definite**：**A ＋ B ＋ C** 各一項
- 其他輔助線索（不在標準內）：RUQ／上腹痛、膽道疾病史（gallstone、膽道手術、biliary stent）
- 鑑別 **acute hepatitis**：hepatitis 很少有明顯全身發炎；分不清時加做病毒與血清學檢查

> [!warning] Pitfall
> - ==**A（全身發炎）是必備條件**==：只有黃疸＋膽管擴張、沒有發炎，不能診斷 cholangitis
> - Jaundice 只出現在約 6–7 成 cholangitis；==沒黃疸也能靠 B-2 肝功能異常成立==

### Cholangitis 影像怎麼選

| 檢查 | 角色 | 重點 |
| --- | --- | --- |
| **Abdominal US** | **第一線**（Rec 1） | 便宜、無侵入；看 CBD dilatation 與病因。對 CBD stone 的 sensitivity 低（約 4 成）但 specificity 很高 |
| **CT** | 第一線之一（臨床上常先做） | 不受腸氣影響、範圍廣、可排除其他急腹症；看 **liver abscess、portal vein thrombosis** 等併發症。結石偵測 sensitivity 差異大（25–90%，看鈣含量） |
| **MRI/MRCP** | US/CT 無法確診時（Rec 2） | 判斷 benign／malignant 最準；stone 在 T2 是 signal void |
| **Dynamic CT／MRI 的 THAD** | 未來研究題目 | Early phase 肝實質短暫不均勻強化，約 7–8 成 AC 病人有；但 pancreatitis、pyelonephritis、pneumonia 也會出現，specificity 不高 |
| ERCP | **治療（drainage）用**，不建議當第一個診斷工具 | |

## Acute cholangitis 的嚴重度分級

### Table 4：TG18/TG13 cholangitis 嚴重度

<div class="orig-fig" data-src="腸胃肝膽科/tg18-originals/kiriyama-table-04.png" data-label="Kiriyama Table 4"></div>

| Grade | 定義 | 項目 |
| --- | --- | --- |
| **III（severe）** | 任 **1 個**器官／系統衰竭 | 心血管：低血壓需 **dopamine ≥ 5 µg/kg/min 或任何劑量 norepinephrine**<br/>神經：意識障礙<br/>呼吸：**PaO₂/FiO₂ < 300**<br/>腎：oliguria 或 **Cr > 2.0 mg/dL**<br/>肝：**PT-INR > 1.5**<br/>血液：**PLT < 100,000/mm³** |
| **II（moderate）** | 下列 5 項中 **≥ 2 項** | **WBC > 12,000 或 < 4,000**<br/>**高燒 ≥ 39°C**<br/>**年齡 ≥ 75 歲**<br/>**T-bil ≥ 5 mg/dL**<br/>**Albumin < 正常下限 × 0.7** |
| **I（mild）** | 不符合 II、III | |

> [!tip] 記法
> Grade II 五項 = **「白燒老黃白」**：WBC、燒 39、老 75、黃 5、白蛋白 0.7。
> 注意兩種「白」：診斷用 WBC 門檻是 **< 4k 或 > 10k**，分級用是 **< 4k 或 > 12k**。

> [!warning] Grade I 也要處理病因
> 表註強調：不論哪一級，**早期診斷、引流／處理病因、抗生素**都是基本治療；Grade I 對初始治療（支持療法＋抗生素）沒反應時，就要做 early drainage。

### Table 3：引流時機與 30 天死亡率（為什麼 Grade II 要早引流）

<div class="orig-fig" data-src="腸胃肝膽科/tg18-originals/kiriyama-table-03.png" data-label="Kiriyama Table 3"></div>

日台約 6,000 名病人的資料，依「24 h 內（urgent）」或「48 h 內（urgent＋early）」有沒有引流比較：

| Grade | 24 h 內引流 vs 沒有 | 48 h 內引流 vs 沒有 | 解讀 |
| --- | --- | --- | --- |
| III | 約 5% vs 5%（無差異） | 無差異 | 可能需要更早（< 12 h）才看得出差別，待研究 |
| **II** | **1.7% vs 3.4%（有差異）** | **2.0% vs 3.7%（有差異）** | ==Grade II 是早引流最能改善預後的族群== |
| I | 約 1% vs 1%（無差異） | 無差異 | 多數靠抗生素即可 |

整體死亡率隨 grade 上升而上升，但**惡性腫瘤造成的 cholangitis 例外**（分級與死亡率不相關）。分級的主要價值其實是**決定誰需要早引流**，而不只是預測預後。

> [!note] Procalcitonin
> 小型研究顯示 PCT 隨 cholangitis 嚴重度上升，可能有助於評估嚴重度，但證據不足（Level D，未來研究題目）。

## Acute cholecystitis 的診斷

### Table 1：TG18/TG13 cholecystitis 診斷標準

<div class="orig-fig" data-src="腸胃肝膽科/tg18-originals/yokoe-table-01.png" data-label="Yokoe Table 1"></div>

| 類別 | 項目 |
| --- | --- |
| **A. 局部發炎** | (1) **Murphy's sign**　(2) RUQ mass／pain／tenderness |
| **B. 全身發炎** | (1) Fever　(2) CRP 上升　(3) WBC 上升 |
| **C. 影像** | Cholecystitis 的典型影像表現 |

- **Suspected**：A 一項 ＋ B 一項
- **Definite**：A ＋ B ＋ **C**
- 需排除：acute hepatitis、其他急腹症、chronic cholecystitis

驗證研究中 TG13 標準 sensitivity 約 **91%**、specificity 約 **97%**，遠勝單用 Murphy's sign（sensitivity 只有約 2 成）。

> [!warning] 和 cholangitis 的差別
> Cholecystitis 的 **A 是局部徵象**（Murphy's、RUQ），cholangitis 的 **A 是全身發炎**；cholecystitis 的 definite diagnosis ==一定要有影像==。

### Cholecystitis 影像怎麼選

| 情境 | 首選 | 重點 |
| --- | --- | --- |
| 一般懷疑 cholecystitis | **Abdominal US**（Rec 1） | Meta-analysis：sensitivity 約 81%、specificity 約 83%；HIDA 診斷率更高但不普及 |
| US 無法確診 | **MRI/MRCP**（Rec 2） | 診斷率略優於 US；可看膽道解剖（術前有用）；但急性腹痛病人可能無法憋氣 |
| 懷疑 **gangrenous** cholecystitis | **Contrast CT 或 contrast MRI**（Rec 2） | 壁不規則增厚、**壁強化中斷（interrupted rim sign）**、腔內膜狀物、周圍膿瘍；US 常低估 |
| 懷疑 **emphysematous** cholecystitis | **CT**（Rec 2） | 壁內或腔內有氣體；US 不易和 porcelain GB 區分 |
| Color／power Doppler | 不建議用來診斷 | 太受機器與體型影響，無法量化 |

**典型影像表現**：GB wall thickening（**≥ 4 mm**）、GB 腫大（長軸 ≥ 8 cm、短軸 ≥ 4 cm）、gallstone 或 debris、pericholecystic fluid、GB 周圍脂肪條狀影；US 上加上 **sonographic Murphy's sign**。

> [!danger] Emphysematous cholecystitis
> 由產氣菌造成，**穿孔率高、進展極快**，可併發腹內膿瘍、腹膜炎、腹壁 gas gangrene 與 sepsis；TG 把它歸在 Grade II 的「marked local inflammation」。

## Acute cholecystitis 的嚴重度分級

### Table 7：TG18/TG13 cholecystitis 嚴重度

<div class="orig-fig" data-src="腸胃肝膽科/tg18-originals/yokoe-table-07.png" data-label="Yokoe Table 7"></div>

| Grade | 定義 | 項目 |
| --- | --- | --- |
| **III（severe）** | 任 **1 個**器官衰竭 | **與 cholangitis Grade III 完全相同**（dopamine ≥ 5 或任何 NE、意識障礙、P/F < 300、oliguria 或 Cr > 2.0、INR > 1.5、PLT < 10 萬） |
| **II（moderate）** | 下列 **任 1 項** | **WBC > 18,000**<br/>RUQ 摸得到壓痛腫塊<br/>症狀 **> 72 h**<br/>**明顯局部發炎**：gangrenous、pericholecystic abscess、hepatic abscess、biliary peritonitis、emphysematous cholecystitis |
| **I（mild）** | 不符合 II、III | 健康、無器官衰竭、GB 只有輕微發炎，cholecystectomy 安全低風險 |

> [!important] 一定要驗 T-bil
> Grade III 要用 ④ 的流程圖判斷 **negative predictive factor**（jaundice＝**T-bil ≥ 2**、neurologic、respiratory dysfunction），所以 ==cholecystitis 也要量 total bilirubin==。

### 分級和預後的關係

<div class="orig-fig" data-src="腸胃肝膽科/tg18-originals/yokoe-table-02.png,腸胃肝膽科/tg18-originals/yokoe-table-06.png" data-label="Yokoe Table 2、6"></div>

- Cholecystitis 整體死亡率只有約 **1%**；日台 5,000 多人資料中，30 天死亡率 Grade I 約 1.1%、II 約 0.8%、**III 約 5.4%**（只有 III 明顯較高）
- Grade 越高，住院天數、**LC 轉開腹率**、併發症、醫療費用都越高
- Grade III 裡面，多變項分析和死亡相關的是 **jaundice、neurologic dysfunction、respiratory dysfunction**（就是後來的 negative predictive factors）；cardiovascular、renal 衰竭則否

## Cholangitis vs Cholecystitis 對照

| | Acute cholangitis | Acute cholecystitis |
| --- | --- | --- |
| 診斷 A | 全身發炎（**必備**） | 局部徵象（Murphy's、RUQ） |
| 診斷 B | Cholestasis（黃疸或 LFT） | 全身發炎 |
| 診斷 C | 膽管擴張或病因 | 典型 GB 影像 |
| Suspected | A ＋（B 或 C） | A ＋ B |
| Grade II | 5 項中 **≥ 2**：WBC > 12k/< 4k、≥ 39°C、≥ 75 歲、T-bil ≥ 5、Alb < 0.7 × LLN | 4 項中 **≥ 1**：WBC > 18k、RUQ mass、> 72 h、marked local inflammation |
| Grade III | 器官衰竭（兩者相同） | 器官衰竭（兩者相同） |
| 分級最大用途 | 決定**引流時機** | 決定 **LC 或 GB drainage** |
